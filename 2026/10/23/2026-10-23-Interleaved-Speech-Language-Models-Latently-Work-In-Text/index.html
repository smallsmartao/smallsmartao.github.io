Interleaved Speech Language Models Latently Work In Text

本文最后更新于 2026年10月23日 下午

论文信息

  • 标题：Interleaved Speech Language Models Latently Work In Text
  • 作者：Talia Sternberg、Gallil Maimon、Yossi Adi
  • 机构：The Hebrew University of Jerusalem
  • 版本：arXiv v2，2026 年 9 月 6 日
  • 论文：arXiv:2606.22473
  • 项目主页：Speech LMs Latently Work In Text

一句话概括：交错式语音语言模型虽然只接受 next-token prediction 训练，却会在中间层形成可解码的当前词、文本续写与事实答案，再在输出端回到语音 token 空间；这种“隐式潜在转写”与语音事实知识能力正相关，但论文尚未证明模型会因果性地使用它。

一段语音进入端到端 Speech LM 后，模型内部究竟以什么形式处理它？直觉上，输入和输出都是离散语音单元，隐藏状态也许会一直留在“语音空间”。这篇论文观察到另一条轨迹：交错式 Speech LM 会先经过一个文本化的中间阶段，当前说出的词、下一词乃至尚未说出口的事实答案，都可能从中间隐藏状态中被解码出来。

最具代表性的结果来自 Llama-3.2 3B PI-1/3 官方模型。在受控数据上，当前词的累计 Recall@10 分别达到 61.9%（logit lens）、68.1%（latent lens）和 87.7%（linear probe）；在七个自然语音语料的聚合结果中，对应数值为 71.7%、40.3% 和 89.4%。三种读出器的绝对值不能直接横向比较，但它们从不同角度共同说明：中间层携带了高度可恢复的词汇信息。

一、为什么研究“模型内部是否在转写”

交错式 Speech LM 通常把离散语音单元和文本 token 放进同一条序列。例如一句话可以被构造成：

关键在于，同一个词只以语音或文本中的一种形式出现。模型没有同时看到某段语音及其逐字转写，也没有接受 ASR loss；它只需完成 next-token prediction。

已有研究发现，文本 LM 初始化和语音—文本交错训练能够改善 Speech LM 的语义能力，但内部机制仍不清楚：模型究竟直接在语音表示上进行语义计算，还是先把语音映射到一种文本式“工作空间”，借用文本 LM 已形成的能力，再映射回语音？

论文把中间层中可解码出对应文本词的现象称为 implicit latent transcription（隐式潜在转写）。它并不意味着模型显式输出 transcript，而是指当前语音词对应的文本 token 已经存在于可读出的隐藏表征中。

二、模型与受控训练配置

论文分析 Llama-3.2 和 Qwen2.5 两个模型家族，三组代表模型为：

  • Llama-3.2 3B PI-1/3 20k（官方 SIMS checkpoint）；
  • Llama-3.2 3B PI-2/3 20k；
  • Qwen2.5 3B PI-1/3 60k。

命名中的字母表示：

  • P：从预训练文本 LM 初始化；
  • R：随机初始化；
  • S：语音数据；
  • T：文本数据；
  • I-$r$：包含语音—文本交错数据，$r$ 是交错 token 在训练 token 中的比例。

所有受控 Llama-3.2 变体采用相同架构和优化设置：序列长度 2048、有效 batch size 32、训练 20K steps，目标只有 next-token prediction。

交错样本中，语音 span 长度从 $\operatorname{Poisson}(\lambda=10)$ 采样，直到语音 span 覆盖约 $\eta=0.3$ 的词。时间对齐 transcript 只用于确定词边界和分配模态；每个词只会以语音或文本形式出现，并不是平行的“语音—转写”监督对。

语音数据包括 LibriSpeech、LibriLight、VoxPopuli、TED-LIUM、People’s Speech、Spoken Wikipedia Corpus 和合成 sTinyStories；文本来自经 Gopher 规则过滤的 RedPajama。语音以 mHuBERT 特征配合 500-unit k-means codebook 离散化，文本使用 Llama-3.2 tokenizer。

三、三种互补的隐藏状态读出方法

3.1 Logit lens：借用模型自己的输出头

设第 $\ell$ 层、位置 $i$ 的隐藏状态为 $h_i^{(\ell)}$。Logit lens 将最终层使用的归一化和词表投影提前应用到中间层：

\[p_{\text{logit}}^{(\ell)}(x\mid i) = \operatorname{softmax}\left( W_{\text{out}}\operatorname{Norm}_f(h_i^{(\ell)}) \right)_x.\]

这样，每一层都会得到一个联合语音—文本词表上的概率分布。它无需额外训练，但只能读出已经与模型输出投影对齐的信息。

3.2 Latent lens：在文本表示库中检索

作者从 held-out RedPajama 收集评测词和随机干扰词的上下文化表示，在每一层对同一个词的多次出现求平均，构造该层的文本词表示库。随后计算语音隐藏状态与词表示的余弦相似度，以 top-$k$ 近邻作为解码结果。

它不依赖输出头，检验的是语音隐藏状态是否在几何上接近“同一模型处理文本时形成的词表示”。

3.3 Linear probe：信息能否被线性提取

第三种方法为每个模型、每一层和每种目标分别训练 affine-softmax 分类器，同时冻结 Speech LM。分类空间包含 tokenizer 对应的 RedPajama 最常见 10,000 个 token 和全部评测目标，训练数据来自 People’s Speech 的 500 万个对齐语音 token 位置。

Linear probe 能证明信息可以被额外监督的线性分类器读出，但不能证明原模型在生成过程中实际使用了该方向。

原论文 Figure 3。虚线为 Recall@1，实线为 Recall@10。当前词信号最强，下一词和事实答案较弱，但在多个模型和解码方法中都可恢复。

四、词级指标如何处理一段语音 token

一个词通常横跨多个离散语音 token，最可读的位置也不固定。令 $S(w)$ 表示词 $w$ 对齐到的语音位置集合。对解码器 $j$，累计 Recall@$k$ 定义为：

\[\frac{1}{|\mathcal D|} \sum_{w\in\mathcal D} \mathbf 1\left[ \exists\,\ell\le L,\ i\in S(w): y_w\in\operatorname{TopK}(p_j^{(\ell)}(i),k) \right].\]

也就是说，截至第 $L$ 层，只要目标词曾在该词某个对齐位置进入 top-$k$，就算成功找回。所有方法统一采用小写、去标点，并对第一个 word-start token 做精确匹配。

为了排除高频词天然容易进入 top-$k$ 的影响，作者为每个金标词从同一 RedPajama 词频区间抽取 20 个控制词，使用完全相同的 span 和累计召回流程，并报告 95% 置信区间。

五、结果一：隐藏状态经历“语音—文本—语音”三阶段

原论文 Figure 2。青色为文本 token 概率质量，黄色为语音 token；下排只统计 top-200 token，用于控制两类词表规模差异。

对 SIMS-Llama3.2-3B 的语音输入，logit-lens 概率质量呈现清晰轨迹：

  • 第 0–2 层：speech token 占主导；
  • 第 2–25 层：概率质量明显转向 text token；
  • 第 26–28 层：重新回到 speech token 域。

文本输入则始终集中在文本 token。作者进一步只保留概率最高的 200 个 token，三阶段模式依然存在，因此不能简单归因于文本词表更大。

这一结果说明中间状态经输出头投影后进入了文本词表区域，但它本身还不能证明模型编码的是正确转写，因此需要后续词级实验。

六、结果二：当前词确实能从中间层恢复

在受控事实提示集上，官方 Llama-3.2 3B PI-1/3 的累计 Recall@10 为：

解码方法 当前词 下一词
Logit lens 61.9 23.9
Latent lens 68.1 41.2
Linear probe 87.7 30.6

三项结果分别表明：当前词已与模型输出词表中的正确 token 对齐；语音状态在几何上接近同词的文本表示；词汇信息可被线性分类器高比例恢复。

Linear probe 接受了额外监督，不能因 87.7 最高就称其为“更好的内部解释器”。真正重要的是，三种假设不同的方法给出了同一方向的结论。非累计逐层曲线还显示，召回主要集中在中间层，到输出端时下降，与模态概率质量的三阶段轨迹一致。

6.1 任意位置聚合有没有夸大效果？

对官方 Llama PI-1/3，附录比较了更严格的 span selector：

span 选择方式 Recall@10
span 中任意位置 61.7
只看最后 25% 38.6
只看最后一个 token 33.9
只看第一个 token 9.2
对所有位置的召回取平均 22.9

任意位置聚合确实最敏感，但只看最后一个 token 时仍有 33.9%，说明 max 操作没有凭空制造现象。第一个 token 的召回较低，也符合模型需要更多声学上下文才能辨认完整词的解释。

信号在词内很局部：至少命中过一次的 word-layer pair 中，82.2% 的目标最多只在两个位置出现，而对齐词 span 的中位长度为 6 个语音 token。与此同时，已被 Recall@10 找回的词中，37.7% 连续保持至少 5 层，24.4% 至少 8 层，17.3% 至少 10 层，11.1% 至少 15 层。

七、不只转写当前词，还会形成文本续写

作者把解码目标换成句子的下一词，以及事实提示末尾对应的正确答案。下一词信号整体弱于当前词，但这并不全是模型能力问题：例如 United 后既可能接 Kingdom，也可能接 States，单一金标会低估合理续写。

原论文 Figure 1。横轴为语音位置，纵轴为 Transformer 层；输入没有说出答案，但 “London” 在后部中间层变得可解码。

事实答案提供了更明确的观察窗口。在语音提示 “The capital of the United Kingdom is…” 中，输入里从未出现的 London 会在中间层被 logit lens 解码出来。这说明隐藏状态不仅回顾当前声学内容，也包含基于上下文形成的文本续写假设。

不过，论文没有观察到稳定的“先转写、再预测”层序。当前词与续写信号可能重叠出现，而不是严格串行的两步流水线。

八、自然语音中仍然存在

受控事实集由 Kokoro-82M 合成，便于精确对齐，但可能过于干净。作者又从 People’s Speech、LibriSpeech、VoxPopuli、TED-LIUM、Spoken Wikipedia Corpus、VCTK 和 Flickr8k 各抽取 300 条，共评测 2,100 条自然语音。

七个语料聚合后的 Recall@10 为：

模型 方法 当前词 下一词
Llama PI-1/3 官方 Logit lens 71.7 27.1
Latent lens 40.3 20.0
Linear probe 89.4 57.4
Llama PI-2/3 Logit lens 57.7 17.4
Latent lens 51.7 28.2
Linear probe 87.7 58.5
Qwen2.5 PI-1/3 Logit lens 40.8 16.5
Latent lens 43.6 28.9
Linear probe 88.0 56.7

不同语料的绝对值差异较大，说明说话人、录音条件和语言分布都会影响可解码性；但总体模式并不局限于合成语音或单一模型家族。

九、哪些训练条件促成隐式转写

论文在相同 Llama-3.2 3B 架构和优化设置下改变初始化与数据构成。主文表 2 的 logit-lens Recall@10 如下：

模型 文本预训练 文本数据 交错数据 当前词 下一词 答案
PI-1/3 官方 ✓ ✓ ✓ 61.88 23.91 41.60
PI-1/3 ours ✓ ✓ ✓ 48.75 15.31 26.40
PI-2/3 ✓ ✓ ✓ 49.06 15.78 24.00
PI-5/6 ✓ ✓ ✓ 2.66 1.72 4.00
PST ✓ ✓ ✗ 3.75 3.28 0.00
PS ✓ ✗ ✗ 0.16 0.00 0.00
RST ✗ ✓ ✗ 5.78 6.72 4.80
RI-1/3 ✗ ✓ ✓ 2.19 5.78 7.20

这组受控比较支持三个判断：

  1. 只有文本数据不够：PST 没有交错样本，当前词 Recall@10 仅 3.75；
  2. 只有交错数据也不够：随机初始化的 RI-1/3 只有 2.19；
  3. 交错比例不是越高越好：PI-1/3 与 PI-2/3 接近 49，而 PI-5/6 降到 2.66。

因此，在论文设置中，强隐式转写最容易出现在“文本 LM 预训练先验 + 适量语音—文本交错”的组合中。作者推测过高交错比例可能改变训练分布，或减少纯模态上下文的暴露，但实验没有单独验证这个解释。

十、隐式转写与事实知识的关系

论文构造了 282 条单答案短提示，覆盖颜色、星期、月份、物体功能、国家语言、亲属关系、数值事实、反义词、首都、简单算术和数列等 13 类。每条真事实都配有一个同类别错误版本；若

\[\log p(\text{真事实}) > \log p(\text{同类别反事实}),\]

就记为回答正确。

原论文 Figure 5。左图为当前词、右图为下一词。散点跨越不同模型架构、规模、初始化、训练预算和数据配方，因此这里只能解释为相关。

跨模型的 Spearman 秩相关为：

  • 当前词 Recall@10：$\rho=0.70,\ p=0.0053$；
  • 下一词 Recall@10：$\rho=0.65,\ p=0.0119$。

两者都通过 Bonferroni 校正后的 $\alpha=0.025$ 阈值。证据允许说：隐式转写较强的模型，通常也有更高的语音事实知识准确率。

但它不能推出“模型因为先转写成文本，所以事实能力才提高”。模型规模、预训练质量、训练预算和数据混合都可能共同影响两个指标；随机初始化模型也会出现非零转写分数，却仍缺少知识能力。论文没有主动增强或削弱隐式转写后再测知识准确率，因此这里只是跨模型关联，不是因果机制。

十一、定性案例：边听边修正文本假设

单词级可视化揭示了两种探索性现象。

第一，隐式转写有时会随声学证据逐步形成：white 先出现 why，lime 先出现 lie，kingdom 先出现 king，Pakistan 先出现 pack，teacher 则从 tea 到 teach 再到完整单词。这与“首 token 召回低、末 token 召回更高”的统计结果相互呼应。

第二，隐式转写也会犯声学错误，例如 lime 有时被解码成 line。一旦语音被压入文本式表示，细微声学差异可能提前丢失或被误判。这个文本工作空间可能帮助模型调用文本知识，也可能成为错误传播和语音—文本模态差距的来源。

十二、论文真正证明了什么

把证据按强度排列，可以得到一条清晰但有限的结论链：

  1. 语音输入的中间层经输出头投影后，概率质量从语音词表转向文本词表，再回到语音词表；
  2. 正确当前词可被 logit lens、latent lens 和 linear probe 三种方法恢复；
  3. 中间层还编码下一词和事实答案等文本续写信息；
  4. 该现象同时存在于合成提示和七类自然语音；
  5. 受控 Llama 比较显示，文本 LM 初始化与适量交错训练的组合最容易产生强信号；
  6. 跨模型看，隐式转写召回与事实知识准确率正相关。

前四点是表征层面的直接证据，第五点是训练配置的受控比较，第六点只是统计关联。它们不能被合并成更强的说法——“模型一定先转写，再依赖文字进行因果推理”。

十三、局限与开放问题

13.1 可读不等于被使用

三种方法都在回答隐藏状态中“有什么信息”，而不是模型生成时“依赖什么信息”。即使三者一致，也不能确定文本式表征在原始前向计算中承担因果作用。

13.2 尚未定位具体电路

论文没有确定哪些 attention head、MLP、残差分量或层间路径计算了隐式转写，也没有使用 activation patching、ablation 或 steering 验证具体机制。

13.3 知识关系没有经过干预验证

最高相关系数为 $\rho=0.70$，仍有大量模型间差异未被解释。要验证因果关系，需要主动改变隐式转写强度，并在其他因素尽量不变时观察知识准确率是否随之变化。

13.4 文本化可能损害声学能力

Speech LM 的价值之一，是保留文本无法表达的韵律、情绪、说话人和环境信息。如果训练目标过度鼓励文本化，可能改善文本充分任务，却损害依赖声学细节的任务。论文没有评测这一权衡。

13.5 隐式转写没有消除模态差距

既然模型能进入文本空间，为什么语音能力仍落后于文本？作者提出三种待验证方向：隐式转写本身有错误；模态转换消耗了计算；语音 token 缺少时间压缩，使后续语言推理更困难。

十四、结论

这篇论文为交错式 Speech LM 提供了一条可测量的内部计算轨迹：

\[\text{离散语音表示} \rightarrow \text{可解码的文本词与文本续写} \rightarrow \text{语音 token 输出}.\]

这条轨迹同时得到输出头投影、文本表示检索和监督线性探针的支持，并从合成提示泛化到自然语音。受控训练比较进一步表明，文本预训练先验与适量交错监督的组合至关重要；仅有文本数据、仅共享词表，或从随机初始化开始接受交错训练，都没有产生同等强度的现象。

但最关键的一步仍未完成：隐藏状态中存在文字信息，不等于模型必须依赖它。后续研究需要从“读出”走向“干预”——定位产生隐式转写的计算路径，改变它，再分别测量文本知识、语音生成和细粒度声学能力，才能判断这个文本工作空间究竟是 Speech LM 的核心机制、一个有用接口，还是与性能共同出现的表征副产物。
