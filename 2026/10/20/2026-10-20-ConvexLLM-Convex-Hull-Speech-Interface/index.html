ConvexLLM：用冻结文本嵌入的凸组合连接语音与大语言模型

本文最后更新于 2026年10月20日 上午

论文信息

  • 标题：ConvexLLM: Scaling Convex-Hull Speech Interfaces to General-Purpose Audio Intelligence
  • 作者：Ming-Hao Hsu、Shujie Liu、Yuxuan Hu、Yuxiang Wang、Yingda Shen、Jinyu Li、Zhizheng Wu
  • 机构：香港中文大学（深圳）、Microsoft Research、Microsoft Research Asia
  • 版本：arXiv v1，2026 年 10 月 16 日
  • 论文：arXiv:2610.23539

一句话概括：ConvexLLM 不让语音连接器自由生成任意向量，而是让每个音频位置选择若干个冻结的文本 embedding，再对它们做连续凸组合。它研究的是：能否用文本嵌入作为固定表示基础，让 LLM 更容易调用语音中的语言信息，同时少破坏原有文本能力。

这篇论文最值得关注的不是“又一个模型刷新榜单”，而是一个更具体的任务取舍：

在论文的 2B 受控接口对比中，C-GATE 的语音语言任务综合分最高，MLP 的转录错误率最低，Q-Former 的 MMAU 音频理解平均分最高。

三种接口各有所长。理解这种差异，比把它们排成一条简单的优劣链更有价值。

一、为什么连接器不只是维度变换？

在此前的语音—语言接口演进综述中，我们讨论了离散音频 token、连续投影、Q-Former 和 CTC posterior 等路线。它们都要回答同一个问题：

语音编码器产生的表示，应该以什么形式进入一个主要通过文本预训练的语言模型？

最常见的连续接口可以写成：

\[H=\operatorname{AudioEncoder}(a),\qquad Z=\operatorname{Projector}(H).\]

只要 $Z$ 的最后一维与 LLM 隐藏维度一致，就能把它作为连续输入，拼到文本 prompt 旁边。但维度一致不代表分布一致，更不代表功能一致。

MLP 可以输出任意实数向量；Q-Former 也可以产生与文本 embedding 分布差异很大的表示。LLM 随后必须学习如何解释这种新输入，而适配过程可能改变它原有的文本处理行为。

ConvexLLM 的思路是：与其让连接器从头创造一种输入语言，不如要求它始终使用 LLM 已有的文本 embedding 作为固定基础。

1.1 离散、无约束连续与凸组合

原论文 Figure 1：离散接口选择 embedding 行；无约束接口可输出凸包外的点；凸接口允许连续变化，但输出始终位于文本 embedding 的凸包内。

设文本输入嵌入表为：

\[E\in\mathbb{R}^{V\times d_l}.\]

三种输入形式的区别是：

  • 离散查表：每个位置直接选择一行 $E_v$；
  • 无约束连续投影：输出任意 $\tilde e\in\mathbb{R}^{d_l}$；
  • 凸组合：输出若干 embedding 的非负加权平均，且权重之和为 1。

第三种形式满足：

\[\tilde e=\sum_v\alpha_v E_v, \qquad \alpha_v\ge 0, \qquad \sum_v\alpha_v=1,\]

因此：

\[\tilde e\in\operatorname{conv}(E).\]

这种“文本约束”是几何约束。它不要求每个音频位置都对应一个可读词，也不是先运行 ASR、再把转录交给 LLM。C-GATE 此前已在语音识别和情感识别中进行过受控研究；ConvexLLM 则把它扩展到完整的通用语音/音频语言模型，并同时考察交互、推理、识别与非语音音频理解。

二、C-GATE：对冻结词表做稀疏注意力读取

2.1 整体数据流

原论文 Figure 2：音频经编码器、时间池化和 C-GATE 后形成连续输入；图中的冻结状态以 Stage 1 为准，后续阶段会逐步解冻 encoder 与 decoder blocks。

完整链路为：

\[a\rightarrow H\rightarrow\bar H\rightarrow\tilde E \rightarrow\operatorname{LLM}\rightarrow y.\]
组件 配置
声学编码器 Whisper-large-v3
主模型 Decoder Qwen3.5-9B
受控接口对比 Decoder Qwen3.5-2B
时间压缩 stride 4 的均值池化
路由维度 $d_r$ 512
默认支持集大小 $K$ 16
路由温度 $\tau_r$ 可学习，初始化 1.0
混合温度 $\tau_m$ 固定 0.7
Query 投影 dropout 0.1

声学编码器输出：

\[H\in\mathbb{R}^{T\times d_a}.\]

均值池化后：

\[\bar H\in\mathbb{R}^{T'\times d_a}, \qquad T'\approx T/4.\]

C-GATE 为每个池化后的音频位置生成一个 $d_l$ 维输入，所以输出长度仍是 $T’$。这里的 $K$ 表示每个音频位置混合多少个词表 embedding，不是送入 LLM 的音频 token 总数。

2.2 音频生成 Query，文本 embedding 生成 Key

对第 $t$ 个池化声学状态：

\[q_t=f_\phi(\bar h_t)\in\mathbb{R}^{d_r},\]

其中 $f_\phi$ 包含仿射变换、LayerNorm 和训练时 dropout。

文本 embedding 表 $E$ 本身冻结，但通过可学习线性映射形成 key：

\[k_v=W_kE_v\in\mathbb{R}^{d_r}.\]

因此：

  • query 来自音频；
  • key 来自文本 embedding 的可学习投影；
  • value 是原始、冻结的文本 embedding。

它类似一次跨模态 attention，但查找对象不是音频时间轴，而是整个文本词表。

2.3 全词表打分并选择 Top-K

\[s_{t,v} = \frac{q_t^\top k_v}{\sqrt{d_r}\,\tau_r}, \qquad S_t=\operatorname{TopK}_v(s_{t,v}).\]

实现中分数会裁剪到 $[-30,30]$。词表按每块 2,048 行分块评分，最后合并全局 Top-K。这个技巧减少峰值内存，但不会把全词表检索变成近似检索，也不减少理论评分量。

2.4 支持集内归一化并进行凸组合

\[\alpha_{t,v} = \frac{\exp(s_{t,v}/\tau_m)} {\sum_{u\in S_t}\exp(s_{t,u}/\tau_m)}, \qquad v\in S_t,\]\[\tilde e_t = \sum_{v\in S_t}\alpha_{t,v}E_v.\]

因为权重非负且和为 1，$\tilde e_t$ 必在冻结文本 embedding 的凸包内。

$\tau_r$ 和 $\tau_m$ 都影响混合分布的尖锐程度。在忽略裁剪造成并列分数的理想情况下，正温度缩放不会改变 Top-K 排序，因此它们不是两个互相独立的“选词规则”。

Top-K 索引选择本身不可微；在普通 $K>1$ 设置中，梯度通过已选 embedding 的分数回传给 query/key 路由器。$K=1$ 的特殊梯度处理将在后文讨论。

2.5 为什么 C-GATE 不是“软转录”？

C-GATE 并未使用 CTC 或逐帧 token 标签监督路由权重。它学习的是：

哪些文本 embedding 的组合，能够帮助下游 decoder 完成当前音频任务？

这与“当前音频帧最可能对应哪个文字 token”不是同一目标。即使 value 来自文本 embedding，连续权重和支持集序列仍可承载韵律、说话方式或环境信息；反过来，论文也没有证明路由权重具有人类可读的逐词语义。

更准确的定义是：vocabulary-grounded continuous interface——以冻结词表为基础的连续音频接口。

三、训练：输入几何约束与输出行为蒸馏

ConvexLLM 同时使用接口约束、分阶段解冻、文本 replay 和文本教师蒸馏。它们作用在不同位置，不能混成一个贡献。

3.1 三阶段解冻

阶段 C-GATE 声学编码器 Decoder blocks Text embedding / LM head
Stage 1 训练 冻结 冻结 冻结
Stage 2 训练 训练 冻结 冻结
Stage 3 训练 训练 训练 冻结

Stage 1 先让接口适应两端已有表示；虽然 decoder 参数冻结，梯度仍可穿过 decoder 回传到接口。Stage 2 解冻声学编码器。Stage 3 再联合调整 decoder blocks。

所以，冻结 embedding 不等于冻结整个 LLM。后期 decoder 仍在学习如何解释这些凸组合输入。

3.2 基础目标：回答 token 的交叉熵

给定音频 $a$、任务 prompt $x$ 和回答 $y_{1:N}$：

\[\mathcal{L}_{\mathrm{CE}}(a,x,y_i) =-\log p_\theta(y_i\mid a,x,y_{\lt i}).\]

只有回答 token 参与损失；prompt、音频位置和 padding 均被 mask。文本 replay 使用相同目标，只是不包含音频。

3.3 9B 主模型：Text-Teacher Distillation

Stage 3 中，如果音频存在对应书面内容 $w$，论文用冻结的原始 Qwen3.5-9B 作为文本教师，让音频学生匹配教师的 next-token 分布：

\[\mathcal{L}_{\mathrm{KL}}(a,x,w,y_i) = \operatorname{KL}\left( p_{\bar\theta}(\cdot\mid w,y_{\lt i}) \middle\| p_\theta(\cdot\mid a,x,y_{\lt i}) \right).\]

这里的 $w$ 可以是合成语音指令对应的书面问题，也可以是真实语音的转录。这个 KL 对齐的是回答端语言模型行为，不是音频 embedding，也不是强迫 C-GATE 权重等于 ASR posterior。

论文按样本类型选择目标：

\[\mathcal{L}_i= \begin{cases} \mathcal{L}_{\mathrm{KL},i}, & \text{有书面对应的音频样本},\\ \mathcal{L}_{\mathrm{CE},i}, & \text{其他音频样本或文本 replay}. \end{cases}\]

这不是对所有样本统一使用 $\mathcal{L}_{CE}+\lambda\mathcal{L}_{KL}$。蒸馏温度为 1.0，教师只在训练时出现。

3.4 主模型与接口消融不是同一训练配方

9B 主模型 Stage 1/2 各训练 7,000 updates，Stage 3 在 7,500 updates 评估；Stage 3 有效 batch 为 512，使用 KL/CE 分流目标。2B 接口实验则用累计 5,000 Stage 1、7,000 Stage 2 和 18,000 Stage 3 updates，有效 batch 为 256，Stage 3 全部使用 CE。

2B Stage 3 的数据族采样为：识别 35%、ASR-derived instruction 15%、交互与音频理解 35%、文本 replay 15%。因此，9B 与 2B 的差异不能只解释成参数规模。

四、主结果：语言知识与推理强，不是所有音频任务都领先

4.1 指标口径

VoiceBench Overall 是 11 个子任务在 0–100 尺度上的等权平均，不包含 MMAU 与 LibriSpeech。部分开放式任务和 SD-QA 使用 GPT-5.4 judge；MMAU Test-mini 有 1,000 道 sound/music/speech 选择题；LibriSpeech 报 corpus-level WER。

但它并未全面领先：

  • MMAU 比 MiMo-Audio 低 14.13 个百分点；
  • ASR 明显落后于 Kimi-Audio；

五、2B 受控接口对比：三类任务，三个赢家

5.1 控制条件

论文将三种接口放在同一个 Whisper-large-v3 和 Qwen3.5-2B 之间，参数量匹配到约 1.7M：

接口 参数量 结构 输出位置数
MLP 1,706,494 1280→510→2048，GELU + LayerNorm $T’$
Q-Former 1,708,268 64 queries、宽度 280、单层 8-head cross-attention 64
C-GATE 1,705,473 512 维路由、Top-16 frozen embeddings $T’$

这点很重要：旧有印象中 Q-Former 常是上亿参数，但本文使用的是小型、参数匹配版本。因此这里不是“大连接器输给小连接器”。

三者共享 Stage 3 数据、CE 目标、有效 batch、学习率与调度。不过 Q-Former 输出固定 64 个位置，另外两者保留 $T’$；每种接口也只训练了一个模型，不能代表所有超参数配置下的最优结果。

5.2 受控结果

接口 Text Overall ↑ Speech Overall ↑ Speech–Text gap ↓ MMAU Avg ↑ clean WER ↓ other WER ↓
MLP 62.72 58.80 3.92 60.70 2.10 4.60
Q-Former 61.63 54.19 7.44 61.40 2.49 5.52

结论非常清晰：

  • C-GATE：语音语言综合任务最好；
  • MLP：逐词转录最好；
  • Q-Former：MMAU 平均最好。

C-GATE 相对 MLP 的 VoiceBench 优势主要集中于 OpenBookQA（59.78 vs 52.97）、MMSU（43.92 vs 41.28）和 SpeechMMLU（46.52 vs 43.63），三者贡献了约 1.12 个综合分差距。

论文给出的配对样本 bootstrap 95% 区间分别为 OpenBookQA [1.98, 11.65]、MMSU [0.68, 4.55]、SpeechMMLU [1.71, 4.07]。这些是测试样本重采样，不是多随机种子训练方差。

5.3 “文本能力保留”不是无退化

C-GATE 的 Text Overall 为 63.20，高于原始 Qwen3.5-2B 的 60.55，但分项并非全都提升。例如文本 BBH 从 76.60 降到 68.20；MLP 降至 63.60，Q-Former 降至 56.20。

三种适配模型在开放式回答、SD-QA 和 SpeechMMLU 上提高，却在 IFEval、OpenBookQA、MMSU 和 BBH 上下降。所以严谨说法应是：

C-GATE 在这组任务上的文本综合分与 MLP 接近，在若干推理任务上退化较少；它没有保证每项文本能力都不下降。

5.4 C-GATE 的 ASR 代价主要是替换错误

相比 MLP，C-GATE 的 clean/other WER 分别高 0.36/0.94 个百分点。附录统计多出 689 次词编辑，其中 559 次是 substitution，占 81.1%。speaker-bootstrap 95% 区间分别为 [0.24, 0.48] 和 [0.73, 1.19]。

这说明语音知识问答更好，不等于逐词听写更准；但论文没有足够证据把替换错误归因为“语言先验压过声学证据”。

六、Top-K：连续混合重要，但 K 不是越大越全面

16 60.35 59.40 2.46 5.54

6.1 为什么 K=1 会崩？

单元素 softmax 恒为 1，普通梯度无法通过这个常量训练路由器。因此 $K=1$ 使用 straight-through estimator：前向选择最高分 embedding，反向使用全词表 softmax 加权平均的梯度。

严重退化说明的是：在这套初始化和训练配方中，单一 embedding 硬选择远不如连续混合。 它不能推出所有离散音频 token 方法都会失败，因为独立训练的 tokenizer、扩展音频词表和不同目标并未被测试。

6.2 K=64 的收益与代价

$K$ 从 4 增到 64 时，WER 和 VoiceBench 持续改善，但 MMAU 在 $K=16$ 达到最高平均分。默认 $K=16$ 是任务折中，不是理论全局最优。

固定支持集后，$K$ 个归一化权重有 $K-1$ 个连续自由度；但不同音频位置还能选择不同支持集。因此整体表示不是一个固定低维子空间。与此同时，$K$ 增大表示每个位置混合更多 embedding，不代表输出序列变长。

七、几何分析：更早接近文本，但不是因果证明

7.1 文本主方向能量

作者对 248,077 个 tokenizer 覆盖的 embedding 行做 PCA，并计算：

\[R_X(k)= \frac{\sum_{j=1}^{k}\lVert X_cv_j\rVert_2^2} {\lVert X_c\rVert_F^2}.\]

前 100 个文本主方向覆盖的变化比例为：

表示 Top-100 文本主方向能量
C-GATE 28.4%
书面问题 token 23.7%
MLP 8.8%
Q-Former 4.9%

这说明 C-GATE 的变化更沿文本 embedding 的主要方向展开。但各集合分别中心化，所以该指标去除了均值位移；它也不直接衡量语义正确性。

7.2 跨层 Speech–Text 对齐

对同一问题的语音和文字表示做中心化余弦相似度后：

  • C-GATE 到 decoder block 7 已达约 0.69；
  • block 7–19 保持约 0.69–0.73；
  • block 7 时，MLP/Q-Former 仅约 0.45/0.44；
  • MLP 到最后一层才接近 C-GATE；
  • Q-Former 峰值约 0.63。

随机重配语音与文本问题后，95% 相似度落在接近零的 ±0.03 内，说明这个信号不只是公共背景成分。

7.3 输入尺度

MLP 和 Q-Former 输入范数分别为 36.7 和 25.2，文本 embedding 仅为 0.65。C-GATE 从第一层开始的尺度演化更接近文字表示。

原论文 Figure 5：20 个问题的输入先做单位 L2 归一化，再投影到书面问题 token 的前两个主成分。前两维只解释 16.12% 和 7.64% 的文字 token 方差，不能把二维聚簇直接解释成高维表示坍塌。

总体上，几何诊断与设计动机一致：C-GATE 让语音以更接近文本的方向、尺度和较早跨层对应关系进入 decoder。但论文没有通过独立干预拆开“范数、方向、凸包”各自的作用，几何相似也不等于功能等价。

八、放回现有连接器谱系：C-GATE 改变了哪一层？

过去常把接口选择简化成“MLP 还是 Q-Former”，但至少要拆成三维：

  1. 输入来自离散 tokenizer 还是连续 encoder；
  2. 时间轴如何压缩；
  3. 接口输出受到什么几何/词表约束。

8.1 五类路线对照

路线 进入 LLM 的表示 文本词表约束 时间结构/长度 主要优劣与适用任务
离散音频 token Token 查表向量 常扩展音频词表或 codebook，不一定复用原文本行 由 codec/tokenizer 决定 统一自回归序列；受量化误差和 token rate 影响，适合生成式统一建模
MLP / Conv projector 任意连续投影向量 通常无 Stride/pooling 后保持局部顺序 简单高效、ASR 强；decoder 要适应新分布
Q-Former Query 汇聚的连续向量 通常无 可固定 query 数，压缩强 擅长全局抽取，时序细节和表现依结构而异
CTC posterior / LegoSLM Posterior 对 embedding 的软组合 显式联系识别词表 取决于 CTC 时间率与压缩 识别监督明确、前后端可解耦；可能形成语言内容瓶颈
C-GATE Top-K frozen text embeddings 的凸组合 显式且固定 本文先 stride-4 pooling，接口保持 $T’$ 连续表达又受词表几何约束；语言推理强，但有全词表路由成本

C-GATE 位于“离散 token”和“无约束连续 projector”之间：它不是离散选择，但每个连续输出都锚定在冻结文本 embedding 的凸包内。

8.2 与 Attention Pooling：加权对象不同

Q-Former 与 Attention Pooling主要讨论如何从时间轴中汇聚音频：

\[z=\sum_t\beta_t h_t.\]

C-GATE 的加权对象则是词表：

\[\tilde e_t=\sum_v\alpha_{t,v}E_v.\]

前者回答“保留哪些音频信息”，后者回答“当前音频状态以什么语言空间表示”。两者不在同一维度上竞争；ConvexLLM 自己就先做时间均值池化，再做词表凸组合。

8.3 与 LegoSLM：同是软词表接口，权重语义不同

CTC posterior 与 C-GATE 形式上都可能写成 $Z=PE$，但 $P$ 的来源不同：

  • CTC posterior 与识别词表、转录监督直接关联；
  • C-GATE 权重由音频 query 与词表 key 路由，并通过下游任务学习。

因此 C-GATE 无需先获得 CTC 对齐，却也没有 CTC posterior 的直接识别概率含义。

8.4 与 JSTIP：接口约束和训练序列可正交

JSTIP通过词级/段级语音—文本交错改变训练上下文；C-GATE 改变输入几何；text-teacher distillation 改变回答分布监督；text replay 改变数据组成。

它们分别作用在序列、输入、输出监督与数据层面，理论上可组合；但 ConvexLLM 没有报告 “C-GATE + JSTIP” 实验，不能提前宣称必然互补。

九、局限与工程代价

9.1 Top-K 稀疏输出不等于低成本路由

对 $T’$ 个音频位置、词表 $V$ 和路由维度 $d_r$，全词表 query–key 评分复杂度为：

\[O(T'Vd_r),\]

支持集混合另需：

\[O(T'Kd_l).\]

2B embedding 表约 24.8 万行，路由空间并不小。按 2,048 行分块只省内存，不降低渐近计算。另一方面，Q-Former 固定输出 64 个位置，可能降低后续 decoder prefill；C-GATE/MLP 保留 $T’$。

论文没有给出完整吞吐、首 token 延迟、峰值显存和能耗，不能仅凭约 1.7M 接口参数就宣称 C-GATE 成本最低。

9.2 冻结 embedding 是稳定参照，不是“自然文本等价”

凸包性质可以严格证明，但下列命题不能由此推出：

  • 输出等价于真实文字 token；
  • 所有文本能力都会保留；
  • 任意声学信息都能被凸包充分表达。

三个受控接口都冻结 input embedding 和 output head，因此论文也没有单独消融“冻结 vs 解冻 embedding”的净效果。

9.3 非语音音频未必天然适配文本几何

ConvexLLM 能做环境声和音乐任务，但主模型 MMAU 落后于最强系统，2B C-GATE 也低于 MLP/Q-Former；增大 $K$ 没持续改善 MMAU。这可能与 encoder、数据、优化和词表约束共同相关，不能单独归因于凸包瓶颈。

9.4 “少于 0.3M 小时”只统计适配暴露上界

论文把各阶段样本按 30 秒上限计为音频，得到不超过 0.271M 小时。它包含重复采样和部分文本 replay，不是去重数据时长；也不包含 Whisper-large-v3 约 1M 小时弱标签与 4M 小时伪标签预训练，更不包含 Qwen3.5 预训练。

所以可以说“以较少音频适配暴露取得强 VoiceBench”，不能说模型全生命周期数据少几十倍，因此接口数据效率必然高同样倍数。

9.5 证据边界

  • 主表是不同基座与数据的完整系统对比；
  • 2B 每种接口只训练一个模型；
  • 几何诊断使用另一套训练步数和 loss 归一化；
  • 9B 没有完整拆开 C-GATE、KL、replay 的单独贡献；
  • 部分任务依赖单次 GPT-5.4 judge；
  • 输入上限 30 秒，未系统报告流式、多语言、口音与公平性；
  • 输出端是文本，不能从“general-purpose audio”推导出语音生成或全双工能力。

十、工程启示：区分“听得准”与“调用得好”

  • 主要目标是 ASR：MLP/Conv 仍是强基线；本文在 LibriSpeech、Common Voice 和 FLEURS 上均由 MLP 领先。
  • 目标是口语知识问答与推理：C-GATE 值得认真比较，它的 2B VoiceBench、知识任务与 speech–text gap 更好。
  • 目标是环境声、音乐和复杂音频事件：不要沿用语言任务排名；本文 Q-Former 在 2B MMAU 领先。
  • 关心部署成本：同时测量路由成本、输出序列长度、decoder prefill、端到端延迟与显存，而非只看接口参数量。

总结

ConvexLLM 展示了一种值得加入 Speech–LLM 工具箱的接口：

用冻结文本 embedding 构造连续音频输入，让模型学习“如何组合与解释”，而不是让 projector 自由创造全部输入向量。

它最有说服力的证据来自三方面：

  1. 9B 完整系统取得本表最高 VoiceBench 十一任务综合分；
  2. 参数匹配的 2B 比较中，C-GATE 的语音语言综合表现优于 MLP/Q-Former；
  3. 独立几何诊断显示，其表示更早呈现与配对文本相关的方向、尺度和跨层对应关系。

同样重要的是，它没有消除任务取舍：

  • 更强语音推理不等于更低 WER；
  • 文本平均分较高不等于每项文本能力都不退化；
  • 凸组合不等于自然文字；
  • 稀疏支持集不等于廉价路由；
  • 几何更接近文本不等于功能等价。

如果传统 connector 主要解决“怎样把声音投影到 LLM 的维度”，那么 ConvexLLM 进一步追问的是：

我们是否应该约束声音进入 LLM 时所使用的表示基础，而不只是匹配它的向量维度？

这比单一榜单排名更值得继续研究。
