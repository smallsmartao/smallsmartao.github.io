从路径搜索到目标词活动：Word Timing 与强制对齐的七条技术路线

本文最后更新于 2026年10月14日 中午

给一句语音和它的转写，如何确定每个词究竟在第几秒开始、在第几秒结束？表面上，Montreal Forced Aligner、WhisperX、Whisper 的 word_timestamps=True、Qwen3-ForcedAligner 与 RNN-T 都能输出类似

的结果；但它们找到这些数字的方式完全不同。有的在音素 HMM 状态图上执行 Viterbi，有的在 CTC trellis 上搜索，有的把 cross-attention 当作软对齐矩阵交给 DTW，有的直接把边界当分类目标，还有的只是读取流式 ASR 已经产生的触发位置。

这些差别决定了系统是否需要发音词典、能否处理 OOV、是否适合流式、边界会偏向词首还是词尾，以及“20 ms 时间分辨率”究竟只是量化网格，还是能够被实验证明的定位精度。本文按时间证据的来源，把 Word Timing 分为七条路线，并统一讨论每条路线的监督信号、目标函数、推理路径、词边界恢复、资源依赖与误差来源。

1. 先定义问题：识别、强制对齐与词时间戳不是一回事

这里至少有三种不同任务：

  1. Forced Alignment：音频和参考文本均已知，目标是只找 $B$；
  2. ASR with timestamps：文本 $\hat W$ 与时间 $\hat B$ 都由系统预测；
  3. 内部定位信号导出：模型本来只为识别训练，时间来自 attention、CTC spike、CIF fire 或 RNN-T emission 等中间量。

若 ASR 漏掉一个词，第一类方法仍可被参考文本“强制”经过该词；第二类方法则根本没有该词可供定位。因此，比较系统时不能只看平均边界误差，还应说明：

  • 是在参考文本还是识别文本上对齐；
  • 插入、删除、替换词是否计入指标；
  • 输出单位是 BPE、字符、语言学词、音素，还是字幕 segment；
  • 边界正确的 collar 是 20、40、100 还是 240 ms；
  • 起点和终点是否分别评估；
  • 长音频是否先做 VAD、分段或说话人分离。

2. 路线一：音素声学模型 + 受约束路径搜索

2.1 代表系统

  • Montreal Forced Aligner（MFA）：McAuliffe et al., Interspeech 2017；
  • Prosodylab-Aligner、FAVE、Gentle，以及基于 HTK/Kaldi 的传统对齐器。

MFA 论文的核心不是“把 ASR 跑一遍”，而是把参考词序列先展开为合法的音素/状态路径，再在声学帧上寻找最优路径。它使用 Kaldi 的 triphone 声学模型和 speaker adaptation，并支持在待对齐语料上训练或适配模型。

2.3 MFA 的实际工作流

完整部署通常包含：

  1. 文本规范化并建立词表；
  2. 查发音词典；
  3. 对 OOV 使用 G2P 生成读音，或把无法处理的词标为未知；
  4. 提取 MFCC 等声学特征；
  5. 使用预训练声学模型，必要时执行说话人适配；
  6. 编译每个 utterance 的参考文本约束图；
  7. Viterbi 对齐并导出 word/phone TextGrid。

因此，“MFA 只需要音频和文本”是用户接口层面的说法。系统内部仍依赖声学模型、语言对应的音素集合、发音词典和 OOV 策略。

MFA 2017 论文还提供了人工边界对照：其 LibriSpeech 预训练模型 MFA-LS 在 Buckeye 上，词边界 absolute difference 的均值/中位数为 24.1/15.8 ms，约有 88% 的词边界误差小于 50 ms、97% 小于 100 ms；但论文同时指出仍有约 2%–5% token 落在长尾大误差区间。这组结果比单报平均误差更有价值：forced alignment 的主要工程风险往往不是所有词都略偏，而是少量文本失配导致灾难性漂移。

2.4 优势与局限

优势

  • 搜索空间被参考文本和发音词典严格约束，路径可解释；
  • 可输出音素级结果，适合语音学标注和发音研究；
  • 多读音、可选静音、词内音素结构都能显式建模；
  • 在匹配语言、干净文本和足够适配数据上，边界通常稳定。

局限

  • 每种语言都需要音素表、词典和声学模型；
  • OOV、缩写、数字、专名、语码混合需要额外规范化或 G2P；
  • 参考文本与实际语音不一致时，强约束会把错误传播到后续路径；
  • 传统训练/适配流水线比端到端 CTC 更复杂；
  • 长静音、重叠语音、唱歌和强噪声仍可能扭曲状态持续时间。

这条路线适合精细语音学标注、已有语言资源、需要音素边界的场景；它的成本主要不是 Viterbi，而是维护词典、G2P 与声学资源。

回溯路径后，每个 token 获得一段帧区间；subword/character 再按 tokenizer 或空格规则聚合为词。NeMo Forced Aligner（NFA）使用 CTC ASR 模型，可根据参考文本或模型转写输出 token、word 与 segment 时间戳。

3.3 WhisperX 属于这条路线，而不是 Whisper attention 路线

WhisperX 的流水线是：

  1. VAD 将长音频切成语音区域；
  2. Whisper 负责批量转写；
  3. 另一个语言相关的 wav2vec2/CTC 模型对 Whisper 文本做 phoneme/character forced alignment；
  4. 字符或音素边界聚合为词边界；
  5. 可选说话人日志将 speaker 标签赋给词。

这里还要区分论文与当前实现：WhisperX 论文对外部音素分类 logits 使用 DTW；当前官方代码则构造 CTC trellis 并回溯路径。二者都属于“外部帧级声学模型 + 参考文本单调约束”，但不应把 WhisperX 简写成 Kürzinger et al. 的 CTC-segmentation，也不应把论文算法与当前代码完全等同。

因此，WhisperX 的词时间定位不是直接读取 Whisper cross-attention，也不是使用 Whisper segment timestamp token。它把“强识别能力”和“专门的单调声学对齐”拆成两个模型。优势是边界有更直接的帧级声学依据；代价是要为语言找到合适的 CTC 模型，并处理 Whisper 文本与 CTC 字符集不一致的问题。

WhisperX 论文用“词字符串完全匹配，且时间落在 200 ms collar 内”联合判定正确：在 AMI 上 precision/recall 为 84.1%/60.3%，在 Switchboard 上为 93.2%/65.4%。这里的 recall 不等同纯边界召回——ASR 漏词、替换词和无法映射的字符也会造成 FN。

3.4 CTC spike 为什么会影响词尾

标准 CTC 只要求非 blank 标签在某个位置出现一次即可正确折叠，常形成“长 blank + 单帧尖峰”。尖峰适合识别，却不天然覆盖整个音素持续区间：

  • onset 可近似取非 blank 首次出现的位置；
  • offset 若简单延伸到下一个 spike，会把停顿和相邻音素分配错误；
  • 下采样率越高，时间网格越粗；
  • BPE token 可能跨越多个音素，峰值也不等于词的声学起止。

Huang et al. 的 Less Peaky and More Accurate CTC Forced Alignment by Label Priors 通过 label prior 提升较少 blank 的路径，在 Buckeye 与 TIMIT 上相对标准 CTC/启发式方法将 phoneme/word boundary error 改善 12%–40%。该结果说明：能输出 CTC path 不代表 path 已经是高质量边界；训练时的峰度与 blank 偏置会直接影响定位。

3.5 优势与局限

优势

  • 可直接复用 CTC ASR 的帧级输出，不需要 HMM 多阶段训练；
  • 单调性与参考文本约束清晰，动态规划成熟；
  • 字符级 CTC 可减少发音词典依赖；
  • GPU 前向后，trellis 搜索成本相对可控。

局限

  • 需要与语言和字符集匹配的 CTC 模型；
  • CTC spike、blank 占优、encoder 下采样都会造成边界偏置；
  • BPE/character 到“词”的聚合依赖语言分词规则；
  • 文本缺词、多词或发音不一致时，约束路径仍会被迫穿过全部标签；
  • 直接对很长音频建 trellis 会增加内存，工程上通常需要 VAD/分段。

若已有可靠 CTC 模型，且任务是离线字幕、数据清洗或 ASR 后处理，这通常是精度、资源与工程复杂度之间最均衡的路线。

4.2 为什么 attention 不是边界概率

Cross-attention 表示 decoder 预测 token 时从哪些 encoder 状态取信息，不是经过词首/词尾标注训练的概率分布。因果解码还可能让当前 token 关注早先累积的语音证据。DTW、head 筛选、滤波和启发式能够让路径更平滑，却不能把不存在的声学监督凭空补出来。

常见错误包括：

  • ASR 漏词没有路径，幻觉词却会被强行分配音频；
  • 标点没有声学实现，但仍占文本位置；
  • BPE 前导空格可能把停顿算进下一词；
  • 多说话人、重叠语音和长静音使注意力发散；
  • 官方 head mask 对原始 checkpoint 有针对性，微调/蒸馏后未必仍最优；
  • 中文等无空格语言的官方输出常接近字符/Unicode 单元，不等于语言学分词。

CrisperWhisper 通过独立空格 token、verbatim 数据与对齐策略改善此问题，也从侧面说明 tokenizer 和转写风格本身会影响 DTW 边界。

5. 路线四：目标词活动检测 + DTW——TWAD 的无词典对齐

Microsoft 的 Target Word Activity Detector: An Approach to Obtain ASR Word Boundaries without Lexicon 提出了一条位于“attention 软对齐”和“显式边界分类”之间的路线。它不预测音素，也不直接回归每个词的 start/end；模型回答的是：

对于每一帧语音，参考句中的哪一个词正在发声？

这将词时间估计改写成一个 frame × word 的活动分类问题。模型输出词活动矩阵，再用 DTW 在矩阵上寻找覆盖给定词序列的单调路径。其关键价值是：推理时不需要发音词典、G2P、逐语言音素集合或逐 token 对齐标签，只需语音、词序列以及 ASR tokenizer/decoder embedding。

5.5 为什么 softmax 后还需要 DTW

逐帧 argmax 得到的词类别可能抖动、跳词或短暂回退。TWAD 因此把 $-\log\hat A$ 构造成代价矩阵，并在词序约束下执行 DTW。对齐前在每两个词之间、句首和句尾插入可选 silence，使停顿不必被强行分配给某个词。回溯得到的最优单调路径将连续帧分配给词，词第一次和最后一次被访问的帧分别形成 start/end。

5.6 模型、数据与 80 ms 时间网格

论文的基础 ASR 是 AED：Nemo-convolution 前端加 24 层 Conformer encoder、3 层 Transformer decoder。输入为 80 维 Mel filterbank，10 ms frame shift、25 ms window；前端进行 $8\times$ 下采样，因此 TWAD 的词活动切换只能发生在 80 ms 网格上。该网格是输出量化粒度，不等同于所有边界误差都小于 80 ms。

ASR 和 TWAD 覆盖英语、法语、西班牙语、意大利语和德语，共用 15,911 大小的 BPE tokenizer。TWAD 使用与 phone baseline 相同的训练数据：

五语种平均结果如下：

模型 边界 Mean↓ p50↓ p90↓ p95↓
CI-phone + lexicon baseline Start 47.7 ms 36 ms 78 ms 120 ms
CI-phone + lexicon baseline End 48.9 ms 36 ms 86 ms 132 ms

结果应分开理解：

  • 词首：TWAD 的平均、p90、p95 均优于强 phone baseline，特别是 p95 从 120 ms 降到 94 ms；
  • 词尾：TWAD 的中位数略好，但平均和长尾更差，p95 从 132 ms 增至 176 ms；
  • 分语言看，TWAD start 在 FR/ES/IT/DE 更好，在 EN 更差；end 仅在 ES/DE 略好，在 EN/FR/IT 更差；
  • 因而论文最稳妥的结论是：TWAD 在不使用 lexicon 的前提下达到可比的总体定位质量，并在词首和多语言扩展上更有优势，而不是全面超过 phone alignment。

5.8 两个重要消融：文本规范化与 encoder 层选择

ASR 输出保留标点、大小写和数字显示格式，例如把 “two hundred dollars” 写成 “$200”；TWAD 训练却使用 normalized text。若直接把 display-format token 输入 TWAD，德语 start/end 由 34.9/34.5 ms 恶化到 49.2/51.5 ms，意大利语由 42.9/58.8 ms 恶化到 58.2/74.3 ms。这说明它虽不需要词典，却仍高度依赖训练/推理一致的文本规范化与 word-token 分组。

层选择也与 phone baseline 完全相反：

  • TWAD 使用最后一层 encoder（layer 23）最好，英语为 61.6/90.6 ms；layer 22、20、9 分别退化到 110.2/121.0、195.7/175.5、248.2/264.9 ms；
  • CI-phone baseline 则在 layer 9 最好，高层因音素信息减少而变差。

这表明 TWAD 依赖的是靠近 decoder token space 的高层词法表示，而 phone alignment 依赖中层保留的局部音系表示。

5.9 优势、局限与适用场景

优势

  • 推理不需要发音词典、G2P、逐语言 phone inventory 或可靠的 word-level LID；
  • 一个模型共享多语言，新增语言不会增加全局 phone 输出维度；
  • 只需词级边界标签，不需要 phone/subword 对齐；
  • ASR 主干冻结，模块可外挂到已有 AED；
  • 词活动矩阵可解释，DTW 显式保证顺序。

局限

  • 仍是 forced alignment：必须已有大致正确的词序列；
  • 训练依赖 hybrid aligner 产生词级监督，教师偏差会被继承；
  • $W\times N$ 联合表示和双轴 BiLSTM 随句长增长，论文用 $W\le100$ 控制 batch；
  • 8 倍下采样只提供 80 ms 网格；
  • 只在正确识别词上评估，会隐藏 ASR 错误导致的端到端失败；
  • 数据和参考边界均为内部资源，缺少公开复现与人工边界验证；
  • 词尾长尾明显弱于 phone baseline；
  • 文本规范化、标点、数字和“word”切分仍是语言相关工程问题。

TWAD 最适合已有多语言 AED、能够获得词级伪标签、但不愿为每种语言维护 lexicon/phone set的离线批量对齐场景。它不是流式 ASR 的原生时间信号，也不是无需监督的即插即用方法。

6.2 非移位训练与非自回归推理

普通 LLM 用“输入第 $i$ 个 token，预测第 $i+1$ 个 token”的 shifted next-token objective。Qwen3-ForcedAligner 保持输出与标签不移位，让 [time] 槽位直接预测自己的时间类别；推理时所有槽位可并行预测，不必自回归生成一串 timestamp token。

训练还随机决定在不同词/字符后插入哪些起止槽位，使模型在推理时能对用户指定的任意位置定位。其监督标签主要由 MFA 产生，因此这条路线本质上是把传统对齐器的大规模伪标签蒸馏进一个多语言语音-文本模型。

Qwen3-ASR 论文公开了这些关键细节：slot filling、80 ms 离散索引、仅 timestamp slot 上的 CE、非移位 causal training、dynamic slot insertion 和 NAR inference。它并非一个“训练细节完全未知的黑箱”，也不应被误写成连续 start/end 回归。

6.3 结果该怎样解读

论文使用 accumulated average shift（AAS）衡量预测槽位与参考槽位的平均绝对偏差。人标测试集上，Qwen3-ForcedAligner-0.6B 的平均 AAS 为 32.4 ms；论文报告其相对 Monotonic-Aligner/NFA 的下降约 67%–77%。但需保留三条边界：

  1. 80 ms 是离散输出步长，平均 AAS 可以低于 80 ms，并不矛盾；平均误差不是单样本分辨率；
  2. MFA-labeled 与 human-labeled 结果不是同一种参考；
  3. 这些数字来自论文规定的语种、数据和 AAS，不能直接与使用不同 collar 的 precision/recall 比较。

6.4 优势与局限

优势

  • 单模型在论文实验中覆盖 10 种语言，并测试语码混合和最长 300 秒音频；
  • 不需要推理时的词典、G2P、trellis 或 DTW；
  • 用户可选择只预测某些词/字符边界；
  • NAR 并行填槽，长文本不产生自回归时间 token 幻觉。

局限

  • 训练需要大量边界标签或伪标签；教师的系统偏差可能被继承；
  • 固定 80 ms 离散类别限制了输出表示；
  • 语音与参考文本严重不一致时，模型仍需为每个槽位给答案；
  • 多语言泛化来自大规模预训练和训练数据，不能推断任意未覆盖语言同样可靠；
  • 槽位预测使用先前上下文，逐槽独立 argmax 也不天然证明全局单调，工程上仍应校验 $s_i\le e_i\le s_{i+1}$。

它适合多语言、长音频、高并发、文本已知且不想维护语言级词典/CTC 模型的场景。

7. 路线六：把时间写进生成序列——Timestamp Token

7.1 Whisper：生成的是 segment 时间，不是逐词时间

Whisper 把 0–30 秒量化为 1501 个 timestamp token：

训练序列把 caption/segment 起止时间穿插在文本两侧：

时间 token 与普通文本 token 一起接受自回归交叉熵监督。推理时，官方解码器通过 logits 规则限制时间单调、首个 timestamp 范围及成对结构；transcribe() 利用连续 timestamp token 切分 segment，并决定下一个 30 秒窗口从哪里继续。

这里的 20 ms 是标签量化网格和 encoder 步长，不等于 segment 边界误差只会有 20 ms。网页字幕弱标签、解码错误、长音频窗口推进和幻觉都可能造成更大偏差。

更重要的是：Whisper 原生 segment timestamp token 与上一节的 word-level attention + DTW 是两套机制——一个写入训练目标并由 decoder 生成，另一个在解码后读取 cross-attention 再对齐。

7.2 Canary：把每个词的起止时间都变成 token

Hu et al. 的 Word Level Timestamp Generation for Automatic Speech Recognition and Translation 先用 NFA 为训练集产生逐词伪标签，再把每个词表示为

具体实现采用 80 ms 网格、0–450 的特殊 token，覆盖最长 36 秒；<|timestamp|> 与 <|notimestamp|> prompt 控制是否输出时间。时间 token 和文本 token 一同由 Canary decoder 自回归生成。

论文在英语、德语、西班牙语和法语上用 8,877 小时 NFA 标注数据训练，timestamp 数据约占全部 ASR 训练数据的 15%。其正确判定要求词文本完全匹配，且 start/end 都落在 240 ms 以内：LibriSpeech test-other 的 precision/recall 为 93.7%/93.6%，起止绝对误差为 50/54 ms；四语种各测试条件的整体平均 precision/recall 为 89.3%/90.2%，起止误差为 55/66 ms。这些是相对于 NFA teacher 伪标签及特定 collar 的结果，不等价于相对人工词边界达到同样误差。

7.3 生成式时间 token 的性质

优势

  • 文本和时间使用统一 vocabulary 与 seq2seq 训练框架；
  • 无需推理后的 DTW/trellis；
  • 可以联合建模 ASR、翻译和字幕格式；
  • 时间历史能帮助后续 token 保持大体顺序。

局限

  • 文本错误与时间错误耦合，漏词意味着同时漏边界；
  • 逐词插两个时间 token 会显著拉长生成序列；
  • 自回归错误会累积，长音频可能慢或发生格式错误；
  • 时间 token 的 softmax 类别数随最大时长/分辨率增长；
  • 解码规则保证格式和单调，不保证时间贴合声学边界；
  • 仍需要逐词监督或 teacher 伪标签，不能只靠普通 ASR 文本自动获得。

Qwen3-ForcedAligner 与 Canary 的关键区别是：前者在已知文本中的 [time] 槽位并行分类，后者把时间作为自回归输出序列的一部分。两者都显式学习时间，但推理依赖和错误传播方式不同。

8. 路线七：利用 ASR 内部单调定位信号

8.1 CIF：把 encoder 权重积分到一次“发射”

Continuous Integrate-and-Fire（CIF）为每个 encoder frame 预测非负权重 $\alpha_t$，沿时间累积；当累积达到阈值 $\beta$（通常为 1）时触发一个输出单元。若阈值在帧 $t$ 内被跨越，该帧的权重会被拆分给前后两个 token，得到长度与文本接近的声学表示：

训练常加入 quantity loss，使总权重接近目标 token 数 $U$：

触发位置天然单调，可用作 token 的代表时间。Dong 与 Xu 的 CIF 论文也将 acoustic boundary positioning 作为能力之一。

但 fire time 表示“模型已积累足够证据产生 token”的时刻，不自动等于人工定义的 onset 或 offset。若要输出完整词区间，仍需把相邻 fire point 转为区间、聚合 subword，或额外预测 duration/boundary。

8.2 RNN-T：非 blank emission 所在 encoder 帧

RNN-T 在二维 lattice 上建模 $(t,u)$：$t$ 是声学帧，$u$ 是已输出标签数。blank 转移推进时间，non-blank 转移产生 token。最佳对齐路径上生成 $y_u$ 的时间索引

可直接作为 token 时间。若一个词由多个 subword 构成，可以用首个 subword emission 作为词首、末个 subword emission 或下一词 emission 估计词尾。

问题在于标准 RNN-T 只优化识别序列概率，同一文本可以对应许多发射路径。为了等待更多右侧声学证据，模型常延迟发射；因此 emission time 更像“何时决定输出”，而不是“语音何时开始”。代表改进包括：

  • 用传统 forced alignment 教师约束词发射时间；
  • 在 RNN-T loss 中惩罚延迟、鼓励接近参考帧的路径；
  • 联合预测 token 与 duration，如 Token-and-Duration Transducer；
  • 增加 start/end 或 duration 辅助头。

Xu et al. 的 Efficient Sequence Transduction by Jointly Predicting Tokens and Durations 让模型联合建模标签和 duration，减少逐帧 blank 解码；但 duration 的发射仍可能滞后，若目标是精确词首/词尾，需要专门时间监督与校准。

8.3 优势与局限

优势

  • 内部路径本来就随流式识别计算，附加延迟和资源小；
  • 定位天然单调，适合实时字幕、语音助手 endpointing 与关键词高亮；
  • 无需额外对齐模型或第二次前向。

局限

  • fire/emission 是决策位置，不是天然的声学边界；
  • look-ahead、chunk、right context 和 beam search 会改变发射延迟；
  • 一个 token 通常只给一个位置，完整 start/end 需要 heuristic 或 duration；
  • BPE 到词的聚合、停顿归属与 blank 分配仍然存在；
  • 若训练没有时间损失，同一识别结果的多条 alignment path 都可能近似最优。

这条路线适合流式系统已有 CIF/RNN-T，且目标是低开销近似时间或控制延迟。如果需要人工标注级边界，应增加时间教师、duration/boundary loss，并单独评估起止偏差。

9. 七条路线的统一对照

路线 时间监督/证据 推理核心 词典/额外模型 流式性 主要偏差

没有一条路线在所有条件下最优。更实用的选择是：

  • 音素研究、发音教学、精细语料标注：MFA/HMM 路线，保留 phone 边界与词典可解释性；
  • 已有参考文本、常见语言、离线批处理：CTC/NFA，或 WhisperX 的 ASR + CTC 解耦方案；
  • 已有 Whisper、部署依赖必须最少：官方 attention + DTW，但要做异常词和低置信度过滤；
  • 已有多语言 AED、只具备词级伪标签且不想维护 lexicon：TWAD 的词活动矩阵 + DTW；
  • 多语言、长音频、高并发 forced alignment：专门的 Qwen3-ForcedAligner 类 slot-filling 模型；
  • 统一 ASR/翻译/字幕输出格式：逐词 timestamp token，但接受序列长度和自回归耦合；
  • 实时字幕与语音助手：优先利用 RNN-T/CIF，再用延迟约束或 duration head 校准。

10. 工程上最容易踩的五个坑

10.1 把时间分辨率当成时间准确率

20 ms、40 ms 或 80 ms 描述的是 encoder stride 或离散类别网格。实际误差还包括监督标签噪声、模型偏置、对齐路径和分词误差。输出两位小数同样不构成 10 ms 精度。

10.2 把所有“Whisper 时间戳”混成一件事

  • Whisper segment timestamp token：训练目标的一部分，自回归生成；
  • Whisper 官方 word timestamp：cross-attention + DTW 后处理；
  • WhisperX word timestamp：独立 CTC forced alignment。

三者的监督、模型和误差来源都不同。

10.3 忽略“word”如何定义

英语可按空格聚合 BPE；中文、日文等必须说明是字符时间、token 时间还是外部分词后的词时间。标点、数字、emoji、缩写和前导空格都会改变边界。

10.4 只评估匹配词，却不报告 ASR 错误

若只在正确识别词上计算 MAE，模型可以通过删除困难词获得漂亮数字。完整报告应同时给 WER/CER、timestamp precision/recall，以及匹配词上的纯定位误差。

10.5 没有为文本失配设计失败模式

Forced alignment 假设参考文本与音频大致一致。生产系统至少应检测：

  • 大片段无法对齐；
  • 路径代价异常；
  • 相邻边界倒置或大量零时长词；
  • 过长词/过长 silence；
  • OOV 或 CTC tokenizer 无法映射字符；
  • VAD 分段切穿一个词。

“总能输出一组时间”不是可靠性的证明；恰恰相反，强约束搜索和 slot filling 都可能在输入错误时仍给出看似合法的边界。

11. 结论

Word Timing 的核心不是选择哪一个工具名，而是回答三个问题：

  1. 时间证据从哪里来？ HMM 状态、CTC 后验、attention、显式边界标签、时间 token，还是流式发射位置；
  2. 谁保证顺序？ 参考图、CTC trellis、DTW、decoder 历史、slot context，还是 transducer lattice；
  3. 谁定义“边界”？ 人工标注、MFA/NFA 教师、字幕 segment、模型触发点，还是工程 heuristic。

传统 MFA 把语言知识和搜索约束写得最显式；CTC 将流水线简化为帧后验与 trellis；attention-DTW 从大模型内部挖掘未经边界监督的软定位；TWAD 则用目标词 embedding 直接监督 frame × word 活动矩阵，再由 DTW 恢复单调词路径；Qwen3-ForcedAligner 把问题改写为并行时间槽填充；Whisper/Canary 把时间纳入生成词表；CIF/RNN-T 则直接复用识别过程的单调轨迹。

它们最终都能输出 [start, end]，但这些数字的统计含义并不相同。真正可靠的系统，应在目标语言、目标噪声、真实文本失配和人工边界上分别校准，而不是只依据模型名称或时间网格做选择。
