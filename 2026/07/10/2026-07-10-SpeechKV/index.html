Compress the Cache, Not the Speech Embedding: KV Compression for Efficient Speech LLMs

本文最后更新于 2026年8月18日 中午

为什么需要 SpeechKV？

Speech LLM 面临一个根本性的效率瓶颈：语音序列远长于文本。英语 ASR 中，一个文本 token 对应约 300ms 语音，而常见语音编码器每 80ms 产生一帧——同等语义信息下，语音序列长度约为文本的 4 倍。在自回归解码阶段，模型需在每一步 attend 所有前序位置，KV cache 的线性增长直接导致延迟和显存消耗随序列长度线性增长。

现有方案的标准做法是在 adapter 层对语音进行早期下采样（CTC blank filtering、CIF 累积、Q-Former 等），但这种”先压缩后推理”的范式引入了不可逆信息损失——一旦在 LLM 之前丢弃了细粒度声学细节，后续层便无法恢复。

SpeechKV 提出了一个优雅的替代思路：将压缩延迟到 LLM 内部，对中间层的语音 KV cache 施加学习式 pooling，让 LLM 自身决定保留哪些声学特征。

一、引言（Introduction）

LLM 在 NLP 任务中展现了卓越能力，研究者将其扩展到语音模态，形成 Speech LLM 家族。典型架构包含三个组件：预训练语音编码器 → 模态适配器 → LLM backbone。

核心挑战在于语音序列长度。以英语 ASR 为例，语音帧率约 80ms/帧，而文本 token 对应约 300ms，导致语音 KV cache 在解码阶段成为主要瓶颈。

作者的初步实验观察到：Speech LLM 在浅层自然地将相邻语音信息合并，在深层产生近重复表示。基于此观察，SpeechKV 在中间层对语音 KV 序列施加学习式 pooling，允许 LLM 学习保留哪些特征、如何融合语音与文本。

主要贡献：

  1. 提出 SpeechKV：在 Speech LLM 中间层对语音 KV cache 施加学习式 pooling 压缩
  2. 将语音压缩到文本级粒度仍维持 baseline 性能，同时获得 1.49–2× 解码加速
  3. 实证分析表明相邻语音表示在 LLM 层间逐渐变得冗余，为”在 LLM 内部压缩”提供理论动机

二、相关工作（Related Work）

2.1 Speech LLMs 与语音序列压缩

Speech LLM 采用 encoder–adapter–LLM 范式。核心挑战是弥合连续语音与离散文本之间的模态和长度差异。

现有预 LLM 压缩方案包括：

  • CTC-based：边界合并或 blank filtering
  • CIF-based：动态累积声学特征
  • Q-Former：提取固定数量的语音表示

这些方法引入瓶颈，导致后续 LLM 层无法恢复已丢弃的信息。

2.2 LLM 中的 KV Cache 压缩

KV cache 线性增长是长上下文 LLM 推理的已知瓶颈。现有方法分两大类：

  • Training-free：基于注意力统计或 recency 的 eviction（H2O、SnapKV、StreamingLLM），低比特量化（KVQuant）
  • Trainable：学习式合并或摘要上下文为更短的 KV cache（Dynamic Memory Compression 等）

Training-free 方法不可避免地存在 train-test mismatch。SpeechKV 属于 trainable 方案，联合训练消除此问题。

3.3 训练与推理

  • 训练阶段：SpeechKV 在前向传播中 on-the-fly 应用，与 next-token-prediction loss 联合优化，确保无 train-test mismatch。
  • 推理阶段：压缩在 prefill 阶段一次性完成，压缩后的 KV 存入 cache，在每个解码步实现 $R$ 倍语音 KV cache 缩减，直接转化为更小显存占用和更快解码速度。

5.2 逐层分析与消融实验

Local Similarity 分析：测量相邻语音位置间的 cosine similarity。

  • Baseline 在前 4 层急剧上升（模型主动聚合局部声学特征），约第 5 层进入平台期（局部聚合基本完成，时间冗余自然出现）。
  • SpeechKV(R=4) 的相似度曲线紧跟 baseline 自然上升趋势，说明压缩与模型本身的聚合行为一致。
  • SpeechKV(R=8) 相似度在所有层都被抬高，模型需重构表示以适应更激进压缩。

5.3 注意力分析

Baseline（左列）：

  • 浅层（Layer 4）：注意力弥散，模型仍在聚合局部声学特征
  • 深层（Layer 27）：出现清晰的单调对齐模式，但注意力分散在相邻近重复位置上

SpeechKV（右列）：

  • 浅层（Layer 4）：即使此层未施加压缩，已出现单调对齐——深层 KV 缩短迫使模型在更早层建立跨模态对应
  • 深层（Layer 27）：压缩后的 key 序列产生更尖锐、集中的注意力峰值，冗余位置已被合并

这表明 SpeechKV 重塑了层间表示：浅层更早建立跨模态对应，深层更高效地在去重复 key 表示上操作。

5.4 解码速度

30s 1.00× 1.49× 1.62×

加速随音频长度增长：语音 KV cache 在总注意力开销中占比更大时，压缩收益更显著。R=8 相比 R=4 仅有边际额外加速，因为 feed-forward 层和文本 KV cache 成为新瓶颈。

R=4 是最佳实践点：精度匹配 baseline，解码速度 1.49–2× 提升。

六、结论（Conclusion）

SpeechKV 将语音 KV cache 压缩延迟到 LLM 中间层，通过保留全分辨率 query 和 residual stream，让 LLM 预训练参数自行决定保留哪些声学特征。

在 71K 小时训练的 Qwen3-1.7B Speech LLM 上：

  • R=4 压缩到文本粒度仍匹配甚至超越 baseline（实体识别相对提升 6.6%）
  • 至少 1.49× 解码加速，随音频长度扩展
  • 注意力分析揭示 SpeechKV 作为结构性正则化：浅层更早建立跨模态对应，深层注意力更集中

未来方向：扩展到 ASR 之外的语音任务、研究自适应跨层压缩比、进一步分析 Speech LLM 的逐层动态。

个人思考

SpeechKV 的核心洞察极其简洁：语音在 LLM 浅层自然聚合后变得时间冗余，与其在 LLM 之前强制压缩（承担不可逆信息损失），不如让 LLM 先看完整信息再压缩 KV cache。这实际上是一种”先理解后摘要”的策略。

更令人意外的是 R=4 压缩不仅无损反而增益——压缩后粒度恰好对齐文本 token rate，形成对 LLM 预训练分布的结构性正则化。这暗示 Speech LLM 的一个深层问题：未压缩时，深层大量冗余 key 实际上是在”稀释”注意力。

从工程角度看，SpeechKV 的实现极为轻量（仅一个线性门 + softmax weighted sum），无需修改推理框架核心逻辑，与 vLLM 等系统的兼容性良好。这使其具有很强的实用部署价值。
