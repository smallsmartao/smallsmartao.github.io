攀岩专项力量训练：悬挂拉升 / 支撑下压 / 下肢爆发（三合一完整指南）

本文最后更新于 2026年7月1日 中午

本文整理自B站UP主「老午Joestar」的攀岩专项力量训练三部曲视频，涵盖悬挂拉升、支撑下压、下肢爆发三大核心能力板块。

为什么攀岩需要专项力量训练？

很多岩友觉得”多爬就行了”，但当你遇到以下瓶颈时，说明需要针对性的力量储备：

  • 爬升非常吃力，明明摸到了点却勾不住
  • 做几下拉升动作后就没力气
  • 支撑石块时怎么也撑不住
  • 动态出手时跳跃高度不够

攀岩的力量需求可以拆解为三个维度：悬挂与拉升、支撑与下压、下肢爆发与弹跳。下面逐一拆解训练方法。

Part 1：悬挂与拉升力量

引体向上是不够的——攀岩的拉升需要从指尖抓握开始，经过肩胛下压，最终完成全链条发力。

动作1：手指挂握训练

目标：前臂握力 + 指关节力量

  1. 用手指前半个指关节（开放式握法）勾住单杠
  2. 利用掌心握力将体重拉升，逐渐过渡为全握抓握
  3. 全程肩胛和躯干不主动发力，只用前臂肌群控制

要点：这个动作模拟的是攀岩中从开放手位到闭合抓握的过程，纯粹锻炼手指→前臂的抓握链条。

动作2：负重肩胛下压

目标：肩胛稳定性 + 核心舒张压 + 拉拽第一步

  1. 全握抓住杠铃杆
  2. 躯干收紧，头微前探
  3. 肩胛做上下运动，将负重拉起

负重越重越好，原因有三：

  • 锻炼抓握能力（重量本身就是握力挑战）
  • 为核心建立”舒张压”，让核心在攀岩中更稳定
  • 强化拉拽发力的第一步（肩胛启动），提升整体拉升力量

动作3：单手TRX/吊环奥氏引体

目标：单侧拉升力量 + 旋转控制

  1. 单手持吊环，放松肩胛，身体向外旋转，手臂打直完全伸展
  2. 躯干尽量水平于地面，另一只手向下够地面
  3. 肩胛后缩启动 → 背阔肌发力 → 水平方向拉至吊环贴胸
  4. 另一只手向上够，身体完成向另一侧的旋转

难度调节：吊环越高越简单，越矮越困难。

动作4：弹力带辅助单手引体

目标：突破单手引体的肌力瓶颈

  1. 弹力带穿过单杠，一只手攥住弹力带（攥越靠上越省力，越靠下越费力）
  2. 另一只手正握抓住单杠
  3. 以抓杠手为主发力完成引体，弹力带手辅助
  4. 重力尽量分配在拉单杠的那只手上

关键原则：不要刻意区分二头还是背阔发力——能拉上去就是胜利。用超负荷方法突破单手肌力极限。

Part 2：支撑与下压力量

攀岩不只是”拉”——当你需要撑住岩点、做mantle（翻越动作）、或者压石块时，支撑和下压力量决定成败。

动作1：负重双杠臂屈伸

目标：上肢推力 + 核心稳定

  1. 双臂向身体两侧尽量夹紧
  2. 身体保持卷曲状态，腹部完全收紧
  3. 尽量采用负重形式完成

攀岩关联：模拟mantle动作中从拉转推的过渡阶段。

动作2：单杠臂屈伸

目标：肘关节强度 + 前侧支撑模拟

相比双杠，单杠臂屈伸对肘的挑战更大，更能模拟攀岩中石头在身体前侧时的发力模式。

  • 同样保持膝盖收紧
  • 尽量选择负重
  • 肘向身体两侧弯曲

动作3：站姿腹肌轮（进阶）/ 跪姿腹肌轮（基础）

目标：上推 + 下拉协同 + 核心屈伸

站姿版（满级难度）：

  1. 站姿屈髋，手持腹肌轮
  2. 顺应重力迅速向下趴，至底端手臂在耳朵两侧，身体完全伸展
  3. 背和胸协同发力，将腹肌轮向回下压
  4. 屈髋重心上移，腹肌轮贴近双脚

跪姿版（入门）：减少了力臂，动作相对容易，同样要求趴到底端、手臂在耳侧、髋打直。

攀岩关联：同时训练推和拉的协同，核心屈伸能力对锁定、翻越至关重要。

辅助动作：倒握绳索三头下压

目标：抓握 + 下压协同

  1. 掌心包住绳索防滑柄，四指抠住形成抓握
  2. 在抓握状态下完成三头下压

攀岩关联：模拟手由屈到伸完成下压和支撑的动作模式，同时训练抓握能力。

Part 3：下肢爆发力

“攀岩练腿的都是狗？”——恰恰相反，下肢爆发力决定了你的动态出手高度和蹬踏效率。岩板上每只脚只有前脚掌是着力点，所以下肢训练必须围绕单腿发力和前脚掌蹬踏来设计。

动作1：垫高脚迈步上墙

目标：单腿蹬踏 + 上下肢协同

  1. 一只脚脚尖垫在障碍物上（模拟岩点高度）
  2. 双手持重物，快速伸髋
  3. 另一只脚抬起，前脚掌踩住前方墙面
  4. 重心向前压，同时提拉上推，一气呵成

要点：脚跟永远不落地，发力向前蹬的同时手臂完成提拉和上推。

动作2：后脚抬高分腿蹲（保加利亚蹲）

目标：单腿肌力储备

  1. 后腿抬高放在椅子/分腿器上
  2. 前脚做支撑，双手持重物完成下蹲
  3. 重心向前压

进阶版：前脚支撑腿的脚后跟抬起，重心压在前脚掌上——更贴近攀岩中的蹬踏模式。

注意：后脚只做平衡维持，不要把重心压在后腿。

动作3：增强式单腿跳箱 + 哑铃翻站

目标：骨盆倾斜状态下的单腿爆发

  1. 单腿快速落地
  2. 单腿发力蹬伸，另一只腿跳上跳箱
  3. 同时完成哑铃高翻（拉高质心）

攀岩关联：模拟身体贴近墙面时骨盆偏斜的状态下，单腿发力上蹬的场景。

动作4：助力动态跳（单杠辅助）

目标：快速蹬伸 + 上拉协同

  1. 双手抓单杠，髋打开，膝盖向两侧外展
  2. 前脚掌着地，身体处于中蹲位
  3. 快速蹬伸向上，上肢配合完成上拉
  4. 拉到杠铃杆到胸前，前脚掌落地

要点：

  • 膝盖始终向外展（否则攀岩时膝盖会磕墙）
  • 落地触地时间越短越好（训练反应力）
  • 不需要完成双离臂，只需尽量向上拉

训练编排建议

训练日 板块 核心动作 组×次
周二 拉升 手指挂握 + 负重肩胛下压 + 辅助单手引体 各3-4组×5-8次
周四 下肢 垫高迈步上墙 + 保加利亚蹲 + 单腿跳箱 各3-4组×6-8次/侧
周六 支撑 负重双杠臂屈伸 + 腹肌轮 + 绳索下压 各3-4组×6-10次

可根据个人攀岩日程灵活调整，避免力量训练和攀岩日冲突。

总结

攀岩力量不是”练引体+做俯卧撑”这么简单。三个维度缺一不可：

  1. 悬挂拉升：从指尖到肩胛的完整拉拽链条
  2. 支撑下压：翻越和压石块的关键能力
  3. 下肢爆发：动态出手和高效蹬踏的基础

把这三块融会贯通，你的攀岩表现会有质的飞跃。
