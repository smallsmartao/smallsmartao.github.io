JSTIP: Rethinking Speech-LLM Integration for ASR

本文最后更新于 2026年8月18日 下午

论文信息

  • 标题: Rethinking Speech-LLM Integration for ASR: Effective Joint Speech-Text Training by Interleaving
  • 作者: Ruchao Fan, Yiming Wang, Rui Zhao, Liliang Ren, Keqi Deng, Xiaoyang Chen, Ali Zare, Bo Ren, Yuxuan Hu, Junkun Chen, Yan Huang, Yelong Shen, Jinyu Li
  • 机构: Microsoft, USA
  • 链接: arXiv:2607.01733

一、WHY：问题的根源在哪里？

1.1 LLM预训练的文本先验为何在ASR中”失效”？

大语言模型（LLM）经由数万亿文本token预训练，天然具备强大的语言建模能力和广泛的世界知识。将LLM集成到语音系统中（Speech-LLM）的核心期望是：LLM的文本先验能弥补有监督ASR数据在稀有词、领域术语和长尾实体上的不足。然而，本文的核心观察揭示了一个尴尬的现实：

随着有监督ASR训练数据量的增加，LLM先验的贡献变得不再明显。ASR准确率主要由语音-文本监督信号主导，而实体识别的提升更多与ASR数据覆盖度相关，而非来自LLM先验。

更具体地说，在传统的Speech-LLM训练范式下：

  • ASR-only训练使解码器过度特化于语音条件下的解码，削弱了文本预训练阶段学到的生成式先验
  • 简单的语音-文本联合训练（即把文本数据混进来）虽然能改善文本侧的预测能力，但这些文本侧的收益无法有效迁移到语音条件下的ASR

本文用MMLU基准量化了这一”模态鸠沟”（modality gap）：ASR-only训练后，MMLU-S2T（语音到文本）仅为35.68%，而LLM本身的文本MMLU为78%。这意味着经过ASR适配后，模型在语音输入条件下几乎丧失了文本推理能力。

1.2 为什么简单的联合训练不够？

在decoder-only架构下，纳入文本数据训练非常简单——只需在语音编码器输入为零时送入文本batch即可。但实验证明（表I中 ASR+PubMed 行）：

  • MMLU-T2T从43.01%提升到64.1%（文本侧大幅改善）
  • MMLU-S2T仅从35.68%提升到43.77%（语音侧改善有限）
  • Medical-AVG EER仅从7.97%降至7.49%

根本原因：文本-only序列和语音-文本ASR序列的建模行为是割裂的。文本序列更新了LLM参数，但由于解码器在处理语音输入时的行为模式与处理文本输入时截然不同，文本侧的知识无法桥接到语音条件下。

二、WHAT：JSTIP的核心设计

2.1 核心思想：交错构造序列

JSTIP（Joint Speech-Text Interleaved Pre-Training）的核心洞察是：

如果我们想让解码器在语音输入条件下也能利用文本先验，就必须让它在训练时反复经历”在语音上下文之后预测文本”和”在文本上下文之后预测文本”这两种模式的交替。

具体做法：给定一个对齐的语音-文本对 $(A, T)$，首先获取词级或段级对齐信息 $(A, T) = {(A_1, T_1), (A_2, T_2), \ldots, (A_n, T_n)}$，然后构造交错序列，交替选取语音段和文本段：

  • 变体1: $(A_1, T_2, A_3, T_4, \ldots, T_n)$
  • 变体2: $(T_1, A_2, T_3, A_4, \ldots, T_n)$

两种变体中，序列的最后一段始终是文本，文本段作为训练目标。这使得同一个解码器在同一条训练样本中同时练习了”语音→文本”和”文本→文本”的预测，模态鸿沟在序列内部就被桥接了。


图1：传统Speech-LLM集成（左）与JSTIP联合语音-文本交错预训练（右）的框架对比。

2.2 词级交错（Word-Level Interleave）

词级交错以每个词为最小对齐单元：每个 $T_i$ 对应一个词，$A_i$ 对应其对齐的声学区域。构造的序列交替频率最高，且跳过了语音段和文本段之间的特殊token，强制实现更紧密的跨模态耦合。

工程挑战与解决方案：当使用连续语音token作为输入时，词级交错面临严重的计算效率问题——大量短声学片段如果独立送入语音编码器，会产生巨大的zero-padding开销并导致GPU OOM。解决方案：

  1. 在输入层将所有语音片段拼接为一个长序列
  2. 通过语音编码器和adapter前向计算后，再将输出放回原始的交错位置

这一策略使词级交错在大规模训练中变得可行。

  • 静音+标点（silence + punctuation）：同时利用文本标点信号切分

2.4 混合交错（Mixed-Level Interleave）

实验证明，将词级和段级交错混合使用效果最优——词级提供了ASR特定的细粒度跨模态耦合，段级提供了更强的模态鸿沟消除能力。

2.5 Loss Masking策略

所有训练格式统一使用交叉熵loss，但仅对文本token计算loss：

  • ASR-only：loss在转录token上
  • Text-only：loss在文本token上
  • 交错训练：loss在构造的交错序列中所有出现的文本token上
  • 语音位置始终被loss mask忽略
  • 特殊token仅作为任务/模态指示器，不参与loss计算

多个样本通过packed SFT打包到同一个8k上下文中，使用FlashAttention的cu_seqlens确保注意力在样本边界重置，无跨样本泄漏。

2.6 统一的训练目标

最终，ASR-only、段级交错、词级交错和text-only四种数据在统一的next-token prediction目标下共同训练。与传统ASR训练的公式 $P(t_i | A, t_{<i})$ 不同，JSTIP使模型暴露于如下分布：

三、实验设置

3.1 训练数据

数据类型 规模 说明
ASR数据 38k小时（~2.3B tokens） 匿名英文内部数据，token率12.5Hz
交错数据 2.3B tokens 基于38k ASR数据构造，与ASR数据量平衡
文本数据 2.3B tokens（PubMed）+ 0.1B tokens（TTS转录） 清洗后截断至8k上下文
合成领域ASR 9k小时 GPT生成医学实体密集转录 + 内部TTS合成音频

对齐方法：使用HMM-based混合ASR系统在38k小时数据上获取词级对齐。对齐失败的utterance被移除，未基于对齐置信度做额外过滤。

3.2 模型架构

组件 规格
语音编码器 400M参数 Conformer，时间下采样因子8
输入特征 80维log Mel filterbank，10ms帧移 → 有效80ms token率
LLM解码器 内部7B参数LLM，5T文本token预训练
Adapter ~20M参数轻量级投影层
上下文长度 8k tokens

3.3 两阶段训练

  • Stage 1：仅更新adapter参数，使用ASR数据稳定跨模态对齐。学习率 $1 \times 10^{-4}$，线性衰减，AdamW优化，覆盖总ASR tokens的10%
  • Stage 2：所有参数（编码器+adapter+LLM）联合优化。学习率 $4 \times 10^{-5}$，线性衰减，AdamW优化

3.4 评估体系

  • 通用ASR: Token Error Rate (TER)，含大小写和标点。两个测试集：conversation（自发短对话）、dictation（长篇听写）
  • 领域实体: Entity Error Rate (EER) = 1 − recall，在8个医学领域 + 1个银行领域评估。Medical-AVG含261条utterance/49.281小时，Banking含36条/5.567小时。EER在文本规范化前计算，格式、大小写、标点、拼写均被考量
  • 模态鸠沟量化: Speech版MMLU，5-shot，比较T2T与S2T的差异
  • 零样本SQA: LLaMA-QA、TriviaQA、WebQA子集，报告平均准确率

关键发现：

  1. 交错训练的纯净效果：仅加入交错数据（无额外文本），Medical-AVG EER从7.97%降至7.32%（相对提升8.2%），SQA-S2T从0.05%飙升至41.92%。这是因为交错序列保留了NTP行为。

  2. 模态鸠沟的量化证据：ASR-only后MMLU-S2T为35.68%，加入交错后升至51.77%，缩小了与T2T的差距。

  3. 文本数据+交错的协同效应：ASR+PubMed无交错时，MMLU-S2T仅43.77%；加入交错后跃至58.98%。说明交错是让文本知识迁移到语音侧的关键桥梁。

  4. 领域转录文本替代合成TTS：无交错时，TTS-transcription几乎无效（7.97%→7.85%）；有交错时，效果直逼合成TTS-pairs（6.81% vs 6.86%）。这大幅简化了领域适配——不再需要为每条文本合成语音。

  5. 最佳配置：JSTIP-Best-EER组合38k ASR + 交错 + TTS-Interleave + PubMed + TTS-transcription，Medical-AVG EER达6.60%，相比ASR-only的7.97%实现17.2%的相对提升。

关键发现：

  1. Word-IL：实体识别提升最大（7.97→7.64），但模态鸠沟消除能力较弱（Δ仅从-7.33缩至-6.89）

无交错时，仅有转录文本（不含合成音频）几乎无法改善ASR的实体识别（7.85% vs 基线7.97%）。加入交错后，纯转录文本的效果（6.81%）几乎追平合成TTS-pairs（6.86%）。这一结论具有重大工程意义：领域适配不再需要昂贵的TTS合成，只需领域转录文本即可。

五、零样本语音问答（SQA）作为机制诊断

SQA结果不是JSTIP的任务目标，而是作为诊断证据——验证交错训练确实保留了LLM的生成式先验：

  • ASR-only：SQA-S2T仅0.05%（LLM生成能力在语音侧几乎完全丧失）
  • +Interleave（无文本）：SQA-S2T达41.92%（生成能力恢复）
  • JSTIP-Best：SQA-S2T达42.07%

这说明交错训练使模型在语音输入下仍能执行开放式生成任务，而非仅限于转录。这正是实体识别提升的底层机制——模型保留了对实体知识的访问能力。

六、与先前工作的区分

JSTIP与现有工作的三个核心区别：

  1. 目标不同：将交错视为保留和迁移LLM先验到ASR的机制，而非通用多模态数据配方
  2. 场景不同：聚焦于大规模有监督数据场景（38k小时），在这种条件下传统ASR适配已经学到了很强的语音-文本映射，LLM先验的价值最难体现
  3. 粒度不同：隔离了构造粒度（词级 vs 段级）对模态鸠沟和实体识别的影响，包括一个针对连续语音表示的可扩展词级交错实现

与Spirit-LM（离散语音token）和Xie et al.（段级行为模仿）不同，JSTIP处理的是连续语音表示下的decoder-only ASR，且直接分析实体识别和模态鸠沟。

七、局限性

  1. 内部数据和模型：主要训练数据、领域评估集和骨干组件均为内部资源，结论应解读为受控系统内的一致性改进
  2. 对齐质量依赖：词级交错对对齐边界误差敏感；对替代对齐器（如CTC对齐）的鲁棒性留待未来研究
  3. LLM规模：使用7B LLM，在Medical上仍弱于Qwen-30BA3B和Voxtral-24B等更大模型
  4. 确定性交替：当前使用确定性交替策略，随机或基于词类型的自适应模态选择未探索

八、总结

JSTIP揭示了一个重要且被忽视的问题：在大规模有监督ASR数据下，传统Speech-LLM训练使LLM的文本先验变得”不可达”——不是因为先验不存在，而是因为模态鸠沟阻断了访问路径。交错预训练通过在训练序列内部交替呈现语音和文本上下文，让同一个解码器持续练习”跨模态之后预测文本”的能力，从而将这条路径重新打通。其工程启示同样重要：领域适配不再需要合成语音，仅需转录文本即可通过交错机制注入领域知识。
