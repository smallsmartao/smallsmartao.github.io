力量、肌肉、耐力到底怎么练？从训练科学重新理解身体进步

本文最后更新于 2026年5月23日 凌晨

本文整理自 B 站视频播客《自然之路》——力量、肌肉、耐力到底怎么练？，作者 Elijah 是一名体能教练、壶铃世界冠军，现居新西兰奥克兰。

核心观点

“很多人没有在训练，而是在制造疲劳。”

  • 累 ≠ 有效
  • 酸 ≠ 进步
  • 流汗 ≠ 训练质量高
  • 动作多 ≠ 计划好
  • 练到崩溃 ≠ 身体一定会适应

真正有效的训练是给身体一个明确的信号：我到底要变得更强？肌肉更大？跑得更久？爆发力更快？

一、训练的本质：刺激 + 恢复 = 适应

训练本质上是：给身体一个刺激，然后让身体通过恢复产生适应。

训练当下你在做的事情是——消耗能量、制造疲劳、打破平衡。真正的进步发生在训练之后：饮食、睡觉、补水、恢复，身体开始适应。

身体的逻辑是：

“下次如果还遇到这样的压力，我要准备得更好。”

于是你变强了、肌肉变大了、心肺提升了、技术更稳定了。

两个部分缺一不可

只有刺激没有恢复 只有恢复没有刺激
结果 过度疲劳 没有进步

很多人最大的问题：只迷恋刺激，不尊重恢复。

好的训练是有节奏的

  • 有时候提高强度
  • 有时候提高训练量
  • 有时候提升技术
  • 有时候提高恢复
  • 有时候测试评估
  • 有时候甚至退一步，让身体吸收训练成果

训练的目的不是破坏身体，而是通过合理的刺激，让身体更好地适应。

二、力量、增肌、耐力——三种不同的训练适应

1. 力量训练

定义：产生最大的力。深蹲多少公斤、硬拉多少公斤、能推多少壶铃。

力量不只是肌肉大小的问题，还取决于：

  1. 肌肉本身的横截面积
  2. 神经系统征募肌纤维的能力
  3. 动作技术
  4. 关节角度和身体结构
  5. 心理状态和发力意愿

一个很有力量的人不一定肌肉很大。

例子：作者跟一个 IFBB Pro（职业健美选手）训练背部，80% 的重量都能跟上，但那人比他大一圈多。另一个力量举朋友卧推 140kg 做组，但 32kg 壶铃推举一个都推不起来——因为没学过动作技术。

力量训练的关键词

关键词 说明
高质量 每一次动作质量都要非常高
高强度低次数 每组 1-5 次（甚至 1-3 次）
长休息 组间 2-5 分钟（ATP 恢复到 90%）
动作稳定 重量大，动作不能变形

常见安排：3-5 组 × 3-5 次。

力量训练不会让你满头大汗，但它对神经系统和力量的提升非常有效。力量训练不是把自己练到很累，而是让身体在关键时候能够产出更大、更高质量的输出。

2. 增肌训练（肌肥大）

定义：让肌肉体积增加、肌纤维变粗。

增肌和力量有关但不完全一样。力量训练更像训练神经系统的高输出能力，增肌训练更像给肌肉足够的局部刺激。

增肌训练的特点

特点 说明
中等到较高次数 6-12 次（15-20 次也可以）
接近力竭 每组接近做不动
训练量更高 总组数 × 次数较多
离心控制重要 慢速离心，更多刺激肌肉
目标肌肉感知 念动一致，知道在练哪里
休息时间相对短 维持肌肉持续张力

增肌训练的关键词

  1. 张力 — 目标肌肉有没有承受足够的机械张力
  2. 训练量 — 有没有积累到足够的有效次数
  3. 接近力竭 — 有没有接近有效刺激
  4. 目标肌肉感知 — 做动作知道在练哪里（很多健美选手的差距就在这里）
  5. 恢复和营养 — 有没有吃够、睡够

很多人增肌失败：以为练了胸，结果肩膀和手臂一直在带偿；以为练了背，但手臂拉得很累。

3. 耐力训练

耐力不只是跑步，有非常多种类：

  • 心肺耐力
  • 肌肉耐力
  • 有氧耐力 / 无氧耐力
  • 长时间低强度耐力
  • 专项耐力

不同运动的耐力完全不同：马拉松 vs 壶铃长循环 vs 足球 vs CrossFit。

壶铃长循环 10 分钟需要的是：技术耐力、握力耐力、肩带耐力、下肢反复蹬伸、呼吸节奏、心肺能力、心理韧性、动作效率。

长距离跑步需要的是：心肺系统、有氧代谢、步频节奏、跑步经济性、能量供应。

耐力训练的关键词

能量系统、节奏、呼吸、专项性、持续输出的能力。

三、为什么很多人训练多年没有进步？

原因一：目标太模糊

“我想练的好一点”——什么叫好一点？力量更强？肌肉更大？体脂更低？跑得更久？

如果你没有目标，训练就会很随机。今天看别人练胸就练胸，看别人跑步就跑步，看别人练壶铃就练壶铃——很难形成系统性进步。

建议：训练之前问自己——接下来 8-12 周想提升什么？只选 1-2 个重点。

原因二：没有渐进超负荷

渐进超负荷是训练进步最核心的原则之一：让身体逐步面对更高的要求。

但”更高要求”不只是加重量！ 提升强度的方式有很多：

  1. 增加重量
  2. 增加次数
  3. 增加组数
  4. 动作质量提高
  5. 休息时间缩短
  6. 动作幅度增加
  7. 节奏控制更好
  8. 同样重量完成得更轻松
  9. 同样时间做更高质量的输出

没有记录就很难管理进步。

作者从 2017 年第一次学壶铃开始，每一堂训练计划都记录在一个小本上——组数、次数、完成情况、感受，至今已经用了三四本。

原因三：只追求疲劳，不追求质量

“一节课什么都有：跑步、波比跳、壶铃摇摆、俯卧撑、跳箱、划船、平板支撑……练完非常累，但你问自己今天的训练目标主要是什么？不知道。”

这种课变成了消耗课。消耗课不是完全不好（出汗、释放压力、多巴胺），但如果你想长期进步，不能每次训练只是消耗。

应该是：今天就练力量 / 今天就练技术 / 今天就做有氧基础 / 今天做乳酸耐受训练 / 今天练活动度稳定性。

原因四：恢复跟不上

很多人不是练得太少，是恢复太差：

  • 睡眠不足
  • 压力太大
  • 蛋白质不够（每公斤体重 1.5-2.0g）
  • 总热量太低
  • 水分不足 / 电解质不够
  • 训练安排太紧密

恢复不是偷懒，而是训练的一部分。

原因五：没有长期周期训练计划

太短视——今天想练力量，明天想减脂，后天想跑马拉松，又想比 Hyrox，又想玩 CrossFit。

一个成熟的训练目标至少要给 8-12 周：

  • 想提升力量 → 8-12 周专注力量训练
  • 想增肌 → 8-12 周专注训练量和营养
  • 提升心肺 → 8-12 周只专注建立有氧基础

真正让你进步的不是新奇的动作，而是基础动作被长期高质量的重复。

作者从 2016 年开始练壶铃到 2026 年，十年时间，主要就练长循环和挺举两个动作。

四、壶铃训练如何对应力量、增肌、耐力

壶铃练力量

  • 双壶铃前蹲（下肢 + 核心）
  • 军事推举（上肢力量）
  • 负重壶铃引体向上
  • Heavy Clean（48kg、36kg 做高翻）
  • 重壶铃摇摆（48kg）

壶铃练增肌

  • 高脚杯深蹲
  • 双壶铃深蹲
  • 高翻和推举
  • 壶铃划船
  • 壶铃分腿蹲
  • 壶铃 RDL（罗马尼亚硬拉，单腿/双腿）

如果真的想增肌，固定器械可能效率更高，但前提是要有好的关节活动度。

壶铃练耐力

  • 间歇壶铃摇摆
  • 壶铃抓举（做组）
  • 壶铃长循环（高翻 + 挺举）
  • 壶铃 Flow（复杂动作串联，5-10 分钟）

壶铃的耐力不是乱甩。技术效率要求更高——技术不好，做得越多代偿越多。

最高级的耐力不是一直用力，而是知道什么时候用力，什么时候放松。

五、训练之外：决定进步的 23 小时

你每天训练可能只有 1 小时，另外 23 小时——怎么吃、怎么睡、怎么面对压力——都影响训练结果。

1. 睡眠

可能是最重要的恢复工具。长期睡不好 → 力量、增肌、耐力、学习能力、情绪管理全部受影响。

问自己：每天睡几小时？睡醒后有没有恢复感？晚上是不是太晚玩手机？

2. 营养

目标 营养重点
增肌 蛋白质吃够 + 总热量要够
减脂 热量有控制，但不能低到影响训练和恢复
耐力 碳水和水分充分 + 电解质

很多人训练表现差，不是意志力差，而是吃得不对。

3. 水分和电解质

脱水会影响力量、心率、耐力和注意力。把每天入嘴的液体都换成水，身体健康指数就会增加很多。

“你不是易胖体质，你是每天吃了炸鸡汉堡薯条，还以为自己只喝了水的健忘体质。”

4. 压力

如果工作压力大、睡眠不好、精神紧绷，身体一直处在高压状态——这时候每天高强度训练，身体吃不消。

训练计划要考虑你的生活压力。好教练看的不只是动作质量，而是这个人的生活状态。

六、普通人最应该记住的训练原则

  1. 先明确目标，再选择训练方法 — 不要问”练什么动作”，先问”我要什么结果”
  2. 不要把疲劳当成训练效果 — 累只是身体反应，不是训练质量的证明
  3. 渐进超负荷是进步的基础 — 无论力量、肌肉还是耐力，都需要逐步提高要求
  4. 技术质量永远最重要 — 动作不好，强度越高问题越大
  5. 恢复决定你能不能吸收训练 — 睡眠、营养、水分、压力管理缺一不可
  6. 训练要长期主义 — 不要三天换一个目标，给身体时间适应

七、实用训练方案

方案一：每周三练（适合时间少的人）

日 内容
周一 全身力量训练 — 高脚杯深蹲、俯卧撑/卧推、划船、罗马尼亚硬拉、农夫行走。每个动作 3-4 组 × 5-10 次
周三 有氧 + 活动度 — 30-45 分钟 Zone 2 有氧（快走/慢跑/骑车/划船）+ 足踝、髋、胸椎、肩关节活动度训练
周五 壶铃/功能性训练 — 壶铃摇摆、高翻、推举、深蹲、农夫行走、平板支撑。重点是力量、心肺和动作协调结合

方案二：每周四练（想进步更快的人）

日 内容
周一 上肢力量 + 核心 — 推、拉、肩胛稳定、核心抗旋转
周二 下肢力量 + 髋主导 — 深蹲、硬拉、弓步、臀腿、搬运
周四 有氧耐力 — 30-60 分钟低强度有氧
周六 壶铃/CrossFit/Hyrox — 力量耐力、全身协调、心肺整合（灵活选择）

方案三：每周五-六练（教练/深度运动爱好者）

日 内容
周一 最大力量
周二 Zone 2 有氧 + 活动度
周三 肌肥大 + 辅助力量（小肌群）
周五 爆发力 + 壶铃技术
周六 专项耐力 + 间歇训练
周日 休息、散步、拉伸、复盘

八、如果我是你的教练：12 周基础周期

第 1-4 周：建立动作质量

  • 学会深蹲、硬拉、推、拉、核心控制、呼吸
  • 学会正确的有氧运动姿态（跑步、划船、骑车）
  • 不追求重量，先把身体唤醒

第 5-8 周：增加训练量

  • 动作更稳定
  • 逐渐增加组数、次数和重量
  • 力量训练每周 2-3 次
  • 有氧训练每周 1 次
  • 保持每天走路，增加日常消耗
  • 让身体适应稳定的训练节奏

第 9-12 周：提高强度和专项目标

  • 想变强 → 提升重量
  • 想增肌 → 提升训练量 + 接近力竭
  • 想提升耐力 → 增加有氧时间和间歇训练
  • 想练壶铃 → 加入专项技术和节奏训练

12 周之后做测试，不要每天都测自己——训练是积累，不是每天的考试。

九、如何判断训练有没有效果？

不要只看体重！从以下角度判断：

1. 力量有没有提升

  • 同样动作能用更大重量？
  • 同样重量能做更多次？
  • 同样次数动作更稳定？

2. 肌肉有没有变化

  • 维度有没有增加？
  • 身体线条有没有变化？
  • 目标肌肉感知有没有变好？
  • 训练后恢复有没有变快？

3. 耐力有没有提升

  • 同样速度下心率更低？
  • 同样心率下速度更快？
  • 训练后恢复更快？
  • 高强度动作转换更顺畅？

4. 动作质量有没有提升

  • 深蹲更稳定？硬拉更清晰？
  • 推举时腰腹没有代偿？
  • 跑步落地更轻松？
  • 壶铃高翻不打手腕了？

5. 生活状态有没有变好（最重要）

  • 睡得更好？情绪更稳定？压力更小？
  • 身体疼痛更少？更愿意活动？
  • 更喜欢自己的身体？更关心自己的身体？

如果训练让你变得非常累、非常焦虑、越来越怕训练——可能需要调整了。

一个好的训练不应该只制造一个更强的身体，它应该帮助你建立更稳定的生活。

总结

“训练不是随机制造疲劳，而是根据目标给身体明确的刺激，再通过恢复完成适应。”

目标 关注什么
提高力量 高质量输出、神经系统、重量、技术、休息
增加肌肉 训练量、肌肉张力、接近力竭、营养和恢复
提升耐力 能量系统、呼吸节奏、专项安排、持续输出

无论练什么都离不开：目标清晰 → 渐进超负荷 → 动作质量 → 恢复管理 → 长期坚持

“你不是在完成训练，你是在理解训练。而这才是真正的身体教育。”
