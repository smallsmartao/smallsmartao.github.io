Contextual Biasing for ASR in Speech LLM with Common Word Cues and Bias Word Position Prediction

本文最后更新于 2026年4月16日 上午

论文链接：arXiv:2604.12398
作者：Sashi Novitasari, Takashi Fukuda, Gakuto Kurata, George Saon (IBM Research)

摘要

语音感知大语言模型（Speech-aware LLMs, SLLMs）近期在自动语音识别（ASR）任务上取得了最先进的性能，但在转录训练数据中稀少或从未出现过的偏置词（bias words）时仍然存在显著困难。现有的上下文偏置（contextual biasing）机制通常通过文本提示或附加模块将预定义的偏置词列表引入模型，并可辅以 G2P（grapheme-to-phoneme）系统生成的音素表示作为发音线索。然而，当兼容的 G2P 系统不可用时，基于音素的上下文偏置难以施行；手动添加精确的音素序列又要求用户具备高级语音学知识。

本文提出了一种基于常见词（common words）的声学线索方法：利用发音与目标偏置词部分相似的常见词序列作为偏置词的发音提示（例如，”Shelley” → “sheriff, legal”）。此外，作者引入了一种偏置词位置预测（bias word position prediction）的多输出训练机制，以增强模型的鲁棒性。该方法相较于基线系统将偏置词识别错误率降低了 16.3%，在域外数据上同样有效。

1. 引言（Introduction）

ASR 技术在近年来取得了飞速发展，尤其是将语音能力集成到大语言模型中的 SLLM 框架 [1–4]，凭借其模块化设计和卓越性能受到广泛关注。这类框架通过为文本 LLM 配备语音编码器，使其能够处理基于音频的任务，同时保留核心的文本处理能力。

然而，端到端 ASR 建模在 SLLM 中仍面临偏置词转录的挑战。偏置词是训练数据中代表性不足的词（即稀有词或未见词），由于训练样本有限，这些词可能被删除或被替换为发音相似但出现频率更高的其他词。

在非 LLM ASR 系统中，上下文偏置机制通过将预定义的偏置词列表深度融合到 ASR 模型中来准确转录偏置词 [5–7]。在 SLLM 研究中，基于提示的上下文 ASR 方法 [8–11] 通过将偏置列表纳入文本提示与任务指令一起输入，利用 SLLM 的文本模块直接处理偏置列表，而无需额外的偏置编码器模块。为处理长偏置列表，先前的研究还提出了列表剪枝方法 [12, 13]。

尽管上下文偏置增强了模型的 ASR 能力，但对于拼写或发音不寻常的词仍会出现错误。此前的研究 [14–16] 通过在推理前使用 G2P 系统生成音素作为发音提示来辅助解码。然而，基于音素的系统在实际场景中面临以下挑战：

  1. G2P 系统的领域/语言覆盖有限：典型的 G2P 系统通常针对特定领域、语言和音素格式设计，当目标偏置词超出其覆盖范围时便无法适用；
  2. 手动添加发音需要语言学专业知识：对于基于词典的 G2P 系统，用户必须手动为新偏置词添加发音条目，但准确的发音标注需要罕见的语音学专业知识；
  3. 系统复杂度增加：集成任何类型的 G2P 系统（包括基于神经网络的系统）都会增加推理阶段的系统复杂度，在低资源场景下尤其不可取。

本文的核心思想是：不使用直接的音素表示，而是利用与偏置词发音部分相似的常见词（common words / non-bias words）作为发音线索。常见词频繁出现在大规模训练数据中，因此 SLLM 对其发音具有充分的知识，使其可作为偏置词的发音参考。所提出的线索可以手动生成或通过简单编程生成，无需任何高级语音学知识。

本文贡献

  1. 提出基于常见词的词级线索（word-level cues）作为偏置词的发音提示，具有高适用性；
  2. 展示基于音素（发音）和结构（拼写）相似性的词级线索选择方法；
  3. 应用带有偏置词位置预测机制的 SLLM 多输出训练框架，提升模型泛化性能。

2. 相关工作（Related Work）

虽然本文未单独设立 Related Work 章节，但在引言部分详细回顾了上下文偏置领域的相关方法，涵盖了从传统 ASR 系统到 LLM 时代的多种偏置技术。以下按类别系统梳理：

2.1 传统深度融合方法

在非 LLM 的端到端 ASR 系统中，上下文偏置通常通过将预定义偏置词列表深度融合（deep fusion）到模型内部来实现：

  • Contextual RNN-T [5]（Jain et al., Interspeech 2020）：在 RNN-Transducer 框架中引入上下文偏置机制，通过注意力机制将偏置词列表的信息融合到解码过程中，用于开放域 ASR；
  • Guided Attention for Contextual Biasing [6]（Tang et al., ICASSP 2024）：提出引导注意力（guided attention）机制改进 ASR 上下文偏置，通过显式引导模型关注偏置词列表中的相关条目；
  • Adaptive Context Biasing [7]（Yolwas et al., Scientific Reports 2025）：在基于 Transformer 的 ASR 系统中实现自适应上下文偏置，动态调整偏置强度。

2.2 基于提示的 SLLM 上下文偏置方法

随着 SLLM 的兴起，研究者开始利用文本提示将偏置词列表直接纳入 LLM 的输入：

  • Contextual Biasing of Named-Entities with LLMs [8]（Sun et al., ICASSP 2024）：将命名实体偏置词列表通过文本提示引入 LLM，使模型在解码时偏向于正确转录这些实体；
  • Contextual Biasing in Speech-Enhanced LLM [9]（Gong et al., Interspeech 2024）：在语音增强的 LLM 中实现上下文偏置语音识别；
  • CTC-assisted LLM-based Contextual ASR [10]（Yang et al., SLT 2024）：结合 CTC 辅助机制与 LLM 的上下文 ASR 方法；
  • CMT-LLM [11]（He et al., Interspeech 2025）：面向多说话人场景的上下文 ASR，利用 LLM 处理多说话人语音中的偏置词。

2.3 偏置列表剪枝方法

当偏置词列表过长时，直接将全部词汇纳入提示会导致效率和准确性下降，因此研究者提出了列表剪枝策略：

  • BR-ASR [12]（Gong et al., Interspeech 2025）：提出高效且可扩展的偏置检索框架，在语音 LLM 的上下文偏置 ASR 中实现偏置列表的有效筛选；
  • Ranking and Selection of Bias Words [13]（Hou et al., Interspeech 2025）：对偏置词进行排序和选择，仅保留最相关的偏置词用于上下文语音识别。

2.4 音素辅助的上下文偏置方法

为处理拼写或发音不寻常的偏置词，研究者提出利用音素信息作为辅助线索：

  • PROCTER [14]（Pandey et al., ICASSP 2023）：发音感知的上下文适配器（Pronunciation-aware Contextual Adapter），在神经转录器中为个性化语音识别引入发音信息；
  • Phoneme Features for Deep Biasing [15]（Qiu et al., ASRU 2023）：在流式转录器的大规模深度偏置中引入音素特征和纯文本数据，改进偏置词的识别；
  • PARCO [16]（He et al., arXiv 2025）：音素增强的鲁棒上下文 ASR（Phoneme-Augmented Robust Contextual ASR），通过对比实体消歧实现更准确的偏置词识别。

本文的方法与上述音素辅助方法的关键区别在于：不依赖 G2P 系统生成音素序列，而是用常见英语词汇作为发音线索，从根本上消除了对 G2P 系统的依赖，降低了用户使用门槛和系统复杂度。

3. 方法论（Methodology）

3.1 基于文本提示的上下文偏置

模型采用文本提示的方式实现上下文偏置。输入由三部分组成：

  • 语音音频 $S = [s_1, s_2, \ldots, s_I]$，包含 $I$ 帧
  • 文本任务指令 $X = [x_1, x_2, \ldots, x_J]$，包含 $J$ 个词（如 “Transcribe this speech”）
  • 偏置词列表 $B = [b_1, b_2, \ldots, b_K]$，包含 $K$ 个偏置词

$X$ 和 $B$ 被拼接为单一文本后输入 SLLM。模型输出为语音转录 $T = [t_1, t_2, \ldots, t_L]$，包含 $L$ 个词，其中 $0 \leq |B \cap T| \leq L$ 个词来自偏置列表。整体操作可表示为：

3.2 基于常见词线索的上下文偏置（核心创新）

音素线索通过文本提示提供给 SLLM，与偏置列表 $B$ 中的相应偏置词配对。作者探索了以下几种线索选择准则：

3.2.1 基于音节的部分音素匹配（Syllable-based Partial Phonetic Match）

核心思想是：为每个偏置词找到一组常见词，使这些常见词的首音节依次发音时近似于目标偏置词。

对于一个包含 $M$ 个音节的偏置词 $b_k = [sb_{k1}, \ldots, sb_{kM}]$，将其与 $M$ 个提示词 $H_k = [h_{k1}, \ldots, h_{kM}]$ 配对。第 $m$ 个提示词 $h_{km}$ 由 $R$ 个音节组成（$h_{km} = [s_{km1}, \ldots, s_{kmR}]$），其首音节 $s_{km1}$ 与 $b_k$ 的第 $m$ 个音节 $sb_{km}$ 具有相同或相似的音素序列。

例如：偏置词 “Gallian”（三个音节）→ 提示词 “gather, leave, under”（三个词的首音节分别近似 “Gal-“, “li-“, “an”）。

提示词选择流程（两步）：

  1. 从常见词列表中检索所有首音节音素序列与目标音节相似的候选词；
  2. 从候选词中选择最终提示词，选择策略包括：
    • 最小字符级编辑距离（CED）：选择与目标偏置词拼写最相似的词，在训练和推理时使用；
    • 随机选择：模拟用户手动提供的多样化输入，仅在推理时用于评估鲁棒性。

3.2.2 音素元音匹配（Phonetic Vowel Match）

偏置词的线索由一组构成与目标词相似元音模式的词序列组成。例如，偏置词 “Shelley” 可与提示词 “healthy” 配对，因为二者共享相同的元音序列 “EH-IY”。

选择元音匹配的理由是：元音在决定词汇发音中起着核心作用。

形式化地，偏置词 $b_k$ 与词序列 $H_k = [h_{k1}, \ldots, h_{kU}]$（$U$ 个词）配对。当存在与目标词元音完全匹配的常见词时，$U = 1$；否则 $H_k$ 将扩展为多个词以匹配目标元音序列。

3.2.3 最小字符级与音素级编辑距离（Closest CED + PED）

不依赖音节匹配，直接从常见词中选择与偏置词 $b_k$ 字符级编辑距离（CED）最小的词 $h_k$ 作为线索。当多个候选词具有相同的最小 CED 时：

  • 训练时：进一步按音素级编辑距离（PED）选择最相似的词；
  • 推理时：也探索从 CED 最小的候选词中随机选择。

4. 实验设置

4.1 模型

采用 Granite-Speech [4] 架构作为 SLLM 骨干网络，包含：

  • 语音编码器：Conformer-CTC 结构，10 个 Conformer 块，经过字符级 ASR 任务预训练
  • 投影器：Q-former [18]，将语音编码器输出下采样并投影到 LLM 嵌入空间
  • 文本 LLM：granite-3.3-8b-instruct

通过后训练（post-training）机制在 ASR 数据集上使用上下文 ASR 提示微调模型，训练 3 个 epoch，学习率 5e-6。仅更新 Q-former 和 LLM 关联的 LoRA [19] 参数。

偏置词标注器采用 FNN 层：音节或元音线索模型使用 9 层，CED+PED 线索模型使用 11 层。

4.2 数据集

初始实验（评估偏置词线索）：仅使用 Librispeech [20]。

完整实验（评估完整流水线）：训练集包括 Librispeech、CommonVoice 17.0 [21]、Voicemail [22]、AMI [23]、VoxPopuli [24]。

评估：

  • 域内：CommonVoice 17.0
  • 域外：SPGI [25]（金融音频）、Gigaspeech [26]（多领域）

偏置列表通过命名实体标注器从语音转录中自动提取。训练时偏置列表大小随机设定为 1–200 词；推理时使用 10 或 200 词的列表。

测试数据统计：

常见词列表使用 MIT 10K 词表构建（排除目标偏置词）。音素转换使用手动标注词典和公开的 SoundChoice G2P 模型 [27, 28]。

关键发现：

  1. 所有提出的模型相较于基线（#2）均显著降低了 B-WER，最高达 24.1%（B-WER 从 5.8% 降至 4.4%），缩小了与使用音素的 oracle 模型（#3）之间的差距。
  2. CED+PED 方法表现最佳：这可能是因为其线索仅由单个词组成，比其他方法（词序列）更简洁，便于 SLLM 处理。
  3. Phon.vow+CED 在短偏置列表（10 词）上取得最低 B-WER，但在长列表（200 词）上表现不如 CED+PED，可能是因为干扰词也被配对了相似的元音提示词，导致模型混淆。
  4. 所有模型在使用随机选择策略替代编辑距离选择时依然表现稳健，表明系统对用户输入具有良好的容错性。

多输出训练方法将上下文 ASR 的 B-WER 改善了最高 8.4%，证明偏置词位置预测辅助任务增强了 SLLM 将语音中的偏置词与文本提示中的线索相关联的能力。

6. 结论

本文提出了面向 SLLM 的上下文 ASR 方法，包含两个核心创新：

  1. 常见词声学线索：利用与偏置词发音部分相似的常见词作为发音提示，摆脱对 G2P 系统的依赖，降低用户使用门槛；
  2. 多输出训练与偏置词位置预测：通过 CTC 损失优化的辅助标注任务，增强模型对偏置词的识别和泛化能力，且不增加推理阶段的计算开销。

实验结果表明，所提方法在多个 ASR 任务和数据集（包括域外数据）上均取得了一致的性能提升，支持构建鲁棒且通用的 ASR 系统。
