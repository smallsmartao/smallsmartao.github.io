Speech LLMs are Contextual Reasoning Transcribers

本文最后更新于 2026年4月8日 下午

论文：Speech LLMs are Contextual Reasoning Transcribers
作者：Keqi Deng, Ruchao Fan, Bo Ren, Yiming Wang, Jinyu Li（微软 Core AI）
arXiv：2604.00610 | 2026-04-01

1. 背景与动机

1.1 LLM-based ASR 的主流范式

随着大语言模型（LLM）在文本任务上取得显著突破，学术界与工业界开始广泛探索将 LLM 的能力迁移至语音任务。在 LLM-based ASR 的主流范式中，做法通常是：将语音编码器输出（speech encoder output）作为 soft prompt 前缀，拼接在文本 prompt 之前，然后让 LLM 执行 next-token prediction 生成转录文本。这一范式有两个代表性的变体：

  1. 离散语音 Token 扩充词表（如 AudioLM、SpeechGPT）：将语音转化为离散 token，扩充 LLM 词表后联合训练；
  2. 连续语音表示作为 soft prompt（如 Qwen-Audio、SALMONN、Phi-4-MultiModal）：用线性映射或 Q-former 将语音 encoder 输出对齐到 LLM 隐空间，再作为 prompt 传入。

本文聚焦第二类范式，并指出该范式目前存在一个根本性问题：LLM 在 ASR 任务中实际上被限制在「转述模式」（reproducing/refining mode），其强大的生成能力和推理能力未得到充分利用。

1.2 核心痛点：ASR 是内容保全映射

语音识别（ASR）在信息论上本质是一种嘈声源-通道模型（noisy source-channel formulation）：语音和转录文本承载几乎相同的内容，ASR 所做的是 content-preserving mapping，而非真正的语义转换。这与机器翻译、问答等任务截然不同——后者需要大量的语义推断与知识运用。

因此，当前 LLM-based ASR 系统仅仅将 LLM 当作一个「更好的语言模型打分器」，训练目标仍然是最小化转录 CE loss，无法触发 LLM 在大规模预训练中积累的知识和推理能力。作者通过大量工业预实验证实了这一点：直接将更大的 LLM 接入 ASR 系统，收益不成正比。

1.3 本文的核心思路

本文提出 CoT-ASR（Chain-of-Thought ASR），首次将思维链（CoT）推理机制引入 ASR。核心思路是：

在生成转录文本之前，先让 LLM 对语音内容进行上下文分析与推理（contextual reasoning），将 ASR 任务从「直接转录」升级为「先理解再转录」。

这一设计不仅充分利用了 LLM 的知识储备和生成能力，还保持了 LLM 标准的 next-token prediction 单遍（one-pass）生成管线，与主流推理框架（HuggingFace、vLLM）高度兼容。

2. 相关工作

2.1 Speech LLMs

文本 LLM 的发展经历了从参数规模扩展（GPT-3、PaLM）到推理增强（GPT-4o、Gemini 1.5）、再到高效小模型（Llama 3、Phi-4 系列）的演进。相应地，Speech LLM 也沿袭了两条路径：

  • 离散 token 路径：将语音编解码为离散 token，扩充 LLM 词表（AudioLM、VALL-E 等）；
  • 连续表示路径：通过适配器（Q-former、CIF、CTC 压缩器、线性投影）将语音 encoder 输出映射为软 prompt，再输入 LLM 生成文本。

当前 LLM-based ASR 在公开基准（如 LibriSpeech）上已取得相当有竞争力的结果，但在实体识别、领域泛化等能力上仍有提升空间。

2.2 Chain-of-Thought 推理

CoT（Wei et al., NeurIPS 2022）通过构造显式中间推理步骤，显著提升了 LLM 在多步推理、组合推断、上下文知识整合等任务上的性能。早期研究主要通过 few-shot prompting 激活 CoT；近年来趋势是将推理能力内化到模型参数中（如 OpenAI o1 系列）。

CoT 在多模态场景的应用也在加速推进：

  • MAmmoTH-VL：大规模指令微调提升跨模态问答；
  • video-SALMONN-o1：面向视频理解的推理增强；
  • CoT-ST：将语音翻译分解为「ASR → 翻译」两步链；
  • 语音情感识别：CoT 提升解释性和鲁棒性。

本文与上述工作的核心区别在于：CoT-ASR 是首个针对 ASR 任务的单遍 CoT 推理模型，而非二轮（two-pass）纠错或针对语义转换任务的多模态推理框架。

3. CoT-ASR 方法

3.1 整体架构

CoT-ASR 由三个主要模块组成：

  1. Speech Encoder：基于 Conformer 架构，将语音信号编码为连续帧级表示序列 $E = (e_1, \ldots, e_L)$；
  2. CTC-guided Modality Adapter：将 $E$ 转换为模态对齐后的表示序列 $A = (a_1, \ldots, a_L)$（长度不变，维度与 LLM 隐层匹配）；
  3. LLM + LoRA：以 Phi-4-mini-instruct（3.8B 参数）为主干，接收 $[A; I]$（speech prompt + text prompt embedding 拼接）并执行 next-token prediction。

3.2 训练流程

3.2.1 推理增强数据构建

训练的核心是将静态的 (speech, transcript) 对转化为动态的推理链数据 (speech, context + transcript)。具体做法是：

  • 使用现成的文本 LLM（本文采用 Qwen2.5-14B-Instruct）对每条 ground-truth 转录文本自动生成对应的上下文分析（contextual analysis）；
  • 上下文分析的质量由精心设计的 prompt template 保障（详见 Appendix A），prompt 要求模型识别语境类型、融入具体实体/专有名词、描述说话者与听众关系，但不直接引用原文；
  • 最终生成格式为：<CONTEXT>...</CONTEXT><TRANSCRIPT>...</TRANSCRIPT>。

这一数据构建策略无需人工标注，可扩展到大规模数据集。

3.3 推理：单遍生成

推理时，给定语音输入和固定的文本 prompt（如 “Transcribe the audio clip into text.”），CoT-ASR 在单次自回归生成中依次产出：

  1. <CONTEXT> 部分：LLM 利用自身知识对语音内容进行上下文分析，推断领域、实体、语境等信息；
  2. <TRANSCRIPT> 部分：以前一步生成的上下文为条件，生成最终转录文本。

3.4 用户引导转录（User-guided Transcription）

CoT-ASR 的框架自然支持一种可选的用户引导模式：当用户提供外部上下文信息时，该信息被封装在 <CONTEXT>...</CONTEXT> 标签中，与语音 prompt 和 text prompt 一起输入，CoT-ASR 跳过自我推理阶段，直接利用用户提供的上下文执行转录。

这一机制利用了 LLM 的 instruction-following 和 in-context learning 能力。需要注意的是，用户引导转录仅为 CoT-ASR 的附加能力，默认工作模式仍是纯语音输入的自主推理转录。

4. CTC-guided Modality Adapter

4.1 设计动机

当前主流的模态适配器（modality adapter）多为简单线性投影（可选非线性激活），其局限在于：

  • 完全依赖训练期间的隐式优化来建立语音-文本模态映射；
  • 无法利用 LLM 在预训练阶段已有的文本 embedding 矩阵；
  • 文献 [14] 和本文作者的工业级预实验表明，对语音 prompt 做任何程度的压缩（如丢弃 blank 主导帧）都会导致 ASR 性能下降。

4.2 CTC 概率的显式计算

CTC-guided Modality Adapter 的核心思路是：利用 CTC 后验概率分布，显式地将语音帧表示映射到 LLM 文本 embedding 空间。

5. 实验设置

5.1 数据集

  • 训练数据：38,000 小时内部英文 ASR 数据（匿名化处理）；
  • 推理增强数据构建：使用 Qwen2.5-14B-Instruct 对上述训练集的 ground-truth 转录生成上下文分析，构建 CoT 训练数据；
  • 公开测试集：LibriSpeech（test-clean / test-other）、FLEURS；
  • 内部测试集：涵盖消费品（Consumer Goods）、营养（Nutrition）、游戏（Gaming）、健康（Wellness）、患者病史（Patient History）、药房（Pharmacy）、外科手术（Surgery）、银行（Banking）等多个垂直领域。

5.2 模型配置

CoT-ASR：

  • LLM 主干：Phi-4-mini-instruct（3.8B 参数），LoRA 微调；
  • Speech Encoder：Conformer，3 层卷积前端（下采样因子 8，输出帧步长 80ms）+ 24 个 Conformer block（注意力维度 1024，FFN 维度 1536，16 头注意力）；
  • Modality Adapter：CTC-guided，阈值 $\tau=0.05$，两层 FFN + GELU；
  • 训练数据：推理增强 ASR 数据（38k 小时 + Qwen 生成的 CONTEXT）。

Phi4MM-style Baseline：

  • 相同的 encoder 和 LLM 主干；
  • 适配器为线性投影（两层 FFN + GELU），无 CTC 辅助；
  • 使用原始 ASR 数据（无 CONTEXT）训练；
  • 按照 Phi-4-MultiModal 设计原则构建，作为公平基线。

5.3 评估指标

除 WER 之外，本文重点采用 EER（Entity Error Rate） 作为主要评估指标。

EER 衡量 reference 中的关键实体（医学术语、人名、专有名词等）未被完整正确识别的比例。与 WER 不同，EER 对语义完整性的要求更严格：一个实体只有在其全部词均正确时才被计为识别成功。这更能反映真实用户体验，也更能考察 LLM 知识利用能力。

CTC Compressor 和 SSR 均因对语音 prompt 进行压缩（丢弃部分帧）而大幅下降。这再次验证了本文的核心设计原则：保留完整语音 prompt 长度是 LLM-based ASR 的关键。

8. 结论与展望

本文提出 CoT-ASR，首次将 Chain-of-Thought 推理机制引入 ASR 任务，建立了推理驱动 ASR 范式。核心贡献包括：

  1. 首个单遍 CoT ASR 模型：在单次自回归生成中完成推理分析和转录，兼容标准 LLM 生成管线；
  2. 用户引导转录扩展：通过 in-context learning 机制，支持用户提供上下文引导转录，进一步降低 EER 24.9%；
  3. CTC-guided Modality Adapter：利用 CTC non-blank 概率显式加权 LLM embedding，实现高效模态对齐，无需语音 prompt 压缩；
  4. 实验验证：CoT-ASR 在公开基准和多领域工业测试集上均优于标准 LLM-based ASR，以 3.8B 参数达到或超越 30B 级别模型的 ASR 性能。

未来方向包括：将 CoT-ASR 扩展至流式（streaming）场景；探索更高质量的上下文分析数据构建策略；以及与 RL-based 推理训练（如 GRPO）结合以进一步提升推理质量。
