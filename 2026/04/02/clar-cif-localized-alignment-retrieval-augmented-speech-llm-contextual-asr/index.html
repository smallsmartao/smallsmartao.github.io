CLAR: CIF-Localized Alignment for Retrieval-Augmented Speech LLM-Based Contextual ASR

本文最后更新于 2026年4月2日 上午

论文信息
标题：CLAR: CIF-Localized Alignment for Retrieval-Augmented Speech LLM-Based Contextual ASR
作者：Shangkun Huang, Huan Shen, Wei Zou, Yunzhang Chen（BRVoice Team, Bairong, Inc.）
arXiv：2603.25460
发表时间：2026年3月26日

一、研究背景与问题定义

Speech LLM 近年来在通用领域 ASR 上取得了显著进展，但在命名实体和长尾词汇的识别上仍面临系统性瓶颈。这一问题的根源在于：LLM 内部的语言模型先验过于强势，在端到端解码时往往压倒微弱的声学证据，将稀有词汇替换为更高频的常见词，甚至产生幻觉（hallucination）。这对信息检索、问答系统、对话系统等下游应用的鲁棒性造成了实质性破坏。

为此，学界提出了上下文偏置（contextual biasing）与检索增强生成（RAG）两类方向。通过向模型注入热词候选列表或少量样本示例，可在一定程度上改善低频词汇的识别效果。但其有效性高度依赖候选列表的精确性，且随列表规模增大，性能往往下降。

更根本的问题在于前端检索器的定位能力：在无时间戳弱监督条件下，如何从完整语句的语音中稳定、准确地定位热词片段？现有方法存在两个关键瓶颈：

  1. 表示粒度不匹配导致特征”稀释”（Representation Dilution）：传统双塔检索器对语音进行全局池化，将不定长语音压缩为单一的话语级向量。在完整语句中，短实体（通常仅持续几百毫秒）的声学线索极易被背景噪声或无关内容平均掉，在以 TTS 合成数据训练时这一问题更为突出。

  2. 弱监督导致对齐偏移（Alignment Deviation）：缺乏显式时间约束时，无约束软匹配范式捕获的是全局语义共现而非严格的时间对应关系，导致注意力焦点漂移、局部聚合错位（attention drift）。

本文提出 CLAR（CIF-Localized Alignment for Retrieval-Augmented），针对上述两个瓶颈设计了一套基于 CIF 单调对齐的局部热词检索框架，并将其无缝集成到 Speech LLM 的提示驱动解码流程中。

二、方法详解

2.1 整体框架（Overall Framework）

CLAR 的整体架构如 Figure 1 所示，包含两个组件：

  1. CLAR 检索器：基于双编码器的 CLAP 风格检索器，集成 CIF 对齐机制，对完整语音中的热词候选进行精细化打分，输出 Top-K 候选列表。
  2. Speech LLM 解码器：接收 CLAR 检索出的热词候选，以自然语言提示的形式作为上下文偏置，驱动 LLM 进行自回归转录。

整个流程可以概括为：语音输入 → CLAR 检索热词候选 → Top-K 候选作为提示注入 → Speech LLM 上下文感知解码。CLAR 仅在推理前端工作，不参与 Speech LLM 的参数更新，也不需要浅层融合或格子重评分。

2.2 CLAP 风格双编码器与 CIF 单调对齐

双编码器架构

CLAR 检索器沿用 CLAP 框架，采用双塔设计：

  • 语音编码器：实例化为 Paraformer 编码器，基于自注意力的非自回归建模架构。输入为对数梅尔滤波器组特征 $\mathbf{X} \in \mathbb{R}^{T_0 \times F}$，输出帧级隐表示 $\mathbf{H} = [h_1, \ldots, h_T] \in \mathbb{R}^{T \times D_{\text{enc}}}$，其中 $T$ 为下采样后的帧数，$D_{\text{enc}}$ 为编码器隐层维度。

  • 文本编码器：初始化自 Chinese-RoBERTa-wwm-ext，通过有效 token 位置的掩码均值池化获取句级嵌入。

两个模态分别通过独立的投影层映射到共享嵌入空间 $\mathbb{R}^D$：

$$
a_t = \frac{f_a(h_t)}{|f_a(h_t)|_2}, \quad e_j = \frac{f_t(z_j)}{|f_t(z_j)|_2}
\tag{1}
$$

其中 $z_j$ 为第 $j$ 个候选的文本编码器池化输出，$a_t, e_j \in \mathbb{R}^D$ 均经过 $\ell_2$ 归一化。投影层 $f_a(\cdot)$ 和 $f_t(\cdot)$ 各为两层带 ReLU 激活的前馈网络。

CIF 单调对齐

CLAR 的核心模块是 CIF 预测器（Continuous Integrate-and-Fire），作用于编码器输出 $\mathbf{H}$，生成帧级权重序列 $\alpha = [\alpha_1, \ldots, \alpha_T]$，其中 $\alpha_t \in (0, 1)$：

$$
\alpha_t = \sigma!\left(\text{Linear}!\left(\text{ReLU}!\left(\text{LayerNorm}!\left(\text{Conv1d}(\mathbf{H})\right)\right)\right)_t\right)
\tag{2}
$$

CIF 通过累计计数器 $C_t = C_{t-1} + \alpha_t$ 积累权重。当 $C_t \geq \theta$（默认 $\theta = 1.0$）时触发一次”发射”（fire event），定义一个单调声学边界，余量由 $C_t \leftarrow C_t - \theta$ 携带至下一帧。帧 $t$ 对应的 token 索引为：

$$
\text{tok}(t) = 1 + \sum_{j=1}^{t-1} \mathbf{1}[C_j \geq \theta]
\tag{3}
$$

这一映射是非递减的，从而为下游语音-文本匹配提供长度感知的局部窗口。

训练阶段的 CIF 约束：采用缩放策略，将预测权重序列 $\alpha$ 乘以标量使得 $\sum_t \alpha_t$ 与真实 token 长度对齐，以教师强制约束稳定对齐学习。CIF 相关参数从 Paraformer 对应组件初始化。

2.3 CIF 局部化热词检索（CIF-Localized Hotword Retrieval）

本节是 CLAR 的核心贡献：利用 token 级对齐实现细粒度可变长度跨模态匹配。

跨模态相似度矩阵

给定语音话语的投影归一化帧级嵌入 $\mathbf{A} = [a_1, \ldots, a_T] \in \mathbb{R}^{T \times D}$，以及包含 $N$ 个预计算文本嵌入的热词词库 $\mathbf{E} = [e_1, \ldots, e_N] \in \mathbb{R}^{N \times D}$，帧级跨模态相似度矩阵计算为：

$$
\mathbf{S} = \tau \cdot \mathbf{A}\mathbf{E}^\top \in \mathbb{R}^{T \times N}
\tag{4}
$$

其中 $\tau$ 为可学习的对数尺度参数（逆温度），控制相似度分布的锐度。

Token Span 均值切片聚合

关键创新在于相似度矩阵 $\mathbf{S}$ 的聚合方式。与全局池化不同，本方法利用 CIF 预测的 token 边界进行局部滑动窗口聚合：

CIF 对齐将 token 索引 $k$ 映射到声学帧区间 $[b_k, e_k]$（分别为首帧与末帧）。CIF 预测器以与文本编码器分词粒度相同的粒度输出声学 token。对于文本 token 长度为 $L$ 的候选热词，在 CIF 发射的 token 序列上滑动宽度为 $L$ 的声学窗口。对窗口位置 $s \in {0, 1, \ldots, K - L}$（$K$ 为 CIF 发射的总 token 数），对应声学区间为 $[b_s, e_{s+L-1}]$，第 $j$ 个候选在窗口位置 $s$ 的均值切片得分为：

$$
\text{score}j(s) = \frac{1}{e{s+L-1} - b_s + 1} \sum_{t=b_s}^{e_{s+L-1}} S_{t,j}
\tag{5}
$$

候选 $j$ 的最终检索得分取所有有效窗口位置的最大值：

$$
\hat{r}_j = \max_s \text{score}_j(s)
\tag{6}
$$

这一设计有两大优势：

  • 支持可变长度匹配：将每个候选与长度成比例的窗口对齐，自然处理不同长度的热词。
  • 保留显著局部线索：避免全局池化的稀释效应；同时使用前缀和窗口计分与按长度分批的候选批处理，保证实际计算效率。

完整推理流程见 Algorithm 1（原文第2页）。

2.4 训练目标与检索增强解码

多粒度训练目标

CLAR 检索器采用多级对比学习框架，总损失为三项之和：

$$
\mathcal{L} = \mathcal{L}{\text{local}} + \mathcal{L}{\text{global}} + \mathcal{L}_{\text{cif}}
\tag{7}
$$

局部热词级对比损失 $\mathcal{L}_{\text{local}}$：在热词跨度级别提供细粒度监督。对每个样本，CIF 推导的 token 对齐识别出被标注热词所在的帧，对这些帧的嵌入做均值池化，得到热词级语音嵌入，然后与对应热词文本嵌入进行对称交叉熵对比：

$$
\mathcal{L}{\text{local}} = \frac{1}{2}(\mathcal{L}{a \to t} + \mathcal{L}_{t \to a})
\tag{8}
$$

其中：
$$
\mathcal{L}{a \to t} = -\frac{1}{B}\sum_i \sum_j y{ij} \log \frac{\exp(\tau, a_i^\top e_j)}{\sum_{j’} \exp(\tau, a_i^\top e_{j’})}
$$

$\mathcal{L}{t \to a}$ 对称定义，$y{ij}$ 为由样本身份推导的软目标。

全局句级对比损失 $\mathcal{L}_{\text{global}}$：将话语级语音嵌入（对有效编码器帧做掩码均值池化）与句级文本嵌入对齐，以保留全局语义。引入全局目标的作用是融合完整话语级语义上下文，进一步提升局部特征的判别力。

CIF 数量约束 $\mathcal{L}_{\text{cif}}$：通过最小化预测 token 计数 $\sum_t \alpha_t$ 与真实文本长度之间的 L1 距离，规范对齐，稳定训练时的 CIF 边界。

检索增强解码

推理时，训练好的 CLAR 检索器处理输入语音，生成帧级嵌入与 CIF 对齐，对热词词库中所有候选执行局部均值切片聚合打分，将 Top-K 候选拼接为文本提示，作为动态上下文偏置前置于 Speech LLM 指令。Speech LLM 对 SFT 基座进行 LoRA 微调后，在音频输入和增强提示共同条件下进行自回归解码。

CLAR 仅作为推理前端的偏置策略，不需要进一步参数更新、浅层融合或格子重评分，且通过自然语言提示接口注入上下文信息，可跨提示条件型 Speech LLM 灵活迁移。

三、实验

3.1 数据集与评估指标

实验采用如下数据集配置：

  • Speech LLM 训练：AISHELL-1
  • CLAR 检索器训练：AISHELL-2（排除包含 AISHELL-1-NE 热词的训练话语）
  • 热词集：AISHELL-1-NE（400个测试热词，600个开发热词）
  • 测试集：Test-AISHELL-1-NE（808条话语，400个热词，226个R1热词）
  • 开发集：Dev-AISHELL-1-NE（1334条话语，600个热词，371个R1热词）

其中 R1 热词定义为基础 ASR 模型召回率低于 40% 的热词，代表更难的长尾场景（测试集 N=226，开发集 N=371）。

评估指标包含：

  • CER（Character Error Rate）：全局字符错误率
  • B-WER（Biased-Word Error Rate）：偏置词错误率，衡量热词识别准确性
  • U-CER（Character Error Rate on Non-bias Words）：非偏置词字符错误率，衡量热词注入对普通词汇的干扰
  • Top-1/5/10 Recall 及 F1：热词检索性能

3.2 实验配置

  • Speech LLM 基座：Step-Audio2-mini
  • 热词模拟：推理时随机采样 5-10 条转录词条作为热词，每个热词为随机3-6字符 n-gram
  • Speech LLM LoRA 微调：r=16, alpha=16, target=all linear, dropout=0.1, bias=none；4张 NVIDIA H20 GPU，batch size=32，2000步，AdamW，峰值学习率 2e-6，warmup ratio=0.1，BF16 混精度
  • CLAR 训练：音频/文本编码器分别初始化自 Paraformer（iic/speech_paraformer-large）和 Chinese-RoBERTa-wwm-ext（hfl/chinese-roberta-wwm-ext）；4张 H20 GPU，batch size=256，AdamW，学习率 5×10⁻⁴；两阶段训练：
    • 阶段一：CIF 预训练 30 个 epoch，全局/局部损失权重固定为 0，仅优化 CIF 损失
    • 阶段二：从阶段一初始化，联合训练 60 个 epoch，优化音频编码器、文本编码器和 CIF 模块

3.3 结果与分析

3.3.1 热词检索性能

损失项消融实验（Table 1）验证了各训练目标的贡献：

Loss Terms Test R@1 Test R@5 Test R@10 Dev R@1 Dev R@5 Dev R@10
$\mathcal{L}_{\text{global}}$ only 33.29 54.70 62.62 29.99 47.53 58.85
$\mathcal{L}{\text{local}}$ + $\mathcal{L}{\text{cif}}$ 96.29 98.89 99.38 95.43 98.88 99.25
$\mathcal{L}{\text{global}}$ + $\mathcal{L}{\text{local}}$ + $\mathcal{L}_{\text{cif}}$ 97.03 99.75 99.75 95.73 98.88 99.48

关键发现：

  • 单独使用全局对比损失 $\mathcal{L}_{\text{global}}$，测试集 R@1 仅 33.29%，开发集 29.99%，说明全局池化无法捕获短实体局部线索。
  • 加入局部对比损失与 CIF 数量约束后，R@1 跃升至 96.29%/95.43%，R@5 达 98.89%/98.88%，证明 CIF 驱动的细粒度单调对齐有效缓解了弱监督软匹配中的注意力漂移。
  • 全三项损失组合取得最优，表明全局目标进一步补充了话语级语义上下文，提升局部特征的判别力。

与基线方法的 F1 对比（Table 2）：

方法 Test F1 (%)
SeACo-Paraformer 96.00
GLCLAP 96.96
CLAR（本文） 97.03

CLAR 以 97.03% F1 达到最优，略超 GLCLAP（96.96%）。值得注意的是，CLAR 的训练数据量比 GLCLAP 少约一个数量级，却仍表现更好，体现了 CIF 局部化对齐的数据效率优势。

案例分析（Figure 3）定性支持了上述结论：局部语音-文本相似度高度集中于目标热词区域（虚线框），非目标候选相似度保持低水平，与短实体定位改善和注意力漂移减少一致。

干扰项列表规模的影响（Table 3）：将 CLAR 检索出的热词候选作为提示注入后，与多种基线进行对比：

设置 CER ↓ B-WER ↓ U-CER ↓
Test-AISHELL-1-NE
Vanilla Step-Audio2-mini 1.86 12.92 0.80
NA（无偏置列表） 1.82 13.03 0.76
GT（Oracle热词列表） 0.82 2.34 0.78
CLAR N=226（R1子集） 1.36 5.97 1.03
CLAR N=400（全集） 0.92 2.78 0.83
Dev-AISHELL-1-NE
Vanilla Step-Audio2-mini 1.76 13.09 0.74

CLAR N=600（全集） 0.87 3.17 0.75

主要结论：

  • 使用完整候选池（N=400/600）时，CLAR 带来最大幅度提升：测试集 CER 从 1.86% 降至 0.92%，B-WER 从 12.92% 降至 2.78%，接近 Oracle 上界（CER=0.82%，B-WER=2.34%）。
  • U-CER 保持低位（0.83%/0.75%），说明热词注入对非偏置词汇几乎无干扰。
  • 在更难的 R1 子集上，U-CER 略有上升（1.03%/1.01% vs. NA 的 0.76%/0.75%），表明假阳性热词偶尔会对非偏置词解码产生扰动，是未来值得关注的方向。

CLAR 以 0.92% CER 和 2.78% B-WER 达到最优，超越所有基线，达到当前最优水平（SOTA）。结果进一步证实，高精度局部检索能有效对抗过强的语言模型先验，减少命名实体替换和幻觉，提升整体识别准确率。

四、结论与展望

本文提出 CLAR，一种基于 CIF 局部化对齐的双编码器检索器，用于 Speech LLM 驱动的检索增强上下文 ASR。其核心贡献在于：

  1. 无时间戳的 token 级单调对齐：利用 CIF 机制在弱监督条件下学习单调对齐，无需人工标注时间戳，为短实体声学线索提供精确定位锚点。

  2. 长度感知局部化匹配：通过 CIF 预测的 token 边界驱动可变长度滑动窗口均值切片聚合，有效抑制全局池化引起的特征稀释与注意力漂移。

  3. 多粒度训练目标：将全局对比损失、局部对比损失和 CIF 数量约束联合优化，实现全局语义与细粒度检索精度的协同提升。

  4. 轻量级即插即用：CLAR 以自然语言提示接口注入上下文信息，无需修改 Speech LLM 参数、浅层融合或格子重评分，可跨不同提示条件型 Speech LLM 灵活迁移。

未来工作将向更大规模多语言场景扩展，以及探索与 Speech LLM 更紧密的集成方式。
