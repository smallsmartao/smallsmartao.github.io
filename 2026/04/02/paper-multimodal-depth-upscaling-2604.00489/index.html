Adapting Text LLMs to Speech via Multimodal Depth Up-Scaling

本文最后更新于 2026年4月2日 上午

论文标题： Adapting Text LLMs to Speech via Multimodal Depth Up-Scaling
作者： Kazuki Yano, Jun Suzuki, Shinji Watanabe（Tohoku University / Carnegie Mellon University）
arXiv： 2604.00489
发表于： 2026年4月

1. 引言：问题背景与研究动机

预训练大语言模型（LLM）在大规模文本语料上积累了强大的语言理解与生成能力。将这些能力扩展到语音领域，催生了语音语言模型（Speech Language Model，Speech LM）这一研究方向。一种自然的做法是：在预训练的文本 LLM 基础上，通过持续预训练（Continual Pre-training，CPT）将语音数据的语音能力注入 LLM，使其既能处理语音（如自动语音识别，ASR），又保留原本的文本能力。

然而，这一做法面临一个核心挑战——灾难性遗忘（Catastrophic Forgetting）：在语音数据上持续训练，往往会严重破坏 LLM 原本在文本任务上的表现，从而削弱”在预训练 LLM 上构建语音模型”的初衷。

现有的缓解策略主要有两类：

  1. 文本数据回放（Text Data Replay）：在语音训练阶段同时混入文本数据，以维持对文本任务的记忆。但这要求获取预训练文本数据，而大多数开源 LLM 并未公开其预训练数据，使得忠实回放在实践中难以实现；即便可以回放，也会成比例地增加训练成本。

  2. 参数高效微调（Parameter-Efficient Fine-Tuning，PEFT），尤其是 LoRA：通过将权重更新约束在低秩子空间内来减少遗忘，在语音 LM 中被广泛采用。然而，本文实验表明，对于较小的基础模型，LoRA 提供的容量不足以充分学习新的语音模态。

本文提出 多模态深度扩缩（Multimodal Depth Up-scaling），将深度扩缩（Depth Up-scaling）这一 LLM 持续预训练策略扩展到跨模态适配场景：在冻结文本 LLM 的全部原始层的同时，插入新的 transformer 层，只训练新增层。由于原始权重从不被修改，推理时可直接移除新增层，精确还原预训练模型。

2. 相关工作

2.1 语音语言模型与灾难性遗忘

将文本 LLM 适配为语音 LM 的主流路线有两条：一是将语音编码器与 LLM 连接（如 SALMONN、Qwen2-Audio）；二是使用离散语音 token，令 LLM 直接对其建模（如 OpusLM）。两条路线均存在 CPT 后文本能力退化的问题。已有研究通过文本回放或参数高效方法（如 LoRA）缓解该问题，也有研究在更广泛的持续语音学习框架下探索经验回放。

2.2 深度扩缩（Depth Up-scaling）

深度扩缩通过插入新 transformer 层来扩展模型容量，LLaMA Pro、SOLAR 等工作均在文本域应用了这一思想。近期工作进一步通过可学习预测（LESA）和最优传输（Progressive Depth Up-scaling）改进层初始化策略。然而，将深度扩缩用于多模态语音适配此前未被探索。

本文系统研究新增层的位置策略与架构选择对 ASR 性能和文本任务保留能力的影响。

3. 方法

3.1 词表扩展（Vocabulary Expansion）

为使 LLM 处理语音输入，首先对预训练 LLM 的 tokenizer 词表进行扩展，加入语音 token。遵循 OpusLM 的做法，通过结合语义 token 与声学 token 将语音转换为离散 token 序列，并将这些语音 token 追加到原始文本词表之后。对应地，嵌入层（embedding layer）随之扩容，并与新增层一起参与训练；原始嵌入权重保持冻结。

3.2 深度扩缩（Depth Up-scaling）

设预训练模型原有 $n$ 层 ${f_i}{i=1}^n$，我们额外插入 $m$ 个新 transformer 层 ${g_j}{j=1}^m$（如图1所示）。训练期间，所有原始层 ${f_i}$ 均被冻结，只有新增层 ${g_j}$ 参与梯度更新。

**函数保持初始化（Function Preserving Initialization）**是深度扩缩成功的关键属性：扩展后的模型在训练开始时应与原始模型行为完全一致，以避免新增层立即扰乱预训练表征、导致训练不稳定。每个新增层 $g_j$ 执行：

$$H = X + \text{MHSA}(\text{LN}(X)) \tag{1}$$

$$Y = H + \text{FFN}(\text{LN}(H)) \tag{2}$$

其中 $X, Y \in \mathbb{R}^{T \times d}$ 分别为输入和输出，$T$ 为序列长度，$d$ 为隐藏维度，LN 为层归一化。遵循先前工作，对 MHSA 和 FFN 的输出投影矩阵采用零初始化，使得初始化时两者输出均为零。由于残差连接和无偏置项的设计，初始化时 $Y = X$，即每个新增层为恒等函数，训练过程中逐步学习语音适配。

层位置策略对性能有重要影响，本文评估五种策略（每个新增层 $g_j$ 初始化为对应原始层 $f_i$ 的副本，并置于其后，形成 $g_j \circ f_i$ 的组合）：

  • INTERLEAVED：将新增层均匀分布于全部原始层中
  • BOTTOM：将新增层集中于网络下半部分
  • MIDDLE：将新增层集中于网络中间部分
  • TOP：将新增层集中于网络上半部分
  • SANDWICH：将新增层置于网络底部和顶部各四分之一处

3.3 新增层架构：E-Branchformer

先前深度扩缩工作均使用与原始层相同的标准 transformer 层作为新增层。本文进一步考虑将专为语音识别设计的 E-Branchformer 用作新增层架构。

与标准 transformer 层顺序执行自注意力和前馈网络不同，E-Branchformer 通过两条并行分支处理输入并经合并模块（merge module）融合：

  • 全局提取分支（Global Extractor）：通过多头自注意力（MHSA）捕获长程依赖关系：

$$H_G = \text{MHSA}(\text{LN}(X)) \in \mathbb{R}^{T \times d} \tag{3}$$

  • 局部提取分支（Local Extractor）：通过卷积空间门控单元（CSGU）和门控 MLP（cgMLP）捕获局部模式：

$$H_L = \text{cgMLP}(\text{LN}(X)) \in \mathbb{R}^{T \times d} \tag{4}$$

合并模块通过拼接、深度可分离卷积（DwConv）进行空间精炼，再投影回 $d$ 维：

$$H_{\text{Merge}} = (H_C + \text{DwConv}(H_C)) W_{\text{Merge}} \in \mathbb{R}^{T \times d} \tag{5}$$

其中 $H_C = \text{Concat}(H_G, H_L) \in \mathbb{R}^{T \times 2d}$，$W_{\text{Merge}} \in \mathbb{R}^{2d \times d}$ 为线性投影矩阵。合并输出 $H_{\text{Merge}}$ 经残差连接后通过 FFN（同公式2）。

由于 cgMLP 分支专为声学处理设计，仅对语音 token 启用 cgMLP 和合并模块；文本 token 绕过这两个组件，只使用 MHSA 输出。

E-Branchformer 的函数保持初始化：标准 transformer 层可独立零初始化 MHSA 和 FFN 的输出投影，但 E-Branchformer 的两个分支共享一个合并投影 $W_{\text{Merge}}$，无法直接套用。本文采用如下初始化方案：

$$W_{\text{Merge}} = \begin{bmatrix} I \ 0 \end{bmatrix}$$

其中 $I \in \mathbb{R}^{d \times d}$ 为单位矩阵，$0 \in \mathbb{R}^{d \times d}$ 为零矩阵；同时设 $W_O = 0$，深度可分离卷积的输出投影也置零。初始化时：$H_G = 0$（因为 $W_O = 0$），因此 $H_C W_{\text{Merge}} = [0, H_L] \cdot [I; 0] = 0$，层退化为恒等映射 $Y = X$，满足函数保持性质。

3.4 推理时层丢弃（Layer Dropping at Inference）

冻结全部原始层的直接好处是：推理时可简单移除新增层，类似随机深度（Stochastic Depth）或层 Dropout，精确还原预训练模型，从设计上保证文本任务零退化。当需要语音能力时使用完整模型；仅需文本能力时则丢弃新增层。

图1：多模态深度扩缩策略。可训练的 E-Branchformer 块与冻结的 transformer 块交替排列，在保留预训练文本表征的同时获取语音能力。

4. 实验

4.1 实验设置

数据：使用 OWSM v3.2 套件的英语 ASR 子集进行训练，共约 48k 小时数据。训练期间仅使用 ASR 任务数据，不混入任何文本数据，以便在无文本回放辅助的情况下孤立评估深度扩缩对文本能力保留的效果。

基础模型：采用 SmolLM2 系列，规模分别为 360M（32层）和 1.7B（24层），均在最多 11T 文本 token 上预训练。

深度扩缩配置：新增层数量为原始层数的 25%——360M 模型新增 $m=8$ 层（$n=32$，新增 0.20B 参数，总计 0.51B），1.7B 模型新增 $m=6$ 层（$n=24$，新增 0.66B 参数，总计 2.27B）。新增层与原始模型隐藏维度相同。

基线方法：

  • 全量微调（Full Fine-tuning）：更新原始模型全部参数，不新增层
  • LoRA：仅训练低秩适配器，预训练权重冻结。LoRA 秩 $r$ 设置为与深度扩缩可训练参数量匹配（360M 对应 $r=144$，1.7B 对应 $r=356$，分别产生 0.20B 和 0.66B 可训练参数），这是对 LoRA 较为有利的设置。

训练：AdamW 优化器，峰值学习率 $1 \times 10^{-4}$，25k 步预热后线性衰减至 $2 \times 10^{-5}$，最大上下文长度 8192 token。

评估：

  • ASR：在 LibriSpeech test-clean 和 test-other 上报告词错误率（WER，越低越好）
  • 文本能力：评估 8 个基准——ARC-Easy、ARC-Challenge、BoolQ、HellaSwag、OpenBookQA、PIQA、WinoGrande、MMLU，报告平均准确率（Avg）及相对预训练模型的变化量（$\Delta$）

核心发现：

ASR 性能方面，深度扩缩（INTERLEAVED）达到与全量微调相当的 WER，大幅优于 LoRA。LoRA 在较小的 360M 模型上表现尤为糟糕（WER clean=11.3），说明当基础模型容量有限时，低秩适配能力不足以学习新模态。在 1.7B 模型上，INTERLEAVED 深度扩缩在 test-other 上甚至以 5.5% 超过全量微调（5.6%）。

文本能力保留方面，全量微调和 LoRA 均造成严重退化（约 -22 至 -35 个百分点），而所有深度扩缩变体的退化均远小于此。在 1.7B 模型上，INTERLEAVED 深度扩缩仅造成 -8.3 的退化，而全量微调高达 -32.6。

位置策略权衡：ASR 与文本保留能力之间存在明确的排序反转——INTERLEAVED 在 ASR 上最优但文本退化相对较多，TOP 文本保留最好但 WER 更高。将新增层分布于整个网络赋予其更强的表征适配能力，但也对原始计算路径影响更大。

核心发现：

E-Branchformer 在两个模型规模上均优于标准 transformer 层的 WER。在 1.7B 模型上，E-Branchformer 新增层匹配甚至超越全量微调的 ASR 性能（clean: 2.3 vs 2.3，other: 5.3 vs 5.6），同时文本退化仅为 -6.8，相比全量微调的 -32.6 减少超过 75%，且可训练参数减少 60%（0.75B vs 1.87B）。

两种架构的文本保留能力相当，说明替换为 E-Branchformer 不以牺牲文本性能为代价。E-Branchformer 中 cgMLP 的卷积分支有助于捕获局部声学模式，与自注意力的全局上下文建模形成互补。

函数保持初始化相比随机初始化一致性地取得更好结果，验证了 $[I; 0]$ 恒等映射初始化策略的有效性。

4.4 定性分析：保留的语言能力

如前所述，移除新增层可完全还原预训练模型。本节进一步考察：当以语音输入为条件时，模型是否保留基础 LLM 的文本指令跟随能力——这是一种无需级联 pipeline 的端到端能力。

实验在 SmolLM2-1.7B（INTERLEAVED, E-Branchformer）上进行，通过在语音输入前附加自然语言指令及少量上下文示例，要求模型直接从语音条件提示生成目标文本。输入语音内容为：”A cold, lucid indifference reigned in his soul.”

表3：零样本提示任务输出对比（SmolLM2-1.7B）

任务 提示 深度扩缩输出 全量微调输出
英法翻译 Translate the sentence into French Une indifférence froide, claire, régnait dans l’âme. in in in in in in …
文本简化 Rewrite into simple, modern English A chilly indifference pervaded his soul. in in in in in in …
摘要生成 Summarize in one clear sentence The man was indifferent to everything. in in in in in in …

全量微调完全失败，反复产生退化性输出（重复 token）。相比之下，多模态深度扩缩在仅用 ASR 数据、无任何文本回放训练的情况下，在三项任务上均产生了语义连贯、任务适配的输出，与表1中保留的文本能力定量结果一致。

5. 结论与展望

本文提出多模态深度扩缩：在冻结文本 LLM 全部层的同时插入新 transformer 层，推理时可丢弃新增层以精确还原预训练性能。在 SmolLM2-360M 和 SmolLM2-1.7B 上的实验表明：

  • 深度扩缩实现了与全量微调相当的 ASR 性能，同时文本能力保留远优于全量微调和 LoRA
  • E-Branchformer 新增层进一步提升 ASR：在 1.7B 模型上匹配/超越全量微调，文本退化减少超过 75%，可训练参数减少 60%
  • 零样本指令跟随能力得以保留，全量微调则完全丧失此能力
  • 深度扩缩与文本数据回放正交，两者可结合使用

未来工作包括将该方法扩展到其他语音任务（如语音翻译、语音问答）和多语言场景。
