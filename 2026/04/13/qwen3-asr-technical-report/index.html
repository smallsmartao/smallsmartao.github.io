Qwen3-ASR Technical Report

本文最后更新于 2026年4月13日 中午

论文链接：arXiv:2601.21337
机构：阿里巴巴通义实验室（Qwen Team）
关键词：Large Audio-Language Model, Multilingual ASR, Forced Alignment, Non-Autoregressive, Streaming ASR

1. 引言：从端到端到大语言模型范式

自动语音识别（ASR）正在经历从传统端到端（E2E）范式——如 Transducer 和 AED——向大音频语言模型（Large Audio-Language Model, LALM）范式的转型。LALM 范式的核心优势在于：模型首先对音频信号形成高层语义理解，再基于该理解生成转录文本，而非仅依赖自底向上的声学模式匹配。这使得长音频转录、噪声鲁棒性、世界知识与命名实体识别、多语言及方言覆盖等传统 ASR 的棘手问题能够被更自然地解决。

本文介绍 Qwen3-ASR 系列，包含三个模型：

模型 参数量 功能 推理模式
Qwen3-ASR-1.7B 1.7B 52 种语言/方言 ASR + LID 离线 / 流式
Qwen3-ASR-0.6B 0.6B 52 种语言/方言 ASR + LID 离线 / 流式
Qwen3-ForcedAligner-0.6B 0.6B 11 种语言时间戳预测 NAR 离线

核心发现：1.7B 版本在开源 ASR 模型中达到 SOTA，与最强商用 API（GPT-4o-Transcribe、Gemini-2.5-Pro、Doubao-ASR）竞争力相当；0.6B 版本提供了最优的精度-效率权衡，TTFT 低至 92ms，并发 128 时 1 秒转录 2000 秒语音。

2. 模型架构

2.1 Audio Transformer (AuT) 与整体架构

Qwen3-ASR 的音频编码器采用 Audio Transformer (AuT)，其架构如下：

  • 输入：FBank 特征，帧率 100Hz
  • AuT 编码器：包含 32 层 Self-Attention Layer + 下采样 Conv2d，将帧率从 100Hz 压缩至 12.5Hz（8 倍下采样）
  • AuT 解码器：8 层 Decoder Cross-Attention + Self-Attention 层，遵循 AED 框架

整体 Qwen3-ASR 流程为：

  1. 预训练的 AuT Encoder 提取隐层音频表示（Hidden, 12.5Hz）
  2. 通过 Projector 映射到 LLM 的输入空间
  3. 与系统提示（含上下文实体列表）拼接后送入 Qwen3 LLM 解码

Qwen3-ASR-1.7B 基于 Qwen3-1.7B LLM 构建；Qwen3-ASR-0.6B 基于 Qwen3-0.6B，搭配 180M 参数的 AuT 编码器（隐层维度 896），专为精度-效率平衡设计。


Figure 2: AuT 编码器架构（左）及 Qwen3-ASR 整体流程（右）。输入音频经 AuT 编码后与上下文实体列表一起送入 Qwen3 LLM 进行自回归解码。

2.2 训练策略

Qwen3-ASR 的训练分为三个阶段：

(1) AuT 预训练

  • 目标：在 AED 框架下获得预训练编码器
  • 数据规模：约 4000 万小时伪标签 ASR 数据（以中英文为主）
  • 效果：在动态注意力窗口下提供通用且稳定的音频表示

(2) Omni 预训练

  • 基础模型：预训练的 Qwen3-Omni
  • 训练数据：多任务音频、视觉、文本数据
  • 训练量：两个模型均使用 3 万亿 tokens 训练
  • 效果：获得多模态理解能力

(3) ASR 监督微调（SFT）

  • 目的：在 ASR 输入/输出格式上进行 style transfer
  • 数据：规模较小的多语言数据（与预训练语料不重叠）
  • 特殊设计：
    • 非语音数据：模型学习识别无人声的音频
    • 流式增强数据：支持流式推理
    • 上下文偏置数据：利用系统提示中的实体列表做 context biasing
    • 仅 ASR 模式：不遵循自然语言指令，防止 instruction injection 和指令跟随失败

输出格式固定为两种模板：

上下文偏置机制允许用户在 system prompt 中放入实体词列表（如”通义””Qwen””Qwen-Omni”），模型在解码时可参考这些实体作为背景知识，从而提升命名实体的识别准确率。

3. Qwen3-ForcedAligner-0.6B：基于 LLM 的非自回归强制对齐

3.1 动机与定位

在实际部署中，ASR 系统往往需要输出时间戳（如字幕生成）。传统方法通常使用 CTC 或 CIF 作为后处理步骤。Qwen3-ForcedAligner 提出了一种基于 LALM 的方案，能在任意时间粒度上产生更准确、更快速的时间戳预测，并借助 LALM 的多语言能力用单一模型覆盖多种语言。

核心优势：

  • 精度：相对于现有强制对齐方法，累积平均偏移（AAS）降低 67%~77%
  • 多语言：单一模型支持 11 种语言，支持跨语言场景
  • 灵活粒度：用户可为任意单词或字符插入时间戳槽位
  • 推理速度：非自回归（NAR）推理，一次性预测所有时间戳

3.2 模型设计


Figure 3: Qwen3-ForcedAligner-0.6B 架构。训练时将随机掩码的时间戳槽位动态插入 token 序列中，表示单词或字符边界。联合序列送入 Qwen3-0.6B LLM，时间戳预测层在每个槽位上预测对应的时间戳索引。

具体流程：

  1. 音频编码：预训练 AuT 编码器处理输入语音，得到语音嵌入
  2. 文本重格式化：在转录文本的每个单词/字符后附加起止时间戳标签，每个时间戳标签替换为特殊 token [time]
  3. 时间戳离散化：将时间戳值除以 AuT 编码器输出的 80ms 帧时长，得到离散索引
  4. 联合处理：语音嵌入和文本嵌入序列拼接后送入 Qwen3-0.6B LLM
  5. 时间戳预测：LLM 输出后接一个线性层，预测每个 [time] 槽位的时间戳索引

3.3 训练策略

伪标签生成：由于人工标注成本过高，训练使用 Montreal Forced Aligner (MFA) 生成的伪时间戳标签。值得注意的是，MFA 伪标签本身包含噪声和系统性偏移。Qwen3-ForcedAligner 并非简单复制 MFA 输出，而是对伪标签进行蒸馏和平滑，使时间戳预测更稳定、偏移更小。

因果训练（Causal Training）：不同于标准 LALM 的 next-token prediction（输出序列与标签序列之间有一个位置的偏移），Qwen3-ForcedAligner 采用非移位的训练方式——输出和标签序列保持对齐，使模型能显式识别时间戳槽位并填充。这种因果训练使模型在预测当前槽位时能利用先前的上下文信息，确保时间戳预测的全局一致性。

损失函数：交叉熵损失仅在时间戳槽位上计算，将训练目标聚焦于时间戳填充。

动态槽位插入策略：训练时对每个单词/字符随机决定是否插入起止时间戳槽位，增强泛化能力。

3.4 推理与可用性

由于训练时 token 序列未偏移，用户可在任意单词/字符后插入起止时间戳槽位，Qwen3-ForcedAligner 使用 NAR 解码一次性预测所有槽位的时间戳索引。最终时间戳 = 索引 × 80ms。

ForcedAligner 推理效率：

4. 实验

4.1 评估设置

基线系统：

  • 商用 API：GPT-4o-Transcribe、Gemini-2.5-Pro、Doubao-ASR
  • 开源模型：Whisper-large-v3、FunASR-MLT-Nano、GLM-ASR-Nano

评估协议（四部分）：

  1. 公开英中基准
  2. 内部鲁棒性测试集（16 种英语口音、22 种中文方言、老人/儿童语音、极端噪声、绕口令、多说话人对话）
  3. 多语言评估（Common Voice、Fleurs、MLS、MLC-SLM 等）
  4. 歌声识别

评估指标：中文及中文方言使用 CER，其他语言使用 WER。

5. 总结

Qwen3-ASR 系列的核心贡献：

  1. 两个全能 ASR 模型（1.7B / 0.6B）：基于 Qwen3-Omni 基础模型和四阶段训练流水线，在 52 种语言/方言上提供 SOTA 级识别性能，覆盖复杂声学环境、口音方言、歌声等场景
  2. 首个轻量级 LLM-based 多语言强制对齐模型：NAR 推理，11 种语言，时间戳精度远超 MFA/NFA/WhisperX，推理速度快
  3. 全部模型以 Apache 2.0 许可开源，并提供统一推理框架

从技术路线来看，Qwen3-ASR 证实了 LALM 范式在 ASR 任务上的全面优势：通过大规模预训练获得的语言模型能力和世界知识，使得噪声鲁棒性、命名实体识别、多语言/方言覆盖等问题不再需要独立的模块或后处理，而是在统一框架内自然解决。ForcedAligner 的成功则进一步表明，LLM 的上下文建模能力即使在非自回归时间戳预测这一看似与语言生成无关的任务上，也能带来显著收益。
