Rethinking Entropy Allocation in LLM-based ASR: Understanding the Dynamics between Speech Encoders and LLMs

本文最后更新于 2026年4月13日 中午

论文链接：arXiv:2604.08003
机构：NIO（蔚来）Advanced Intelligent Systems Group
关键词：LLM-based ASR, Entropy Allocation, Hallucination Mitigation, Multi-stage Training

1. 研究动机与核心问题

当前 LLM-based ASR（以下简称 LLM-ASR）已成为语音识别的主流范式。Seed-ASR、FireRedASR-LLM、Voxtral Mini Transcribe、Fun-ASR、Qwen3-ASR 等模型通过将语音编码器与大语言模型耦合，利用 LLM 的世界知识和上下文推理能力来消解语义歧义，在公开 benchmark 上取得了显著成果。

然而，LLM-ASR 在实际部署中面临两个根本性挑战：

  1. 效率与识别质量的权衡：在轻量化设置下，LLM-ASR 不仅面临缩放退化，还需要承担弥合语音-文本模态鸿沟的隐性开销。这种开销会消耗非平凡的模型容量，对小模型造成不成比例的负担。
  2. 幻觉（Hallucination）问题：在联合训练过程中，编码器容易被 LLM 梯度所主导，导致表征漂移（representation drift）——编码器逐渐依赖语言捷径而牺牲声学保真度，放大幻觉风险。

本文从熵分配（entropy allocation）的视角重新审视 LLM-ASR，将 ASR 任务视为将高熵语音信号压缩为低熵语言符号的过程。在此视角下，编码器和 LLM 在一个”零和熵预算”下运作：编码器吸收的不确定性越多，LLM 需要解决的就越少。

2.4 度量揭示的两种次优模式

通过对两组代表性 ASR 模型族进行度量对比（保持编码器架构不变以隔离联合训练的影响），论文揭示了两种截然不同的次优行为模式：

模式一：FireRedASR-AED → FireRedASR-LLM

  • NSE 显著下降（86.8% → 85.1%）：编码器承担了更多熵缩减
  • PAI 下降（23.50 → 21.60 bits）、CSAI 上升（11.37 → 12.25 bits）：压缩并非来自声学信息的精炼，而是编码器偏离了音素专业化方向，转向语义可达性——这正是表征漂移的特征

模式二：Whisper-large-v3 → Voxtral-Mini-3B

  • 三个指标在联合训练前后几乎不变（NSE: 90.2% → 90.2%，PAI: 20.10 → 20.05，CSAI: 10.69 → 10.68）
  • 相比 FireRedASR，NSE 更高但 PAI 和 CSAI 更低：编码器承担的熵缩减负载很轻，更多残余不确定性被推给了 LLM
  • 虽然缓解了表征漂移，但增加了 LLM 的容量需求，迫使 LLM 在其主要建模优势之外解决音素级不确定性，导致参数效率低下

3.2 设计原则

基于度量分析揭示的两种次优模式，论文提出了能力边界感知（capability-boundary-aware）的设计原则，包含两个核心要求：

  1. 编码器应在暴露于 LLM 主导的联合优化之前，先被引导向低熵、声学锚定的表征。这可以提前收窄模态鸿沟，降低后续训练诉诸语义偏差捷径的风险。
  2. 在联合优化过程中，模块间的功能边界应被显式维护，确保编码器的进一步压缩沿声学锚定方向进行，而非以声学表征质量为代价。

3.3 多阶段训练流水线

如图所示，与传统的”预训练 → 对齐 → 联合 SFT”三阶段流水线相比，本文的设计包含两个核心创新：音素级 CTC 预训练和迭代异步 SFT（IA-SFT）阶段。

3.3.1 音素级 CTC 预训练

编码器骨干继承自 FireRedASR-AED 的权重（Conformer 架构，约 600M 参数），将自回归解码器替换为轻量级三层 MLP CTC 头，采用 CR-CTC 目标训练。关键设计选择：

  • 采用音素级而非词级/字级监督：音素表征提供更通用、更具声学锚定性的接口。
  • 选择 CTC 而非 AED 或自监督目标的两个结构性考量：
    • CTC 目标通过其 peaky 行为和单调对齐约束，鼓励编码器将连续语音压缩为更接近底层 token 序列的表征，弥合与离散文本的结构鸿沟
    • 轻量级 CTC 头充当容量瓶颈，推动编码器走向低熵表征
  • 这些特性在表征层面收窄语音-文本模态鸿沟，同时低熵接口减轻下游 LLM 的容量需求。

3.3.2 对齐与迭代异步 SFT（IA-SFT）

传统流水线中，对齐和联合 SFT 在预训练完成后顺序执行。本文在对齐和联合 SFT 之间引入 IA-SFT 阶段，且对齐和 IA-SFT 与预训练异步并行进行，无需等待预训练完成。

具体流程：

(1) 对齐阶段：预训练运行足够步数后，快照编码器作为参考检查点。持续监控 CKA 分数，当首次降至预设阈值以下时，取新快照初始化对齐阶段的编码器并更新参考检查点。对齐期间编码器和 LLM 均冻结，仅训练适配器。

(2) IA-SFT 阶段：对齐完成后进入 IA-SFT，编码器冻结，适配器和 LLM 联合训练。核心机制是 CKA 驱动的迭代编码器热替换：每当 CKA 分数降至阈值以下，将正在进行的预训练中的最新编码器检查点热替换到 IA-SFT 模型中，并更新参考检查点。CKA 约束确保每次替换都带来非平凡的表征演化，使 LLM 以课程学习的方式从逐步精炼的编码器中学习。

IA-SFT 的核心优势：

  • 维护功能解耦：限制编码器向 LLM 语义流形漂移的倾向
  • 多编码器视角的正则化：迭代更新的编码器具有不同的声学线索偏好模式，IA-SFT 以课程学习方式暴露 LLM 于不同信噪比级别的表征，鼓励 LLM 关注跨编码器状态一致的声学特征
  • 并行化和效率：将顺序的预训练和 SFT 转化为异步并行过程，显著减少总训练时间
  • 灵活性和可迁移性：功能解耦使编码器同时兼容 CTC 头和 LLM 解码器

3.3.3 联合 SFT

IA-SFT 结束后进入联合 SFT，所有模块端到端训练。此时模态鸿沟已被最小化，语音表征的声学锚定特性得到保持，LLM 已建立稳健的音频表征理解能力——这些共同降低了联合训练期间的表征漂移风险。

3.4 度量动态的实证分析

论文追踪了各训练阶段的度量变化，并与 FireRedASR-AED → FireRedASR-LLM 的直接转换路径做对比：

音素级 CTC 预训练阶段：

  • NSE 显著下降——CTC 瓶颈迫使编码器形成紧凑的低熵表征
  • PAI 下降但并非声学信息损失，而是 CTC peaky 分布的结构性后果：编码器表征偏向离散化符号形式，在池化和 PCA 后稀释了全局可达的线性音素结构
  • CSAI 温和上升，因为单调对齐逐步推动表征走向更细粒度的 token 级分辨率
  • 与字级预训练对比，音素级预训练始终具有更高的 PAI 和更低的 CSAI，表明在建立稳健声学基础的同时抑制了编码器中的过早语义锚定

联合 SFT 阶段：

  • NSE 继续下降——端到端优化进一步驱动编码器走向更低熵表征，逐步减轻 LLM 的下游容量压力
  • 关键模式：PAI 显著恢复而 CSAI 保持平坦或略微下降——这与设计预期一致。由于联合优化始于已经收窄的模态鸿沟和良好对齐的接口，LLM 梯度激励编码器精炼音素-声学表征而非利用语言捷径，编码器避免吸收应委托给 LLM 的语义功能
  • 消融 IA-SFT（绿色曲线）：NSE 衰减更慢，PAI 和 CSAI 均收敛到更低的最终值——证实了线性可达性在声学和语义维度的退化，验证了 IA-SFT 作为”表征缓冲器”的关键作用

5. 实验

5.1 训练数据

训练语料总计约 560K 小时标注语音-文本对，覆盖英文和中文（含方言）。主要数据源包括 YODAS-Granary（120K h）、Emilia（189K h）、MLS（45K h）、LibriHeavy（50K h）、PeopleSpeech（30K h）、WenetSpeech-Yue（22K h）等，以及约 50K 小时的内部数据。所有训练阶段使用相同语料，仅训练步数和目标函数不同。

5.2 训练配置

阶段 批大小（帧） 最大学习率 调度策略
预训练 20K 5.0e-4 线性 warmup 8K 步 + 指数衰减
对齐 10K 1.0e-3 线性 warmup + 指数衰减
IA-SFT / 联合 SFT 7K 1.0e-5 线性 warmup + 指数衰减

所有阶段使用 Adam 优化器，NVIDIA A100 80GB GPU，DeepSpeed ZeRO Stage-2，4 步梯度累积，bfloat16 精度，FlashAttention-2。

5.3 IA-SFT 的 CKA 驱动编码器更新调度

CKA 阈值设为 $\tau = 0.975$。具体调度如下：

预训练步数 触发条件 动作
0–0.5M — 预训练开始，0.5M 步初始化参考检查点
0.5M–1.01M CKA < 0.975 1.01M 步时快照更新参考检查点并初始化后训练编码器；启动对齐阶段（130 万步）
1.01M–1.32M CKA < 0.975 1.32M 步时快照更新参考检查点和 IA-SFT 编码器
1.32M–2.00M — 预训练结束；最终快照更新 IA-SFT 编码器
— — IA-SFT 结束后进入联合 SFT（200 万步）

编码器热替换之所以无需重新对齐，是因为：(1) 预训练和 SFT 针对相同的有监督 ASR 任务，优化方向一致；(2) CKA 分数在预训练过程中始终较高，表明编码器主导子空间具有实质性的相似性——后续预训练主要在减少声学冗余和精炼声学偏好，而非重塑全局流形。

幻觉可被解释为两种失败模式：

  1. 语义污染的编码器表征：联合优化使编码器表征与文本相关的规律性对齐，部分不确定性缩减通过非声学锚定的模式实现——接口变得对转录更具预测性但失去了对声学变异的鲁棒性
  2. LLM 主导的不确定性缩减：编码器提供弱/结构不充分的接口时，通过贝叶斯分解 $p(Y|Z) \propto p(Z|Y)p(Y)$，似然项 $p(Z|Y)$ 信息量不足，后验越来越被先验 $p(Y)$ 所塑造——模型生成语言上合理但不被语音信号支持的输出

7. 总结

本文的核心贡献在于：

  1. 提出了 LLM-ASR 的熵分配视角，以 NSE、PAI、CSAI 三个度量刻画编码器与 LLM 之间的熵缩减分配动态
  2. 提出能力边界感知的多阶段训练范式，通过音素级 CTC 预训练建立声学锚定的低熵接口，通过 IA-SFT 显式维护功能解耦并约束表征漂移
  3. 仅 2.3B 参数即在中英文 ASR benchmark 上取得领先性能，同时有效缓解幻觉问题

从工程实践角度，本文提供了一个清晰的诊断框架：当你的 LLM-ASR 系统出现幻觉或参数效率低下时，可以通过 NSE/PAI/CSAI 三个度量来定位问题出在编码器端还是 LLM 端，进而针对性地调整训练策略。IA-SFT 的异步并行设计也为大规模工业训练提供了时间效率上的实际收益。
