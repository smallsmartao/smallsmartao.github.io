LongCat-Next: Lexicalizing Modalities as Discrete Tokens

本文最后更新于 2026年4月8日 下午

美团 LongCat 团队于 2026 年 3 月发布的技术报告，提出了 DiNA（Discrete Native Autoregression） 统一多模态离散自回归范式，以及对应的视觉分词器 dNaViT，在单一模型内实现了文本、视觉、音频的原生统一建模。

arXiv: 2503.xxxxx
GitHub: meituan-longcat/LongCat-Next
HuggingFace: meituan-longcat/LongCat-Next

1 引言

大型语言模型（LLM）已在 Next Token Prediction（NTP）范式下取得了显著成功。然而，现有多模态系统仍以语言为中心，将视觉、音频等非语言模态作为外挂附件，导致架构碎片化、多模态集成效果不佳。

本工作从一个根本性问题出发：如何在统一的离散 token 空间中表示并建模所有模态？

如果将多模态类比为语言的自然延伸，则问题简化为：所有模态均表示为由单一自回归目标统治的可互操作 token 序列。核心挑战是为每种模态设计「分词器—逆分词器」（tokenizer–detokenizer）对。

主要贡献：

  1. Discrete Native Autoregression（DiNA）范式：将 NTP 从语言扩展到原生多模态，所有模态共享同一离散 token 空间与自回归目标，保持 decoder-only 架构简洁性。
  2. dNaViT（Discrete Native-Resolution Vision Transformer）：以语义完备性为核心原则的视觉分词器，支持任意分辨率的视觉理解与生成，打破离散视觉建模的性能天花板。
  3. 统一多模态工业级模型 LongCat-Next：基于 MoE backbone（A3B，总参数 68.5B），在视觉理解、图像生成、音频理解与语音合成四大方向均达到竞争力水平。

2 方法论

2.1 模型架构

LongCat-Next 整体遵循 DiNA 设计哲学：

  • 模态特定分词器/逆分词器：负责原始信号与离散 ID 之间的转换，固定于大规模训练之前。
  • 模态无关的 MoE backbone：将所有离散 ID 视为统一 token，执行多任务学习，无需模态特定分支。
  • 文本、视觉、音频在同一自回归目标下训练，differing only in conditional prior。

2.2 视觉分词器

2.2.1 设计动机

语言分词器实现了近无损的离散压缩，文字天然是紧凑离散的单元；而视觉信号高维连续、信息密度极高。现有方案的问题：

方案类别 代表工作 优势 不足
低层重建模型 VAE、VQ-VAE 像素级保真度高 高层语义理解差
自监督语义编码器 DINOv2、SigLIP 结构/对比特征强 缺乏生成重建能力
无编码器像素 tokenization EVE 系列、NEO 简单可扩展 像素冗余严重
语义对齐编码器（SAE） QwenViT、MoonViT、AIMv2 语义丰富+生成充分 本文聚焦

本文提出的核心原则是语义完备性（Semantic Completeness）。

2.2.2 语义对齐编码器（SAE）

定义：给定图像 $I$ 和查询 $Q$，若离散表示 $z = {idx_1, \ldots, idx_n}$ 满足：

则称 $z$ 满足语义完备性。该等价关系蕴含两个属性：

  • 判别不变性（Discriminative Invariance）：量化过程不应降低下游判别性能。
  • 生成充分性（Generative Sufficiency）：离散码 $z$ 应提供足够的语义描述，使逆分词器 $\mathcal{D}(\cdot)$ 能够重建结构与纹理内容（$I’ \approx \mathcal{D}(z)$）。

SAE 的训练目标为多方面视觉-语言对齐：

在实践中，现有视觉-语言预训练模型（如 QwenViT、MoonViT、AIMv2）可直接作为 SAE 近似使用，无需从头训练。

2.2.3 分词（Tokenization）

SAE 提供了语义完备的连续流形，离散化采用残差向量量化（Residual Vector Quantization，RVQ）：

  • $r_0$：投影后的潜在表示
  • $\hat{q}_l$：第 $l$ 层量化特征
  • $r_l$：第 $l$ 层残差误差
  • $\hat{z}$：最终量化表示

码本更新采用指数移动平均（EMA）：

其中 $N_k \leftarrow \gamma N_k + (1-\gamma)|S_k|$，$m_k \leftarrow \gamma m_k + (1-\gamma)\sum_{j \in S_k} r_j$，$\gamma$ 为衰减因子。

量化目标为：

其中 $\mathcal{L}_{\text{commit}}$ 为标准承诺损失，$\mathcal{L}_{\text{semantic}}$ 为基于余弦相似度的语义重建损失。

本地分辨率分词的两大优势：

  1. 语义结构化：离散 token 继承视觉-语言预训练的自然关联性。
  2. 原生分辨率：直接在编码器原生分辨率的潜在表示上操作，支持任意输入分辨率。

2.2.4 逆分词（De-tokenization）

分词训练完成后，SAE 编码器与码本均被冻结。逆分词器以一个像素解码器为核心（400M 参数的 ViT，从零训练），训练目标为：

为进一步改善视觉保真度（减少过度平滑问题），引入基于 flow matching 的图像精修器（Image Refiner），以像素解码器重建结果和离散码嵌入为条件，聚焦于高频纹理细节的增强。

关于信息恢复的讨论

一个有趣的发现：即使是随机初始化的 ViT-Base 也具备强重建能力，甚至优于预训练版本。原因在于现代视觉编码器的残差架构天然保留了低层信号传播的潜在通道：

恒等映射 $x_{l-1}$ 确保早期层的细粒度视觉信号不被高层语义抽象覆盖，而是通过网络逐步积累进入 $z_p$，使其与原始图像保持高互信息 $I(I; z_p)$。

各编码器重建性能定量对比：

指标 ResNet50 ViT-B/16（预训练） ViT-B/16（随机初始化） QwenViT（w/o merger）
PSNR ↑ 20.88 ± 3.44 21.86 ± 3.14 30.52 ± 3.42 18.16 ± 2.61
SSIM ↑ 0.509 ± 0.174 0.581 ± 0.139 0.887 ± 0.051 0.46 ± 0.14

随机初始化 ViT 的输出类噪声信号反而易于解码器去噪，而其残差路径仍保留部分原始像素信息。

2.2.5 dNaViT：离散原生分辨率视觉 Transformer

dNaViT 的核心设计目标是扮演语言分词器在 LLM 中的角色：

  • 任意分辨率：直接在原始分辨率上操作，避免缩放/裁剪/填充引入的信息损失。
  • 层级离散 token：编码多语义层级信息，同时保留全局结构与局部细节。
  • 语言式视觉词汇表：图像表达为离散符号序列，直接兼容自回归建模。
  • 原生视觉表示：视觉码本嵌入随机初始化，与语言 token 在统一自回归目标下共同演化，形成模型内部原生视觉语义空间。

自回归建模时，采用多层 token 加法编码（additive encoding）和 DepthTransformer 高效解码，实现指数级表示空间与单步自回归计算效率的兼顾。

2.3 音频分词器

音频分词器将连续语音转换为保留语义与声学信息的离散 token：

  1. Whisper 编码器提取音频特征（初始化自 Whisper-large-v3）
  2. 特征经 4× 下采样后，由 8 层 RVQ 量化为离散 token（码本大小：8k, 4k, 2k, 1k×5）
  3. 并行两路：
    • 路径一：送入冻结 LLM（Qwen3-1.7B）进行语义与声学对齐训练（训练后丢弃）
    • 路径二：经对称解码器重建粗 Mel 频谱，再由 flow matching 精修器细化，最后通过声码器合成波形

训练目标：

训练语料约 250 万小时，分三阶段：

  1. 阶段1：解码器热身（编码器和 LLM 冻结）
  2. 阶段2：语义-声学联合训练（启用 RVQ）
  3. 阶段3：解码器微调（重配置为 DiT 去噪模块，处理 24kHz 高质音频）

2.4 语言模型 Backbone

采用 LongCat-Flash-Lite A3B 作为 decoder-only backbone：

  • 总参数 68.5B，平均激活 3B（范围 2.9B–4.5B）
  • 采用 Zero-Expert 与 Shortcut MoE 架构
  • 模态无关（modality-agnostic）：所有 token（文本、视觉、音频）经过同一 MoE 路径，无模态特定分支、无 3D RoPE、无双向注意力

2.5 多模态组件

2.5.1 端到端多模态嵌入

  • 视觉嵌入：码本大小 $8 \times 16384$，多层 token 通过多层求和融合（不跨层共享，各层捕获互补信息）
  • 音频嵌入：设计与视觉类似，但码本大小递减（对应 RVQ 各层）
  • 所有嵌入随机初始化，端到端联合训练，不依赖预量化特征值

2.5.2 多模态 Head

  • LLM head：标准 MLP（执行单步自回归预测）
  • 多模态 token 解码：DepthTransformer（任务感知，并行生成多层输出以恢复视觉/音频细节）

2.5.3 内部语言引导（Internal Linguistic Guidance）

受 Moshi 启发，提出文本引导音频模态（text-guided audio modality），将段级对齐的文本 token 与音频 token 分别嵌入后逐元素求和融合，实现内部语言引导。

与之对应，用户实时输入（通常无文本引导）定义为纯音频模态（pure audio modality）。

两种生成策略（图7）：

策略 原理 优势
并行生成（Parallel） 每步同时生成文本与音频 token，首个音频 token 延迟指定步数 消除响应延迟，适合全双工
串行生成（Serial） 先生成引导文本段，再生成对应音频段 每步单模态预测，语言质量更高

统一训练范式：对每个对齐文本-音频段，延迟步数从 1 随机选取至文本段长度，使模型学习鲁棒的语义对齐，串行/并行生成成为该统一框架的两个极端情形。

3.2 方法论实验分析

3.2.1 弥合离散与连续建模的理解差距

通过预对齐阶段实验，系统比较了离散 dNaViT 与连续 NaViT 的性能差距：

ID 表示类型 PT Tokens MT&SFT Tokens Pre-Buffer OCRBench DocVQA ChartQA MMMUval MathVista
I 连续 0.1B 4B — 779 88.2 80.1 49.8 59.6
II 离散 0.1B 4B ✓ 598 78.0 71.6 44.8 47.3
III 连续 5B 4B — 776 88.9 80.6 49.1 56.1
IV 离散 5B 4B ✓ 720 86.7 76.8 48.0 54.2

VI 连续 5B 300B — 858 96.0 84.0 58.0 75.0

关键洞察：

  1. 初期差距：离散表示初始对齐损失更高，收敛较慢。
  2. Pre-Buffer 模块（单层 FFN）：在多层 token 求和后重编码，显著加速收敛，提升离散 token 表达力。
  3. 数据规模弥合差距：Exp VI vs VII 表明，大规模数据下离散模型可达到与连续模型近乎相同的性能——离散建模本身并无固有天花板。

在相同实验设置下训练三类模型（各约 100B tokens）：

3.2.5 模态无关 MoE 的训练动态

在从纯语言模型演化为原生多模态架构的过程中，MoE 层内部出现显著变化：

  • 部分专家逐渐功能特化，对特定模态产生明确偏好
  • 路由机制变得更结构化，专家选择模式更清晰稳定
  • 多模态训练后，每个专家处理的平均 token 数从 507.1 增至 584.6，模型容量利用率提升

4 实现细节

4.1 训练阶段

4.1.1 视觉分词器

直接采用 Qwen2.5-ViT（28× 空间压缩比）作为 SAE 编码器（绕过大规模 SAE 训练）。

阶段 1：视觉分词

  • 采用 FlashAttention 支持变长序列（最大 8192 tokens）
  • 两阶段：固定分辨率（快速收敛）→ 任意分辨率 RVQ 训练
  • 训练数据：LAION、COYO、DataComp、TextAtlas + 内部视觉理解数据 + MidJourney 高保真合成数据
  • 约 5000 万张图片，最大分辨率 1736×1736

阶段 2：视觉逆分词

  • 像素解码器：400M 参数 ViT，带 2D RoPE 位置编码，从零训练
  • 图像精修器：从 OmniGen2 初始化，flow-matching 损失继续训练
  • 精修器条件：(1) 像素解码重建结果（空间引导）(2) 离散码嵌入（语义条件）

4.1.2 音频分词器

见第 2.3 节三阶段训练方案，训练语料约 250 万小时。

4.2 视觉理解数据

4.2.1 数据收集

  • 图像描述数据：三阶段清洗流水线（启发式过滤 → LVLM 重标注 → SigLIP 相似度剪枝）
  • 交错图文数据：Web 页面图文对（CLIP 过滤）+ 视频场景关键帧（ASR+OCR 提取文本）
  • OCR 数据：75% 内部合成 + 25% 真实数据，来自 90+ 开源数据集，涵盖文档/图表/场景/合成文本
    • 合成策略：SynthDoG、LaTeX，处理艺术字体、手写、形变等挑战场景
  • STEM 数据：60% 开源（70+ 数据集）+ 40% 专有/合成，构建结构化推理链
  • GUI 数据：数万并发会话自动采集原始交互轨迹，结合 UI-TARS/EvoCUA 方法精炼
  • 视觉定位与计数：10+ 公开源聚合（约 6000 万样本）+ 800 万计数样本

4.2.2 数据清洗、过滤与采样

  • 去污与去重：pHash 图像匹配 + N-gram 文本重叠检测，语义级聚类去重
  • 质量过滤：规则过滤（去除链接/格式错误/冗余推理）+ 模型打分（LLM-as-a-judge）
  • 数据采样：按难度、推理长度、多样性动态调整采样比例，防止单源过拟合

4.3 视觉生成数据

针对 Web 数据高频模式主导、长尾语义密度不足的问题，设计三阶段数据策略（共约 3 亿图文对）：

4.3.1 阶段 I：预训练

  • 多级过滤：SigLIP 去重 + 分辨率/宽高比/HPS v3 质量控制 + 水印/AIGC 检测
  • 结构化重标注：Qwen3-VL-8B 生成概述+细节+标签的层级描述；文本丰富图像额外整合 OCR 信号

4.3.2 阶段 II：中期训练——基于聚类的再平衡

  • SigLIP2 编码 + FAISS 分布式 K-Means 聚类（百万级语义簇）
  • 簇内去重 + 幂律再权重（提升稀疏簇采样概率），有效扁平化数据分布

4.3.3 阶段 III：有监督微调

  • 聚类代表样本 + 高美学数据（专业摄影/数字艺术）+ 文本丰富数据（合成排版/OCR 场景）
  • 为文本渲染提供密集监督信号

5 基础设施

5.1 基于 VHalf 的流水线并行

多模态模型计算异质性明显：嵌入层与模态特定损失模块（DepthTransformer）的执行时延与 LLM transformer 层差异显著，且随批次中模态分布动态变化，导致标准流水线严重不平衡。

VHalf-based Pipeline Parallelism 设计：

  1. V 形调度：将第一计算阶段（嵌入层）与最后计算阶段（模态损失模块）同置于同一物理设备，吸收异质计算开销。
  2. 共享缓冲区：V 形第一阶段构建共享 buffer，模态损失模块可直接访问 RVQ 多层 token 对应的隐状态，无需跨阶段通信。
  3. LLM Head 独立：从模态损失模块中解耦，与少量 LLM transformer 层分配到独立 pipeline stage，防止锚定设备过载。

收益：

  • 消除流水线 Bubble：异质计算开销被 V 形调度有效吸收，近完美负载均衡
  • 消除跨阶段通信：嵌入层与模态损失模块同设备，前向激活与反向梯度均通过零拷贝设备内内存访问解决

6 强化学习与未来工作

6.1 强化学习

离散视觉潜在空间天然适合 RL：作为有限 MDP 结构的动作空间，与 GRPO 等语言 RL 方法无缝兼容，无需 ODE-to-SDE 转换。

文本生成图像的 RL：给定输入提示，策略生成离散 token 序列后由冻结解码器生成图像，多维奖励模型计算标量奖励。

多级 GRPO 目标（跨 RVQ 各层加权）：

四维奖励模型：

  1. 综合能力增强（对象计数/颜色准确性/空间定位/属性一致性）
  2. OCR 能力增强（GOT-OCR 2.0 识别，编辑距离衡量文本保真度）
  3. 文本-图像语义对齐（VLM 判断提示描述与生成图像的概念对齐）
  4. 图像质量评估（HPS v3 + 美学分数 + 统一奖励）

图像理解的 RL——熵爆炸问题及解决方案

RL 训练图像理解时面临严重的熵爆炸问题：策略熵与训练-推理不一致度正相关增长，低概率 token 进入训练数据后通过正反馈循环急剧放大。

提出序列级过滤机制：

  • 熵过滤：序列熵超过批均值 $n$ 个标准差则剔除
  • 训练-推理差异过滤：序列中任意 token 的采样策略与训练策略概率差超过阈值 $\delta$ 则剔除

6.2 讨论与未来工作

  1. 视觉分词器：当前版本 de-tokenizer 侧重语义一致性而非像素保真度，未来将进一步优化。
  2. 超越理解与生成：目标是泛化至任意模态组合的 any-to-any 生成与多模态交错推理。
  3. 数据扩展与表示学习：连续预训练范式不能直接迁移至离散建模，需协同设计数据、预训练目标与离散化策略。

7 结论

LongCat-Next 以工业级规模验证了离散原生自回归范式（DiNA）的可行性：通过精心设计的视觉/音频分词器和统一训练策略，连续感知信号可被有效离散化，同时保持强大的理解与生成能力。关键结论：

  • 离散视觉建模无固有性能天花板，其性能主要受训练数据规模与质量约束
  • 理解与生成并不冲突，统一自回归目标下两者互相促进
  • 模态无关 MoE 在多模态训练后自发产生功能特化，容量利用率显著提升
  • Platonic 表示假说得到支持：原生离散训练使视觉与文本 token 在嵌入空间中深度交融

附录补充

A.1 RL 训练-推理不一致性分析

实验发现熵爆炸触发器：单序列内仅需极少数（甚至 1 个）异常 token（采样策略概率 > 0.4 而训练策略概率 < 0.01）即可引发灾难性序列质量崩溃。Truncated/Multiple Importance Sampling 等方案仅延迟爆炸，未根治。token 级概率差过滤（阈值 $\delta$）是最有效的直接干预。

A.2 离散量化策略对比

实验确认：

  • 2 层 RVQ 略优于 vanilla VQ
  • 8 层 RVQ 特征重建损失显著更低
  • 8 层 RVQ 在信息损失与计算开销间达到最优权衡，作为默认配置

A.3 视觉逆分词器分析

像素解码器单独可恢复图像语义内容与空间结构，但细节偏平滑；精修器（flow-matching refiner）在保持语义一致性的同时有效恢复高频纹理细节。
