Evaluation of Automatic Speech Recognition Using Generative Large Language Models

本文最后更新于 2026年4月24日 下午

论文信息

  • 标题: Evaluation of Automatic Speech Recognition Using Generative Large Language Models
  • 机构: Idiap Research Institute 等
  • arXiv: 2604.21928

引言：WER 为何不够用？

自动语音识别（ASR）系统的评估长期以来几乎被一个单一指标所统治——词错误率（Word Error Rate, WER）。WER 通过计算参考转录与假设转录之间的编辑距离（插入、删除、替换操作数）来衡量系统性能，计算简单、可复现，因此成为事实标准。

然而，WER 的根本缺陷在于：它是一个纯词级的操作性指标，完全不具备语义感知能力。一个仅含无害填充词（如”呃”）的假设与一个语义完全偏离的假设，在 WER 眼中可能获得相同的分数。更关键的是，多项研究已证明 WER 与下游任务表现以及人类主观感知之间的相关性均不理想。

本文的核心动机正源于此：能否利用生成式大语言模型（LLM）来替代或补充传统指标，使 ASR 评估更接近人类的感知判断？作者通过三条实验路线系统地回答了这一问题。

相关工作

2.1 WER 的局限性

WER 的计算基于 Levenshtein 编辑距离，将所有词级错误等权对待。这意味着：

  • 一个无意义的替换（如将”银行”识别为”冰棒”）和一个近义替换（如将”银行”识别为”银号”）在 WER 中产生相同的惩罚；
  • 填充词、犹豫音等对语义无影响的插入也被全额计入错误；
  • WER 与下游任务（如机器翻译、信息抽取）的性能相关性较弱，与人类对转录质量的主观感知亦存在显著偏差。

这些局限性催生了对更具语义感知能力的评估指标的需求。

2.2 基于嵌入的语义指标

为弥补 WER 的语义盲区，研究者提出了基于预训练语言模型嵌入的语义距离指标。代表性工作包括：

  • BERTScore：利用 BERT 系列模型的上下文嵌入，通过 token 级别的余弦相似度匹配来计算参考与假设之间的相似性；
  • SemDist（Semantic Distance）：将参考和假设分别编码为句子级嵌入向量，通过余弦距离衡量语义偏差。

这类指标在捕获语义信息方面明显优于 WER，但其性能受限于底层编码器模型的表征能力，且主要依赖 encoder-based 模型（如 CamemBERT、BERT），尚未系统探索 decoder-based LLM 的潜力。

2.3 人类感知与可解释性评估

为建立评估指标与人类判断之间的可靠对标基准，研究者构建了 HATS（Human Annotations for TTS and STT）数据集。该数据集包含大量配对的 ASR 假设，每对假设均经由多名标注员判断哪个更接近参考转录。标注员之间的一致率被记录下来，可据此划分不同置信度的子集（如 100% 一致、≥70% 一致等），为指标评估提供了有梯度的金标准。

实验

3.1 利用 LLM 选择最佳假设

实验设计：给定一条参考转录和两个候选假设 A、B，要求 LLM 判断哪个假设更接近参考。采用 one-shot prompt，包含一个标注示例，随后给出待预测样例。模型被明确要求先阐述推理过程（chain-of-thought），最后以”A”或”B”作结。

Prompt 格式如下（翻译自原文）：

User: 参考文本是音频的精确转录。现提供两个不正确的假设。请解释推理过程，并在最后写出”A”或”B”。
Reference: it’s to him self
Hypothesis A: are to him self
Hypothesis B: it’s uh to him-self

Assistant: 尽管假设 B 包含填充词”uh”，但它在词汇和语义上与参考更为吻合。填充词若属于原始语音的一部分是可以容忍的，而假设 A 的语法错误则更为严重。因此，最可接受的转录是假设 B。

3.2 基于 Decoder LLM 嵌入的语义指标

本节探索使用 decoder-based LLM 的隐层表示来计算 SemDist 指标。核心挑战在于：decoder 模型输出的是 token 序列的嵌入，需要通过 pooling 操作将其聚合为单一的定长向量。

Pooling 策略

设 $t_i$ 为第 $i$ 个 token 的嵌入，$n$ 为序列长度，作者比较了以下 7 种 pooling 方法：

  • Last token: 取最后一个 token 的嵌入 $t_n$
  • Second-to-last: 取倒数第二个 token 的嵌入 $t_{n-1}$
  • Mean: 所有 token 嵌入的算术平均
  • Mean without last token: 排除最后一个 token 后的均值
  • Weighted mean: 按位置加权平均，越靠后的 token 权重越大
  • Weighted mean without last: 排除最后一个 token 的加权均值
  • Mean of last 4 tokens: 最后 4 个 token 嵌入的均值

关键发现：

  1. Last token pooling 普遍表现最差（平均 74%），这与 decoder 模型中最后一个 token 嵌入承载”下一 token 预测”功能有关，其表示偏向于预测而非概括整句语义。
  2. Mean pooling 和加权均值表现稳健（平均 80-81%），是通用 decoder 模型的合理默认选择。
  3. 经过嵌入任务微调的模型（Qwen3-Embedding 系列）全面领先，其中 Qwen3-Embedding-8B 在所有 pooling 策略上均达到 87-89% 的一致率，且在 last token pooling 上也达到 88%——这说明微调有效地将最后一个 token 的表示转化为了全局语义表征。
  4. 指令微调的聊天模型（如 Qwen3.5-35B）在嵌入任务上反而表现不佳，可能因为指令微调改变了隐层表示的分布。

3.3 利用生成式 LLM 对假设进行定性分类

在第三组实验中，作者进一步探索 LLM 的定性评估能力：要求模型将每个 ASR 假设分类为以下四个类别之一：

  • identical：与参考完全一致
  • useful：虽有差异但不影响理解
  • bad：存在明显错误，影响理解
  • incomprehensible：完全无法理解

该分类方案使得评估不再局限于二元比较，而是提供了可解释的质量等级。

箱线图清晰表明，LLM 赋予的类别标签与 SemDist 数值之间存在高度一致的单调关系：”identical” 类别对应最低的 SemDist（即最高的语义相似度），随着类别从”useful”到”bad”再到”incomprehensible”，SemDist 值逐步升高。这验证了 LLM 的定性分类与数值化语义指标具有内在一致性，同时为 ASR 评估提供了传统指标所不具备的可解释性维度。

结论

本文系统地证明了 decoder-based 生成式 LLM 在 ASR 评估中的三重价值：

  1. 假设选择：通过 chain-of-thought prompting，最佳 LLM（GPT-4.1, 94%；Qwen3.5-35B, 92%）在与人类感知的一致率上远超 WER（63%）和语义指标（SemDist Sentence, 90%）；
  2. 语义嵌入：decoder LLM 的隐层表示经适当 pooling 后可用于计算 SemDist，其中经嵌入微调的 Qwen3-Embedding-8B 达到 89% 的一致率；
  3. 定性分类：LLM 能够对假设进行有意义的质量分级，其分类结果与连续语义指标高度一致。

这些发现意味着 LLM 不仅可以作为 ASR 评估的新工具，还能在自动标注、系统间相对比较等场景中发挥独特作用。尤其值得关注的是，开源模型已展现出与闭源模型相当的评估能力，为低成本、可复现的 ASR 评估提供了可行路径。
