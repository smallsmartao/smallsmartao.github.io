Phonemes vs. Projectors: An Investigation of Speech-Language Interfaces for LLM-based ASR

本文最后更新于 2026年4月15日 上午

论文信息

  • 标题: Phonemes vs. Projectors: An Investigation of Speech-Language Interfaces for LLM-based ASR
  • 作者: Ziwei Li, Lukuang Dong, Saierdaer Yusuyin, Xianyu Zhao, Zhijian Ou (清华大学 SPMI Lab & TasiTech)
  • 链接: arXiv:2604.09332
  • 会议: Interspeech 2026 (投稿)

1. 为什么需要这项研究？

将预训练语音编码器（Large Acoustic Models, LAMs）与大语言模型（LLMs）组合用于 ASR，已成为当前语音识别研究的主流范式。在这一架构中，语音-语言接口（speech–language interface）是连接声学感知与文本生成的关键枢纽，直接决定识别性能与数据效率。

现有接口大致可分为两类：

  1. 连续接口（Projector-based）：通过可学习的投影器将编码器输出映射到 LLM 的嵌入空间，LLM 以连续向量序列为条件生成文本。
  2. 离散接口（Phoneme-based）：先将语音转写为音素序列，再将音素作为类文本 token 输入 LLM，由 LLM 完成音素到字素的转换。

二者各有理论优势：连续接口保留了完整的声学信息，但需从配对数据中学习跨模态对齐；离散接口提供了语言学上有根据的中间表示，天然对齐 LLM 的文本输入空间，但引入了不可逆的信息压缩。然而，在相同编码器和 LLM 骨架下对两类接口进行受控比较的工作几乎缺席——这正是本文要填补的空白。

2.3 BPE-Phoneme 接口

单音素序列不包含词边界信息。本文提出 BPE-Phoneme 接口：在音素转录上用 SentencePiece 学习 BPE 合并，同时保留词间空白。

  • BPE-phoneme 单元作为 CTC 目标用于 S2P 训练
  • S2P 输出的 BPE-phoneme 序列携带词边界，解码时先还原为音素词序列再送入 LLM

关键洞察：BPE-phoneme 并非通过缩短序列长度获益。实验表明其 LLM token 数（125）甚至略多于单音素（113）。增益来源于 显式词边界分割 和 局部多音素模式的组块化。

2.4 Phoneme-Informed Hybrid 接口

两类接口并非正交：可先用音素目标微调编码器（Ph-Stage1），再将微调后的编码器接入投影器通路。这种 phoneme-informed projector 利用音素监督为编码器注入发音结构信息，使投影器的跨模态对齐更容易学习。

3. 实验设置

3.1 数据集

语言 数据集 规模 评估集
英语（高资源） LibriSpeech 960h test-clean / test-other
鞑靼语（低资源） Common Voice v11.0 (tt) 20h dev / test

3.2 模型骨架

  • 语音编码器: WavLM-base (94.7M), WavLM-large, Whistle-small (90M), Whistle-large（多语言音素预训练）
  • LLM: Qwen3-1.7B-Base / Qwen3-8B-Base，LoRA 适配（rank=512, α=256），self-attention 和 MLP 全部注入
    • Qwen3-1.7B: ~0.5B 可训练参数；Qwen3-8B: ~1.4B 可训练参数

3.3 发音词典

  • LibriSpeech: 基于 CMUdict 转 IPA + Phonetisaurus 扩展
  • CV-tt: Phonetisaurus + LanguageNet G2P 模型

核心发现：

  1. Vanilla projector（E1–E2）表现较弱，仅靠配对数据学习跨模态对齐具有挑战性。
  2. Phoneme-informed hybrid 接口显著更强：经过 Ph-Stage1 音素微调后，投影器接口大幅提升，与离散音素接口具有竞争力。
  3. BPE-phoneme 接口取得最佳 WER（E5：2.78/6.75），略优于对应的 phoneme-informed projector（2.85/6.79）。

训练效率（E5 配置，8×A800）：

  • 投影器两阶段总计 9.24 小时（Pr-Stage1: 5.14h + Pr-Stage2: 4.11h）
  • 音素接口 S-SKM（K=8）仅需 5.83 小时

尽管 S-SKM 单步开销更高，但所需优化步数大幅减少，总训练时间反而更短。

4.2 低资源场景：鞑靼语 (CV-tt, 20h)

表7：低资源 CV-tt 上的 WER（相同冻结 Whistle-large 编码器）

ID Interface dev test
T1 Projector-based 28.10 33.58
T2 Phoneme-based (Mono) 14.14 17.44

在低资源场景下，音素接口将 test WER 从 33.58% 降至 17.44%，几乎减半。两个系统使用完全相同的冻结 Whistle-large 编码器，均未在 20h 鞑靼语数据上微调编码器，因此性能差异完全归因于接口设计。

这一结果凸显了离散音素接口在有限配对监督下的优越数据效率：音素序列作为语言学上有据可依的中间表示，为 LLM 提供了接近其原生文本空间的输入，免去了投影器从有限数据中学习跨模态对齐的困难。

5. 讨论与总结

本文的主要贡献可概括为：

  1. 系统性受控比较：在相同编码器和 LLM 骨架下，首次系统比较了 projector-based 与 phoneme-based 接口。
  2. BPE-phoneme 接口：提出保留词边界的 BPE-phoneme 离散接口，通过显式分割线索和局部多音素组块（而非序列压缩）取得增益。
  3. Phoneme-informed hybrid：揭示了音素监督对投影器接口的显著增益——音素微调为编码器注入了发音结构信息，使后续跨模态对齐更容易。
  4. 低资源优势：在 20h 鞑靼语上，音素接口展现出压倒性的数据效率优势。

未来方向包括：免发音词典的端到端优化、统一离散与连续接口的训练，以及向更多领域和语言的扩展。
