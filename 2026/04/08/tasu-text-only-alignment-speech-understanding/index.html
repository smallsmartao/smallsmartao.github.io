TASU: Text-Only Alignment for Speech Understanding

本文最后更新于 2026年4月8日 下午

📄 论文：TASU: Text-Only Alignment for Speech Understanding
👥 作者：Jing Peng, Yi Yang, Xu Li, Yu Xi 等（上海交通大学 X-LANCE Lab、华中科技大学、苏州大学、思必驰）
📅 发表：arXiv 2511.03310，2026 年 1 月更新 v2

一句话总结

不用一帧语音数据，仅靠文本就能训练出能听懂语音的大模型。 TASU 提出了一种全新的语音-文本对齐范式：通过模拟 CTC 后验概率，让模型在训练时只看文本，推理时直接处理语音，实现了零样本语音识别和多任务语音理解，在 MMSU 基准上甚至超越了 GLM-4-Voice 和 Step-Audio。

1. 引言：为什么需要 TASU？

1.1 现有 Speech LLM 对齐范式的痛点

近年来，Speech LLM 的主流做法是将语音编码器的输出通过某种投影器映射到大语言模型（LLM）的输入空间。但这里有两个核心问题：

  1. 冗余性问题：连续音频特征的帧率很高（通常每秒几十到上百帧），直接送入 LLM 会带来大量冗余，增加计算开销，同时加大过拟合风险。
  2. 数据依赖问题：要缓解冗余、获得好的多任务性能，通常需要海量的配对语音-文本数据和复杂的训练流程。

1.2 关键直觉：CTC 后验 ≈ 文本的 one-hot

这篇工作的核心洞察非常优雅：CTC 后验概率在结构上与文本的 one-hot 向量高度相似。

想想 CTC 解码的过程：大部分帧要么输出 blank，要么输出某个 token 的高置信概率。经过去 blank、合并重复之后，得到的后验序列其实就是一个”软化”的 token 序列——它和文本 one-hot 向量之间的距离，远比原始音频隐层特征与文本之间的距离要小得多。

这意味着：如果我们能模拟出 CTC 后验的分布特性，就可以用纯文本数据来训练投影器，完全绕开配对语音数据的需求。

2. 相关工作

2.1 CTC 及其后验概率的利用

CTC（Connectionist Temporal Classification）通过引入 blank 符号和路径边缘化，将未分段的声学序列映射为变长标签序列。其”折叠”操作——去除 blank、合并重复——将帧级后验投影为紧凑的表示，可以直接用于解码。

已有一些方法尝试利用 CTC 后验来解决上述两个问题：

  • AlignFormer：利用 CTC 信号对声学特征进行下采样，在一定程度上展示了指令跟随能力。但在配对数据量少时，多任务性能急剧下降，多选题准确率接近随机水平。
  • LegoSLM：用 CTC 后验作为权重对 LLM 的词嵌入进行加权，生成更结构化的声学表示。但这种做法牺牲了多任务能力，且需要大规模数据来重新对齐 LLM 词表。

TASU 与这些方法的根本区别在于：它只训练投影器，完全不动 LLM 参数，且训练数据可以是纯文本。

3. 方法：TASU 的两大核心组件

TASU 的核心思想是在 CTC 后验层面建立一个统一的接口：

  • 训练时：文本通过 CPS（CTC Posterior Simulation）模块转化为伪 CTC 后验，训练投影器。
  • 推理时：真实语音通过编码器和 LSD（Label-Synchronous Decoding）压缩为紧凑的 CTC 后验，经投影器送入冻结的 LLM。

3.1 标签同步解码 (Label-Synchronous Decoding, LSD)

CTC 解码的原始输出有两个问题：大量的 blank 帧和连续的重复帧。直接送入 LLM 会传播冗余并淹没语义信息。LSD 通过两步操作来压缩序列：

3.2 CTC 后验模拟 (CTC Posterior Simulation, CPS)

CPS 是 TASU 实现”纯文本训练”的关键。它将每个 ground-truth token 序列转化为模拟真实 CTC 输出分布特性的伪后验序列 $\tilde{S}$，包含三个随机化阶段：

（2）随机删除 (Random Deletions)

以概率 $p_{\text{del}}$ 独立删除序列中的每个元素。这模拟了 CTC 对齐中非 blank token 偶尔消失的现象——迫使系统对缺失证据保持鲁棒性。

（3）随机插入 (Random Insertions)

插入次数为 $N_{\text{ins}} = \lfloor |\tilde{S}| \times p_{\text{ins}} \rfloor$。每次插入时，以等概率选择：(i) 复制相邻帧，或 (ii) 插入 blank 的 one-hot 向量。这一步引入对齐抖动，捕捉 CTC 特有的重复和 blank 分隔模式。

实验表明，如果没有随机插入步骤，性能会显著下降——这说明模拟 CTC 的对齐不确定性是必要的。

TASU 的独特之处一目了然：唯一一个仅用文本训练、仅训练投影器、同时具备零样本和多任务能力的方案。

4. 实验设置

4.1 模型架构

  • 语音编码器：SenseVoice-Small（提供可靠的 CTC 后验概率）
  • LLM 骨干：Qwen2.5-1.5B（参数冻结）
  • 投影器：Linear–SiLU–Linear 结构，瓶颈维度通常为 1024；多任务设置下为 2048。仅投影器参数可训练。

4.2 训练数据

  • ASR：LibriSpeech、SlideSpeech、CommonVoice4
  • 语音翻译 (ST)：CoVoST2 En→Zh
  • 口语指令理解：SLURP

4.3 训练超参数

参数 值
LSD 阈值 $\tau$ 0.9
标签平滑范围 $(\lambda_{\text{low}}, \lambda_{\text{high}})$ (0.8, 1.0)
删除概率 $p_{\text{del}}$ 0.05
插入概率 $p_{\text{ins}}$ 0.05
学习率 $5 \times 10^{-5}$
训练轮数 5

4.4 评测

  • ASR：LibriSpeech test-clean/test-other（域内），TED-LIUM 3（域外泛化）
  • 语音理解：MMSU 基准
  • 翻译：CoVoST2 En→Zh (BLEU)
  • WER 使用 WeNet 工具包计算

5. 实验结果与分析

5.1 零样本语音识别与领域泛化

系统 训练文本 训练音频 LibriSpeech clean/other SlideSpeech TED-LIUM 3
SLAM — LibriSpeech 3.72 / 8.47 18.58 20.65
TASU LibriSpeech — 4.57 / 9.90 24.07 19.36
TASU LibriSpeech + SlideSpeech — 4.21 / 10.31 18.70 13.23
TASU (+SFT) LibriSpeech LibriSpeech 3.55 / 7.96 17.40 14.38
TASU (+SFT) LibriSpeech + SlideSpeech LibriSpeech 3.06 / 8.04 14.65 11.40

所有系统共享相同组件和训练配置，仅投影器可训练。WER%，越低越好。

几个值得关注的发现：

  1. 零样本 ASR 的惊人表现：纯文本训练的 TASU 在 LibriSpeech 上与使用配对数据的 SLAM 基线差距不到 1.5% WER。考虑到 TASU 一帧语音都没见过，这个结果令人印象深刻。

  2. 文本数据的扩展性：仅通过加入 SlideSpeech 的文本转录（不需要音频！），TASU 在 TED-LIUM 3 上从 19.36% 骤降至 13.23%，远超使用音频训练的 SLAM 基线（20.65%）。这说明 TASU 可以轻松利用纯文本数据来提升领域泛化能力。

  3. 课程学习的叠加效果：将 TASU 作为预训练阶段、再用配对数据微调（TASU +SFT），在所有测试集上都取得了最佳性能。特别是 SlideSpeech 从 18.58%（SLAM）降至 14.65%，TED-LIUM 3 从 20.65% 降至 11.40%。

5.2 LSD 消融实验

系统 投影特征 LSD LibriSpeech clean/other SlideSpeech TED-LIUM 3
SLAM Hidden ✗ 3.72 / 8.47 18.57 20.65
SLAM-CTC CTC 后验 ✗ 3.79 / 8.13 24.13 25.89
TASU 伪 CTC ✗ > 100 > 100 > 100
SLAM-CTC CTC 后验 ✓ 3.13 / 8.59 18.59 14.61
TASU 伪 CTC ✓ 4.57 / 9.90 24.07 19.36
TASU (+SFT) (伪) CTC ✓ 3.55 / 7.96 17.40 14.38

所有模型仅在 LibriSpeech 上训练，结构相同。

这个消融实验揭示了几个关键信息：

  • LSD 对 TASU 是不可或缺的：没有 LSD 的 TASU，WER 直接飙升到 100% 以上，完全不可用。这说明 LSD 的压缩不只是加速手段，它是让文本模拟和真实语音后验能够对齐的必要桥梁。
  • LSD 本身也能提升性能：即使在使用真实音频的 SLAM-CTC 配置下，加入 LSD 后在 TED-LIUM 3 上从 25.89% 降至 14.61%，巨幅提升。这表明 LSD 有效缓解了过拟合。
  • 不加 LSD 的 CTC 后验反而比 Hidden 特征差：SLAM-CTC（无 LSD）在 SlideSpeech 和 TED-LIUM 3 上比 SLAM 更差，说明原始 CTC 后验的冗余 blank 和重复帧确实会损害性能。

5.3 多任务语音理解泛化

模型 模型规模 训练音频时长 LibriSpeech clean/other (WER%↓) CoVoST2 En→Zh (BLEU↑) MMSU (ACC↑)
TASU 1.5B 0 6.47 / 10.35 33.35 40.32
TASU (+SFT) 1.5B 0.9k h 3.28 / 6.91 36.51 40.48
SLAM 1.5B 1.8k h 3.30 / 7.24 37.34 36.70
SALMONN 13B > 100k h 2.10 / 4.90 34.40 25.84
GLM-4-Voice 9B > 100k h 2.82 / 7.66 — 35.51
Step-Audio 130B > 100k h 2.36 / 6.32 — 37.42
Qwen2.5-Omni 7B > 100k h 2.37 / 4.21 41.40 60.57

这张表是全文最有冲击力的结果：

  1. 零音频的 TASU 在 MMSU 上以 40.32% 超越了所有需要大量音频训练的模型（SALMONN 25.84%、GLM-4-Voice 35.51%、Step-Audio 37.42%），而这些模型的参数量是 TASU 的 6-87 倍，训练音频量是 TASU 的无穷倍（因为 TASU 是 0）。

  2. SLAM 在 MMSU 上只有 36.70%——使用了 1.8k 小时音频 + 相同架构，却不如纯文本训练的 TASU。这强有力地证明了 TASU 的对齐范式在保留 LLM 多任务能力方面的优势：因为 LLM 完全冻结，原有的推理和多任务能力不会被破坏。

  3. 加入少量音频微调（TASU +SFT）后，ASR 和翻译任务迅速提升，同时 MMSU 维持 40.48%。这表明 TASU 作为预训练阶段与后续音频微调具有良好的兼容性。

  4. 当然，Qwen2.5-Omni 以 60.57% 的 MMSU 准确率遥遥领先，但它使用了 7B 参数和超过 10 万小时的音频数据——这恰恰说明了 TASU 在效率上的非凡潜力。

6. 总结与未来方向

TASU 提出了一个简洁而有效的新范式：

  • 核心理念：CTC 后验与文本 one-hot 的结构相似性，使得纯文本训练成为可能
  • LSD：6 倍下采样，消除冗余，缓解过拟合，是 TASU 正常工作的必要条件
  • CPS：通过标签平滑 + 随机删除/插入，模拟真实 CTC 后验的分布特性
  • 结果：零样本 ASR 仅有微小精度损失；多任务理解超越参数量大数十倍的模型

未来方向：

  1. 进一步改进 CPS，缩小真实 CTC 后验和伪后验之间的差距
  2. 引入大规模文本数据，探索该对齐方法的可扩展性

个人思考：TASU 的工作在某种程度上暗示了一个有趣的观点——对于语义层面的语音理解，声学信息的重要性可能被高估了。当语音编码器足够好、能产生可靠的 CTC 后验时，对齐投影器其实只需要学习”将 token 概率分布映射到 LLM 嵌入空间”这个相对简单的任务。这个映射与声学细节无关，只与符号层面的结构有关——而文本恰好可以完美提供这一点。当然，这个结论目前仅限于语义理解任务；对于说话人识别、情感识别等依赖声学细节的任务，TASU 的范式是否适用还有待验证。
