自重背部训练——不需要单杠也能练出完整背部

本文最后更新于 2026年8月3日 上午

本文整理自B站视频 【Jeff】自重背部训练（不需要单杆！）（原频道 ATHLEAN-X，Jeff Cavaliere），通过Azure语音识别转录 + 结构化整理而成。

核心观点

背部是自重训练中最让人头疼的部位——没有单杠，似乎就无从下手。Jeff 在这期视频中给出了三个动作，分别覆盖上背、中背（背阔肌）、下背，完全不需要任何器械。关键理念：理解肌肉的发力方向，利用身边环境发挥创造力，自重训练同样可以提供足够的负荷甚至超出你的预期。

动作一：Back Widow（上背）

目标肌群：菱形肌、斜方肌、三角肌后束

做法：

  1. 仰卧在地面上，双脚平放，膝盖弯曲
  2. 双肘撑地，放在身体两侧
  3. 通过肘部下压地面的力量，将上背部抬离地面
  4. 双脚只是辅助支撑，不要用脚蹬地借力——所有力量来自上背部的挤压

要点：

  • 每个重复都要在顶部停留，确认是背部肌肉在做功，而不是惯性
  • 感受菱形肌和斜方肌的收缩
  • 这个动作在 ATHLEAN ZERO 计划中也有使用，验证过效果

动作二：地板滑行拉（中背/背阔肌）

目标肌群：背阔肌，模拟直臂下拉 / Pullover 的运动轨迹

做法：

  1. 找一块光滑的地面（硬木地板、瓷砖等），拿一条裤子（或毛巾）垫在手下
  2. 俯卧，双脚向后伸直，双臂完全前伸——身体完全展开
  3. 通过背阔肌发力，将整个身体从完全伸展位拖拽到顶端收缩位
  4. 然后缓慢放回起始位置

进阶方式：

  • 基础版：允许膝盖和小腿贴地滑行，减轻部分体重
  • 进阶版：全程脚尖撑地（类似俯卧撑起始位），然后拉起——难度极大

要点：

  • 这个动作非常难，即使是有训练基础的人也可能需要退阶
  • 运动轨迹完美模拟了直臂下拉（Straight Arm Pulldown），Jeff 本人最推崇的背阔肌动作之一
  • 地面越粗糙摩擦力越大，难度越高；混凝土地面也可以做，只是会更吃力

动作三：Superman 变体（下背 + 臀部 + 背阔肌）

目标肌群：竖脊肌（下背）、臀大肌、背阔肌、肩外旋肌群

做法：

  1. 俯卧在地面上，双臂放在身体两侧（不是前伸）
  2. 同时抬起上半身和双腿（Superman 基本姿势）
  3. 在抬起的同时，双肩向后旋转——加入肩外旋的动作
  4. 顶部挤压背阔肌、臀部和下背

要点：

  • 每次重复在顶部保持 2-3 秒，确保肌肉在做功而非惯性
  • 这是一个复合动作：下背与臀部协同发力（这是它们天然偏好的工作模式），同时背阔肌从上方提供辅助
  • 微妙的肩外旋还能顺带激活肩袖肌群

训练理念总结

要点 说明
自重 ≠ 简单 地板滑行拉的难度甚至超过很多器械动作，可能需要退阶
创造力是关键 一条裤子 + 光滑地面就能模拟直臂下拉
理解过载原则 只要理解如何对肌肉施加足够的张力，在家也能获得训练效果
完整覆盖 上背（Back Widow）→ 中背（地板滑行拉）→ 下背（Superman变体），三个动作覆盖整个背部

个人笔记

这三个动作对于没有单杠、在家训练的场景非常实用。尤其是地板滑行拉，看似简单实则是高阶动作，第一次做大概率会被难度惊到。结合当前攀岩训练计划，可以在休息日用这组动作做背部补充训练，不需要额外器械。
