杂七杂八的基础知识储备

本文最后更新于 2026年8月31日 中午

本文系统梳理了大语言模型（LLM）、强化学习对齐（PPO / GRPO / DPO）、底层 Transformer 架构机理、多模态（语音/视觉/CLIP）融合演进、幻觉机制与治理以及智能体（Agent）落地实战中的核心技术要点与深层考点。力求从数学推导、架构设计、训练动态到工业落地避坑，提供无死角的硬核技术全景指南。

一、 大模型强化学习与对齐体系（RLHF / DPO / GRPO）

在后预训练（Post-Training）时代，强化学习对齐已从最初复杂的“Actor-Critic-RM-Ref”四模型协同架构，向轻量化、显式偏好拟合（如 DPO）以及无需 Critic 模型的组内相对优势探索（如 GRPO）演进。

3. GRPO、PPO 与 DPO 三者的本质区别与演进脉络

强化学习在 LLM 对齐中的核心目标是优化策略 $\pi_\theta(y|x)$，使得在环境反馈或人类偏好下累积奖励期望最大化，同时加入 KL 散度约束以防止策略退化或灾难性遗忘：

这三种算法在达成上述目标时的计算范式和架构设计存在根本差异：

维度 PPO (Proximal Policy Optimization) DPO (Direct Preference Optimization) GRPO (Group Relative Policy Optimization)
显式模型数量 4 个 (Actor, Critic, Reward Model, Ref Model) 2 个 (Actor, Ref Model) 2/3 个 (Actor, Ref Model, 可选规则/轻量 RM，无 Critic)
训练模式 On-Policy 在线强化学习（需环境 Rollout 采样） Off-Policy 离线监督偏好优化（直接读取偏好对数据集） On-Policy 在线强化学习（组采样 Rollout）
奖励评估方式 Token 级或句子级 Reward，经由 Critic 网络估计价值 无需显式打分，基于相对胜负偏好隐式建模 基于规则判别器或生成式 RM，对组内 $G$ 个样本打分
优势函数估计 GAE（广义优势估计），在每个 Token 步长上计算 $A_t$ 无显式优势函数，通过显式解析解将梯度转化为隐式胜率对数比 组内相对归一化：$A_i = \frac{r_i - \text{mean}(\mathbf{r})}{\text{std}(\mathbf{r})}$
显存与训练开销 极大（Critic 模型常与 Actor 同样大小，通信与显存开销沉重） 极小（与标准 SFT 显存和吞吐相当） 显著低于 PPO（省去 Critic 的前向/反向与显存，支持超长推理链 CoT）
探索能力 (Exploration) 强（通过在线采样探索未知状态空间） 弱（受限于静态偏好数据集的支撑集分布） 极强（组内采样 $G$ 条样本形成天然的多样性探索空间）

4. PPO（逐 Token Advantage）与 GRPO（逐 Sequence Advantage）的深度辨析

(1) PPO 的逐 Token Advantage 与 GAE 机制

标准 PPO 将文本生成视为马尔可夫决策过程（MDP）。给定序列 $y = (y_1, y_2, \dots, y_T)$，在每个时间步 $t$，Critic 网络 $V_\phi(s_t)$ 输出当前前缀状态 $s_t = (x, y_{<t})$ 的状态价值。
为了平衡偏差与方差，PPO 采用广义优势估计（GAE, Generalized Advantage Estimation）：

  • 本质特征：利用 Critic 神经网络赋予模型在每个 Token 粒度上的信用分配（Credit Assignment）能力，理论上能精确定位具体哪个词导致了奖励的增减。
  • 代价与弊端：
    1. 文本生成中中间 Token 的真实 Reward 通常为 0，仅在结尾有序列级奖励（Sparse Reward），Critic 拟合难度极高且方差极大；
    2. 显式训练 Critic 模型不仅占用与 Actor 同等量级的显存，还极易由于 Critic 训练不稳定导致策略崩溃。

(2) GRPO 的逐 Sequence 组内相对 Advantage

GRPO 彻底去除了 Critic 网络。针对同一输入 Prompt $x$，策略模型 $\pi_{\theta_{\text{old}}}$ 采样生成一组输出候选集 $\mathcal{O} = {y_1, y_2, \dots, y_G}$。对每个完整序列由评估器（如数学验证器或编译器）打出标量奖励 $r_i = \mathcal{R}(x, y_i)$。

  • 两者核心权衡：
    • PPO：牺牲显存与训练稳定性，换取细粒度 Token 级别的局部反馈能力。
    • GRPO：放弃密集的中间 Token 状态估计，利用同一 Prompt 下生成多个样本的横向对比（Comparative Baseline）消除环境基线方差，大幅降低显存占用，天然适配长思维链（CoT）推理模型的强化训练。

  2. 分布偏移（Distribution Shift）：随着 DPO 策略 $\pi_\theta$ 的持续迭代，其输出分布会迅速偏离原始数据集和 $\pi_{\text{ref}}$ 的覆盖范围。在未见过的状态区域，DPO 的隐式奖励估计会严重失真，导致过拟合或退化；而在线 RL（PPO/GRPO）通过持续与环境交互重采样，动态校准策略行为。

6. 生成式 Reward Model（Generative RM）的数据构建策略

当任务无法通过静态规则（如数学正则解析、LeetCode 测试用例执行）直接获得 0/1 判定时，需要训练生成式奖励模型（LLM-as-a-Judge / Generative RM）进行打分或生成评判理由（Critique）。

核心数据构造规范

  1. 多维度细粒度标注体系（Multi-dimensional Rubrics）：
    • 避免仅标注单一的 1~5 分总分。必须构建结构化维度：事实准确性（Factuality）、逻辑严密性（Logical Coherence）、安全性（Safety）、指令遵循度（Instruction Following）与表达精炼度（Conciseness）。
  2. CoT 评判轨迹数据（Critique-before-Score）：
    • 数据格式不仅包含最终判定或分数，必须显式包含推导过程：Input Prompt $\to$ Candidate Answer $\to$ Chain-of-Thought Evaluation (评判思考过程) $\to$ Final Decision / Rubric Score。让 RM 学会先分析错误点，再给出打分，显著提升奖励的鲁棒性。
  3. 难负例挖掘（Hard Negative Mining）与扰动样本：
    • 事实反转样本：在原本优质的回答中篡改微小实体、时间或因果链条，迫使 RM 关注细微事实错误；
    • 废话连篇但无用样本（Length-biased / Verbose Negatives）：构造行文华丽但未解答核心问题的长文本，打压 RM 的长度偏置（Length Bias）；
    • 格式违背样本：精准测试指令约束（如“字数限制在200字以内”、“必须输出JSON格式”）。
  4. 多样化 Prompt 覆盖与一致性去噪：
    • 同一 Prompt 配备多模型（开源/闭源多种尺寸）生成的 4~8 个不同回答，利用人类专家或极高算力裁判模型完成全序或半序排列，通过 Elo 机制转化或 Bradley-Terry 矩阵交叉验证消除标注歧义。

7. Reward Model 离线预训 vs 在线与 Policy 联合训练的权衡

特性 离线提前训练好 RM (Offline RM) 在线与 Policy 协同训练 (Online/Iterative RM)
工程实现与复杂度 流程解耦，先打榜/评测 RM，再跑 RL 流程，工程链路简单。 系统高度耦合，需在 RL 训练循环中动态插入打分校准、主动学习或异步重新微调，系统架构复杂。
计算资源消耗 低。RM 在 RL 阶段仅需做纯 Inference 前向传播（甚至可做量化加速）。 高。RM 需要伴随 Policy 产生的轨迹进行周期性梯度更新或在线评判推理。

8. 在线训练中抑制 Reward-Hacking 的核心手段

Reward-Hacking 是指 Policy 模型学会在不真正提升生成质量的情况下，最大化 Reward 信号的漏洞（例如：恶意复读安全免责声明、无意义拉长回复长度、过度谄媚 Sycophancy、或生成迎合特定打分词的乱码）。工业界常见防御方案包括：

  1. KL 散度约束与动态自适应调节：
    • 维持惩罚项 $-\beta \mathbb{D}_{\text{KL}}(\pi_\theta | \pi_{\text{ref}})$。采用自适应 $\beta$ 调节算法：当实际 KL 超出设定阈值时增大 $\beta$，抑制策略偏离；回落时减小 $\beta$。
  2. 集成奖励模型与保守悲观估计（Ensemble & Pessimistic Bound / Min-Reward）：
    • 同时部署多个不同初始化或不同架构的 RM（$RM_1, RM_2, \dots, RM_k$）。
    • 策略计算奖励时采用保守打分（Worst-case Reward）：$r_{\text{final}} = \min_k RM_k(x, y)$ 或均值减去方差 $r_{\text{final}} = \mu_r - \alpha \sigma_r$。只要有一个模型识别出异常，Policy 就无法获得高分。
  3. 显式长度与格式惩罚项（Length/Verbosity Penalty）：
    • 在奖励信号中加入长度线性或对数衰减项：$r_{\text{norm}}(x, y) = r(x, y) - \lambda \cdot |y|$，打破“字数越长得分越高”的虚假相关性。
  4. 迭代式数据重标注（Iterative / Active Exploration Update）：
    • 周期性地将当前 Policy 产生的高分可疑样本提交给更大规模裁判模型或人工审核，打上负标签后回填至 RM 训练集，重新微调 RM。
  5. 推理过程与最终结果隔离打分（Process vs Outcome Separation）：
    • 对于思考模型（Reasoning Model），严格分离 <think> 标签内部的思维链与最终答案。RM 只对最终输出判定客观正确性，防止模型通过在思维链中“刷关键词”骗取高分。

9. SFT 阶段与 RL 阶段的深层本质关系

大模型训练中，SFT 与 RL 绝非简单的“前后工序”，而是扮演着完全不同的信息论角色：

  • SFT 奠定能力的下限与格式边界：SFT 相当于给模型建立“概念字典”和“行动协议”。没有高质量 SFT，RL 的随机探索空间（Action Space）过大，极难在初期采样到有效高分轨迹；
  • RL 决定能力的上限与自纠错深度：SFT 仅迫使模型拟合数据集中单一的黄金路径（Gold Trajectory），无法学会“走入死胡同后如何回退重试”。RL 通过引入试错机制，改变了 Token 的采样分布拓扑，让高置信度推导路径的概率质量高度聚焦。

二、 智能体架构与落地实战（Agent Systems）

10. 除 ReAct 外的主流 Agent 范式

尽管 ReAct（Reasoning + Acting 交替迭代）是目前最直观的 Agent 范式，但在复杂工业场景中，更多架构已被广泛验证并落地：

  1. Plan-and-Solve (规划-执行分离架构，如 Plan-and-Solve / BabyAGI)：
    • 核心思想：将“高层全局任务规划”与“底层低阶工具执行”解耦。Planner 模型首先将用户目标拆解为拓扑依赖的任务 DAG（有向无环图），随后由独立的 Execution Worker 严格按依赖关系执行并聚合结果。
  2. Tree of Thoughts (ToT) / Graph of Thoughts (GoT)：
    • 核心思想：摒弃线性推导，引入树状或图状搜索空间。结合广度优先（BFS）或深度优先（DFS）搜索，配合评估模型（Heuristic / Value Evaluator）对不同推导分支剪枝、回溯，用于复杂组合求解与定理证明。
  3. Multi-Agent 协作与博弈系统 (如 MetaGPT / AutoGen / ChatDev)：
    • 核心思想：构建具有不同 Prompt Persona、知识库和工具权限的多智能体网络。利用 SOP（标准作业程序）、角色扮演、交叉审核（Reviewer）、双向辩论（Debate）机制，降低单一模型在长程任务中的幻觉与错误积累。
  4. Reflexion (反思自纠错记忆架构)：
    • 核心思想：引入显式评估器（Evaluator）和短期反思记忆缓冲器（Self-Reflection Memory）。当工具执行或任务判定失败时，Agent 将执行历史和错误堆栈输入模型，生成反思摘要，在下一次迭代中作为提示词约束，避免重蹈覆辙。
  5. Toolformer / 深度内化原生工具调用架构：
    • 核心思想：通过在预训练或精调阶段将特殊的 <tool_call> Token 内化进词表，使得模型在自回归生成过程中自然预测何时挂起、调用 API 并接收 <tool_response>，消除外部繁琐的字符串正则解析。

11. ReAct 推理模式的核心弊端

  1. 误差级联与不可逆的死循环（Error Cascading & Infinite Loops）：
    • ReAct 是严格的单向贪心线性决策。一旦中间某一步 Observation 返回了意料之外的信息或 Action 参数错误，Thought 极易产生偏离基准的解释，进而陷入反复调用相同无效工具的死循环。
  2. 上下文膨胀与长程遗忘（Context Window Bloat & Cost）：
    • 每次 Thought -> Action -> Observation 都会被完整保留并追加到 Prompt 中。在多步复杂任务中，Token 消耗呈平方级激增，迅速挤占有效上下文窗口，稀释系统最初的 System Prompt 约束。
  3. 缺乏全局前瞻性与回溯能力（Myopic Horizon & No Backtracking）：
    • ReAct 仅根据当前前缀做局部一步最优贪心决策，无法在面临全局矛盾时主动放弃当前分支、回退到两步前重新规划。
  4. 串行延迟不可控（High Wall-Clock Latency）：
    • 所有思考与工具调用均为完全同步串行阻塞。即使某些工具调用之间互相独立（如同时查询北京天气和上海天气），ReAct 也难以自发生成并行调用流。

12. Agent 离线评测高分但线上暴跌的排查维度

当 Agent 离线 Benchmark（如 AgentBench, GAIA）表现优异但在线真实生产环境大幅退化时，应系统性从以下五大维度进行根因排查：

  1. 输入分布偏移与用户意图歧义度（User Query Drift & Ambiguity）：
    • 离线测试集通常格式规范、意图清晰；线上真实用户的输入包含大量错别字、口语化表达、省略句、上下文指代不清以及对抗性注入。
  2. 外部工具接口的确定性与契约漂移（Tool Contract & Schema Drift）：
    • 离线沙箱环境通常提供 Mock 数据或高可用专线；线上环境面临真实第三方 API 的网络延迟、限频拦截（HTTP 429）、非标准错误码、返回超大 JSON 数据导致上下文瞬间被冲垮。
  3. 会话状态膨胀与多轮历史污染（Multi-turn State Pollution）：
    • 离线评测多为单轮或固定步骤测试；线上复杂对话中，用户会不断更改需求、追问纠错，过往会话中陈旧的 Observation 严重干扰了当前的判断。
  4. 超时熔断与非优雅降级机制（Timeout & Concurrency Hazards）：
    • 线上存在网关超时（Gateway Timeout）。当模型因慢网络生成过慢被强制中断时，系统状态是否处于不一致的中间态（如钱扣了但单未下）？
  5. 安全与审查系统的干预截断（Safety Guardrail Interference）：
    • 线上部署的前置/后置安全审核模型可能误伤 Agent 生成的中间 Action 代码或工具返回的敏感数据，破坏了原本预期的执行流。

三、 语音与多模态融合前沿（Multimodal & Audio Intelligence）

在多模态与智能语音交互领域，大模型正经历从“级联管道（Cascade: ASR $\to$ LLM $\to$ TTS）”向“端到端全双工原生模态融合（End-to-End Multimodal Interaction）”的全面演进。

13. 智能语音与多模态核心前沿洞察

智能语音岗位与多模态大模型的交叉点集中在以下核心方向：

  • 音频特征表示与离散化：从连续声学特征（Filter Bank / WavLM / Whisper Encoder 特征）到离散神经音频编解码（Neural Audio Codec，如 EnCodec, DAC, Mimi, SoundStream）；
  • 全双工端到端语音交互（Full-Duplex Speech-to-Speech LLM）：如 Mini-Omni, Moshi, Step-Audio 等架构，无需转文本作为中间载体，直接在统一 Transformer 内部实现流式文本与音频 Token 的并行交错自回归生成；
  • 声学对齐与实体偏置（Contextual Biasing & CTC Fusion）：将语音编码器输出与大语言模型通过 Cross-Attention 或投影层高效桥接，结合 CTC Loss 或 CIF（连续积分触发）实现流式低延迟语音识别与多模态上下文感知。

14. 多模态融合范式全景

  1. 早期特征融合（Early Fusion / Input-level Fusion）：
    • 在进入主干网络前，将不同模态的特征在输入端进行拼接（Concatenation）或线性映射。
    • 优缺点：允许模型自底层起捕获跨模态低阶交互，但对时间分辨率对齐要求极高（如音频 50Hz 与文本 Token 的对齐），极易产生模态主导与 Modality Gap 现象。
  2. 晚期决策融合（Late Fusion / Decision-level Fusion）：
    • 各模态分别拥有独立的单模态编码器与分类/决策头，在输出端对概率分布进行加权平均、门控投票（Gating）或集成。
    • 优缺点：工程解耦清晰，但完全丢失了模态之间的深层语义交互，无法完成复杂跨模态推理。
  3. 混合与交叉注意力融合（Hybrid Fusion / Cross-Attention / Adapter / Q-Former）：
    • 主流方案：保留单模态预训练基座（如 Whisper Encoder + LLM），通过轻量级 Projector（如 MLP, Perceiver Resampler, Q-Former, Cross-Attention 层）将语音/图像特征投影到 LLM 的 Embedding 空间。
    • 机制：LLM 可以像阅读自身 Text Token 一样处理多模态序列，兼顾计算效率与多模态深度语义推理能力。

15. CLIP 原理与架构实现剖析

CLIP（Contrastive Language-Image Pre-training）通过双塔对比学习（Two-Tower Contrastive Learning）在大规模图文对（Image-Text Pairs）上实现跨模态联合表征学习。

核心机制与数学公式

  1. 特征提取与 L2 归一化：
    • 图像批次通过图像编码器得到向量并归一化：$v_i = \frac{f_I(I_i)}{|f_I(I_i)|_2}$
    • 对应文本批次通过文本编码器得到向量并归一化：$u_j = \frac{f_T(T_j)}{|f_T(T_j)|_2}$
  2. 双向对比损失（Symmetric InfoNCE Loss）：
    • 设 Batch Size 为 $B$，可学习温度系数为 $\tau = e^t$。
    • 余弦相似度标量为：$S_{i, j} = \tau \cdot (v_i^\top u_j)$。
    • 图像到文本对齐损失：$\mathcal{L}_{I \to T} = -\frac{1}{B} \sum_{i=1}^B \log \frac{\exp(S_{i,i})}{\sum_{j=1}^B \exp(S_{i,j})}$
    • 文本到图像对齐损失：$\mathcal{L}_{T \to I} = -\frac{1}{B} \sum_{j=1}^B \log \frac{\exp(S_{j,j})}{\sum_{i=1}^B \exp(S_{i,j})}$
    • 总损失函数：$\mathcal{L}_{\text{CLIP}} = \frac{1}{2} (\mathcal{L}_{I \to T} + \mathcal{L}_{T \to I})$
  3. 零样本分类迁移（Zero-Shot Classification）：
    • 推理时，将候选类别构造为 Prompt（如 "a photo of a {class}"），计算图像与所有类别文本的相似度，通过 Softmax 选取最高匹配项。

四、 幻觉机理、长上下文与注意力本质（Hallucination & Transformers）

16. 大模型幻觉的本质成因与非 RAG 治理手段

幻觉产生的根本原因

  1. 概率预测与知识真实的根本脱节（Statistical Autoregression vs Truth）：
    • LLM 的优化目标是最大化训练语料在自回归下的对数似然 $\sum \log P(x_t|x_{<t})$，即学习统计分布上的平滑连续性，而非形式逻辑学上的真实性（Truthfulness）。模型倾向于生成“最符合语法逻辑和统计流畅度的词”，即使事实是捏造的。
  2. 预训练数据中的噪声、冲突与长尾遗忘（Parametric Memory Noise & Long-tail Fallacy）：
    • 互联网语料包含大量自相矛盾、过时或虚假信息；在模型参数容量有限的情况下，低频长尾实体记忆模糊，在解码时被高频概念强行覆盖（Confabulation）。
  3. 解码策略的随机性引入（Decoding Randomness）：
    • Temperature > 0 及 Top-p 采样在发散分支上引入了不可控的扰动，使得模型脱离了高置信度事实事实核。

除 RAG 之外的系统性抗幻觉手段

  1. 推理时干预与引导（Inference-Time Interventions）：
    • DoLa (Decoding by Contrasting Layers)：对比 LLM 深层与浅层的输出 Logits。由于深层更富含事实知识，对比浅层能压制低阶统计语法关联，显著降低幻觉；
    • 对比解码（Contrastive Decoding / ITI）：通过在注意力头内部探测并减去“幻觉方向”的激活向量。
  2. 思维链自洽性与多路径投票（Self-Consistency & Tree Search）：
    • 采用多路径采样并聚类最终答案，利用多数共识压制单一路径上的偶然幻觉。
  3. 外部验证器与反思反馈闭环（External Verifier & Critique Loop）：
    • 引入符号计算器、代码解释器或形式化逻辑检查器，对生成结果做确定性校验并触发重试。
  4. 对齐阶段引入不确定性显式拒答（Calibrated Refusal / DPO for Honesty）：
    • 在 SFT 和 RL 阶段构造“不知道”类样本，训练模型对不确定知识进行主动拒答（Uncertainty-Aware Refusal），降低过度自信。

17 & 18. 长上下文导致幻觉/性能衰减的机理与 Self-Attention 序列关系

长上下文衰减（Lost in the Middle / Context Saturation）不仅是工程显存问题，更是 Attention 机制在数学与特征空间上的必然物理限制：

  1. Softmax 分布的过度弥散与信噪比（SNR）雪崩：

    • 设 Query 对 Key 算出的原始相关性分数为 $S_{i,j} = \frac{q_i k_j^\top}{\sqrt{d_k}}$。在 Softmax 归一化时：

    • 当序列长度 $N$ 从 1K 扩展到 128K 时，分母累加了十万个微小项。即使某些背景上下文的无关 Token 仅分得极小注意力，上万个背景 Token 的加权和也会形成巨大的背景噪声基底，严重稀释目标关键信息的特征贡献。

  2. 位置编码的外推失效（Positional Extrapolation Breakdown）：
    • RoPE（旋转位置编码）在预训练见过的序列长度以外，其高频分量旋转角度发生混叠，相对距离衰减的先验特性被破坏，导致模型无法准确定位长距离上下文的相对依赖关系。
  3. 注意力集中于首尾的固有偏置（Lost-in-the-Middle Phenomenon）：
    • 因自回归因果掩码及起始 Token（Attention Sink）的存在，模型的注意力权重呈现出强烈的“U型分布”——高度偏向序列开头的 System Prompt 和最近生成的末尾 Token，处于序列中间 30%~70% 位置的信息召回率断崖式下跌。

  • 为何除以 $\sqrt{d_k}$（缩放因子 Scaling Factor）：
    • 假设向量 $q$ 与 $k$ 的各分量是独立同分布且均值为 0、方差为 1 的随机变量。则点积 $q^\top k = \sum_{i=1}^{d_k} q_i k_i$ 的均值为 0，方差为 $d_k$。

20. Transformer 与 RNN / LSTM 的全方位对比

对比维度 RNN / LSTM / GRU Transformer
计算时空复杂度 时间复杂度 $\mathcal{O}(N)$（序列串行），空间复杂度 $\mathcal{O}(1)$（仅需保留隐状态） 时间复杂度 $\mathcal{O}(N^2 \cdot d)$，空间复杂度 $\mathcal{O}(N^2 + N \cdot d)$
训练并行性 完全无法并行。计算时刻 $t$ 必须等待 $t-1$ 的隐藏状态 $h_{t-1}$ 输出，受限于顺序执行。 完全高度并行。自注意力矩阵可通过高度优化的 GPU GEMM 矩阵乘法一次性完成全局计算。
长距离依赖捕获 极差。信息必须在隐状态向量中连续压缩传递，存在固有的指数级梯度消失或梯度爆炸；长程记忆随距离急剧退化。 极佳。任意两个 Token 之间的交互路径长度固定为 $\mathcal{O}(1)$，信息可无衰减跨越全局直接连接。
推理自回归开销 极低。推理仅需传递并覆盖定长隐藏向量 $h_t$，显存与时间恒定。 较高。自回归依赖 KV Cache 机制，显存随序列长度线性增长，长序列面临访存瓶颈（Memory Bound）。
归纳偏置 (Inductive Bias) 强。天然蕴含“时间先后顺序”与“马尔可夫局部近邻”假设。 弱。缺乏天然序列感知能力，必须显式依赖外部位置编码（Positional Embeddings）。

21. Transformer 现存缺陷与业界前沿改进

  1. 显存墙与算力墙优化（Attention 机制与 IO 加速）：
    • GQA (Grouped-Query Attention)：将多个 Query 头共享一组 KV 头，在几乎无损模型性能的前提下，将推理阶段 KV Cache 的显存占用降低数倍；
    • FlashAttention-1/2/3：从底层硬件 GPU SRAM/HBM 访存特性出发，利用分块计算（Tiling）与在线 Softmax 动态更新，避免在慢速 HBM 中读写庞大的 $N \times N$ 中间矩阵，实现数倍物理加速。
  2. 长序列外推方案（Context Scaling）：
    • YaRN (Yet another RoPE extensioN)：结合高频关注局部、低频内插延伸的机制，将预训练 4K 上下文无损扩展至 128K 以上。
  3. 稀疏激活与计算架构创新（Sparse MoE & Linear RNN）：
    • 细粒度 MoE (如 DeepSeek-V3 MoE)：采用细粒度共享与路由专家机制，在千亿总参数下仅激活一小部分，大幅削减推理算力开销；
    • SSM 状态空间混合架构（Mamba / Jamba）：将线性时间复杂度的 SSM 算子与自注意力层交替堆叠，兼顾长序列线性推理速度与高精度联想回忆能力。

23. Decoder-only、Encoder-Decoder 与纯 Encoder 架构对比

架构类型 代表模型 注意力掩码机制 (Attention Mask) 优势特性 核心适用场景
纯 Encoder BERT, RoBERTa 无因果掩码（全可见双向注意力）。序列中每个 Token 均可与所有其他 Token 计算注意力。 能够无死角获取整段文本的全局双向深层表征，上下文语义抽取极强。 语义匹配、命名实体识别（NER）、句向量嵌入（Embedding）、文本分类。
Encoder-Decoder T5, BART, Original Transformer Encoder 双向全可见；Decoder 采用因果下三角掩码 + Cross-Attention 关注 Encoder 输出。 编码与解码严格解耦，非常适合输入与输出长度不对等的转换任务。 机器翻译、长文档抽取式/生成式摘要。
Decoder-only GPT-4, LLaMA, DeepSeek, Qwen 严格下三角因果掩码（Causal Mask）。位置 $t$ 的 Token 仅能看见位置 $\le t$ 的历史 Token。 预训练任务极度统一（Next-token Prediction）；天然适合 KV Cache 连续自回归推理与 Zero-shot 泛化。 开放式文本生成、通用多轮对话、复杂推理 Agent。

24 & 25. BERT 原理及其与 GPT 任务目标的本质差异

(1) BERT 的核心原理

BERT（Bidirectional Encoder Representations from Transformers）基于 Transformer Encoder 架构，核心创新在于利用自监督无监督语料进行深度双向表征预训练：

  1. MLM（Masked Language Model，掩码语言模型）：
    • 随机选取输入序列中 15% 的 Token 进行特殊处理（其中 80% 替换为 [MASK]，10% 替换为随机词，10% 保持不变）。模型必须基于周围无死角的双向上下文预测被掩盖的词。
  2. NSP（Next Sentence Prediction，下一句预测）：
    • 输入句子对 $(A, B)$，二分类判定句子 $B$ 是否为句子 $A$ 的真实下一句。

(2) BERT 与 GPT 的任务目标本质不同

  • BERT 采用 Autoencoding（自编码）目标：
    • 优化目标为：$\mathcal{L}_{\text{MLM}}(\theta) = -\sum_{i \in \text{Masked}} \log P(x_i | x_{\backslash i}; \theta)$。
    • 核心特征：训练时能同时获取上下文两侧的信息，适合判别与抽取式任务；但由于引入了 [MASK] 标记，存在预训练与微调时的分布不一致问题，且天然不具备高效连贯自回归长程文本生成的能力。
  • GPT 采用 Autoregressive（自回归）因果语言建模目标：
    • 优化目标为：$\mathcal{L}_{\text{CLM}}(\theta) = -\sum_{t=1}^T \log P(x_t | x_{<t}; \theta)$。
    • 核心特征：严格遵循因果逻辑，最大化前向单向似然，完美统一了预训练与生成推理阶段，是涌现出强泛化能力与上下文学习（In-Context Learning）的基石。

26. Encoder-Decoder 架构如何实现机器翻译

在以 Transformer 为基座的神经机器翻译（NMT）中，输入源语言（如中文）到输出目标语言（如英文）的流转过程如下：

  1. 源序列完全编码：源端中文句子一次性送入 Encoder，经过全可见自注意力计算，输出富含全局双向语义的表示矩阵 $\mathbf{H}_{\text{enc}} \in \mathbb{R}^{L_{\text{src}} \times D}$。
  2. 目标序列自回归解码：
    • 解码起始时刻输入起始符 <BOS>；
    • 步骤 $t$ 时，Decoder 接收已生成的译文前缀 $y_{<t}$，首先通过Masked Self-Attention避免偷看未来词；
    • 紧接着进入 Cross-Attention 层：以 Decoder 当前隐状态作为 Query，以 Encoder 的输出矩阵 $\mathbf{H}_{\text{enc}}$ 作为 Key 和 Value，计算当前生成词与整个中文源句各词之间的软对齐关联；
    • 经过 FFN 和线性分类头预测出下一个英文词 $y_t$；
    • 将预测结果追加至 Decoder 输入，循环往复直至生成结束符 <EOS>。

27. Self-Attention 与 Cross-Attention 的核心区别

维度 Self-Attention (自注意力) Cross-Attention (交叉注意力)
Q, K, V 来源 同源。$Q, K, V$ 均来自同一个输入特征序列（经过不同的线性矩阵投影）。 异源。$Q$ 来自当前主序列（如 Decoder 隐状态），而 $K, V$ 来自外部条件序列（如 Encoder 输出或图像/音频特征）。
注意力矩阵形状 维度为 $(L_q \times L_q)$，是一个方阵（自相关矩阵）。 维度为 $(L_q \times L_{kv})$，通常为非方阵。
核心功能 建模单一序列内部各元素之间的长程依赖与语法结构关联。 实现跨序列、跨模态或条件约束下的语义检索与特征对齐（Conditioning）。

28. Tokenizer 底层实现机理：从 Raw Text 到 Token ID

文本无法直接作为连续张量输入神经网络，分词器（Tokenizer）扮演着离散自然语言字符与模型密集数字索引之间的桥梁。

1. 主流分词算法：BPE (Byte-Pair Encoding) 的构建与编码机制

现代大模型（如 GPT-4, LLaMA）普遍采用 Byte-level BPE 算法：

  • 词表构建阶段（Training/Learning Phase）：
    1. 初始化基础词表：包含所有基本的单字节（256 个 Byte，确保绝对不会产生 OOV 未知词）；
    2. 将训练语料中的所有单词按字节/字符拆开，统计相邻字符对（Bigram）的共现频次；
    3. 选取当前共现频次最高的字符对（例如 't' 和 'h'），将其合并为一个新的子词单元 'th'，并加入词表与合并规则表（Merge Rules）；
    4. 重复上述合并迭代步骤，直至达到预设的词表大小（Vocab Size，如 32K, 100K 或 128K）。
  • 文本编码与映射阶段（Encoding Phase）：
    1. 规范化（Normalization）：执行 NFKC 规范化、去除非法不可见字符；
    2. 预分词（Pre-tokenization）：基于正则表达式（如 GPT-4 的特化正则）将输入划分为单词与标点切片；
    3. 规则迭代应用：按照训练时学习到的 Merge 规则优先级，自底向上贪心合并子词；
    4. ID 查找（Token-to-ID）：将最终切分得到的子词单元在固定词表中查询对应的唯一整型索引（Token ID），生成作为模型最终输入的张量序列。
