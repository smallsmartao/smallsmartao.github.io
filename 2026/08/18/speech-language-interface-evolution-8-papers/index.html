从离散 Token 到原始频谱：Speech–LLM 接口的八篇论文演进综述

本文最后更新于 2026年8月18日 下午

在构建语音大语言模型（Speech-LLM）时，最核心的架构决策莫过于“语音信号究竟以何种形式、通过何种接口模块送入 LLM”。不同的接口设计直接决定了词表扩展方案、对齐与适配机制、训练阶段划分以及计算/显存开销。

本文聚焦于这一主线，梳理 8 篇代表性工作在输入形式、适配接口（Projector / 结构设计）以及配套训练机制上的具体实现。

8 篇工作接口设计横向对比

1. AudioPaLM (Google, 2023)

1.1 音频如何送入 LLM？

  • 输入形式：将音频离散化为离散 Token 序列。
    • 输入端（ASR/AST）：使用预训练 w2v-BERT 聚类得到的 1024 个离散语义 Token；
    • 输出端（TTS/S2ST）：使用 SoundStream / EnCodec 提取的多层量化声学 Codec Token。
  • 接口连接模块：无任何独立的跨模态 Projector（如 MLP 或 Q-Former）。直接将离散 Token 视为普通词表 Token，通过共享的 Embedding Table 查表得到向量。

1.2 配套设计与训练要点

  • 词表扩展：将文本 SentencePiece 词表与音频离散 Token 空间直接拼接，构建统一超大词表（如 32k 文本 Token + 1024 语义 Token + 各量化层声学 Token）。
  • 交互方式：序列级展平（Flatten）与交错。音频与文本统一以离散序列的形式输入标准的 Decoder-only 架构（PaLM-2）。
  • 训练方式：多任务端到端自回归训练，通过统一的 Prompt 触发 ASR（音频 Token $ o$ 文本）、TTS（文本 $ o$ 音频 Token）或 S2ST。

2. SALMONN (Tsinghua & ByteDance, 2023)

1.1 音频如何送入 LLM？

  • 输入形式：连续特征。采用双编码器结构分别提取语音与通用音频特征：
    • Whisper-Large-v3 编码器：提取时序细粒度的连续语音表征；
    • BEATs 编码器：提取非语音环境声与背景事件表征。
  • 接口连接模块：窗口级 Q-Former（Window-level Q-Former）。
    • 将双编码器沿时间对齐拼接后的连续特征，以滑动窗口（如每 $0.33$ 秒为一个窗口）送入轻量 Transformer Q-Former，大幅压缩时序序列长度。

1.2 配套设计与训练要点

  • LLM 交互：不改动 LLM 原生词表。Q-Former 输出的降采样特征作为连续 Soft Prompt，与系统文本 Prompt 的 Text Embeddings 拼接输入 LLM（Vicuna）。
  • 训练流程：
    1. 跨模态预训练（Pre-training）：冻结双编码器与 LLM，仅训练 Q-Former 进行模态特征对齐；
    2. 跨模态指令微调（Instruction Tuning）：保持编码器冻结，放开 Q-Former 并对 LLM 注入 LoRA 进行微调；
    3. 激活微调（Activation Tuning）：解决跨模态微调后 LLM 原生文本能力衰退与任务幻觉问题。

3. LauraGPT (Alibaba, 2023)

1.1 音频如何送入 LLM？

  • 输入形式：完全采用离散 Token 表征。
    • 采用统一神经音频编解码器，将输入语音转化为多层离散 Codec Token（涵盖语义离散流与声学细节离散流）。
  • 接口连接模块：无外挂 Projector，纯离散 Token 查表输入。

1.2 配套设计与训练要点

  • 词表设计：构建包含文本 Token、特殊控制 Task Token 以及音频多层 Codec Token 的全模态统一词表。
  • 序列组织与生成：在自回归主干中统一建模多模态序列，支持 Audio-to-Text、Text-to-Audio 及 Audio-to-Audio 的全能任务流。

4. SLAM-ASR (Carnegie Mellon University, 2024)

1.1 音频如何送入 LLM？

  • 输入形式：预训练连续语音编码器（如 w2v-BERT 2.0、HuBERT、Whisper-Encoder）输出的连续声学表征。
  • 接口连接模块（系统化消融对比）：
    • Linear / MLP Adapter：简单的单层/双层线性映射，将声学维度对齐到 LLM 隐藏维度；
    • 1D 卷积降采样 Adapter（Conv Downsampler）：在时序上进行 2x/4x 步长卷积下采样，压缩 Token 数量；
    • Q-Former Adapter：基于 Query 查询的注意力池化降采样。

1.2 配套设计与训练要点

  • LLM 交互：投影后的声学特征作为 Soft Prompts 与指令文本 Prompt 拼接，LLM 词表保持完全不变。
  • 训练范式：
    • Stage 1 (Alignment)：完全冻结语音编码器与 LLM，仅优化 Adapter 参数实现特征空间映射；
    • Stage 2 (Joint Fine-tuning)：保持语音编码器冻结，联合优化 Adapter 与 LLM 内部的 LoRA 适配器。

5. LegoSLM (ByteDance, 2024)

1.1 音频如何送入 LLM？

  • 输入形式：CTC 预测后验概率分布（Posterior Probabilities）。
    • 传统方案直接将编码器的高维 Dense 隐藏状态送入 LLM，绑定了特定编码器结构；
    • LegoSLM 在冻结的语音编码器顶部外挂一个预训练好的 CTC Head，输出每一帧在音素/单字词表上的离散概率分布向量 $P_{ ext{CTC}} \in \mathbb{R}^{T imes |V_{ ext{CTC}}|}$。
  • 接口连接模块：极轻量的线性投影（Linear Projector）。
    • 仅需将维度为 $|V_{ ext{CTC}}|$ 的后验概率向量直接投影到 LLM 的嵌入维度 $D_{ ext{LLM}}$。

1.2 配套设计与训练要点

  • 设计动机：利用 CTC 概率分布充当通用的模态交换中介（Lingua Franca）。
  • 解耦优势：声学编码器和 LLM 实现物理级完全解耦。只要 CTC 词表统一，更换声学编码器无需重新训练 LLM，反之更换 LLM 也只需重新训练一层极小开销的线性映射层。

6. Phonemes vs. Projectors (Johns Hopkins University, 2024)

1.1 音频如何送入 LLM？

本工作针对“离散音素序列”与“连续表征+Projector”两条技术路线进行了严格的受控对比：

  • 方案 A（离散音素流）：音频 $ o$ 离线音素识别器（1-pass ASR） $ o$ 显式文本音素串（如 /h/ /eh/ /l/ /ow/） $ o$ 走 LLM 原生文本 Tokenizer 与 Embedding。完全无需额外的 Projector。
  • 方案 B（连续特征流）：音频 $ o$ 连续声学编码器 $ o$ 线性/MLP Projector $ o$ 作为 Soft Prompt 拼接输入 LLM。

1.2 配套设计与结论

  • 音素流优势：完全免除了连续模态投影层（Projector）的对齐训练，天然复用 LLM 的文本处理能力。
  • 连续 Projector 流优势：保留了副语言声学线索（语调、音色、信噪比细节），在真实强噪声与口音场景下鲁棒性显著更强。

7. Mel-LLM (HKUST & Huawei, 2024)

1.1 音频如何送入 LLM？

  • 输入形式：80 维原始 Log-Mel 频谱特征。
    • 完全摒弃独立的预训练 Speech Encoder（如 Whisper 或 w2v-BERT）。
  • 接口连接模块：轻量 1D 卷积降采样模块 + 线性投影层。
    • 采用多层连续 1D 卷积（Stride 降采样 4x~8x）将密集的频谱帧序列压缩为离散步长特征，直接映射至 LLM 维度。

1.2 配套设计与训练要点

  • LLM 交互：保持 LLM 原生词表不变，降采样后的 Mel 特征作为连续 Token 送入 LLM。
  • 两阶段极简训练：
    • Stage 1：冻结 LLM，仅训练卷积降采样模块与投影层进行声学粗对齐；
    • Stage 2：联合训练卷积层与 LLM 的 LoRA 权重，直接让 LLM 的 Transformer 层学习建模原始频谱的声学与语义特征。

8. JSTIP (CUHK & Tencent, 2024)

1.1 音频如何送入 LLM？

  • 输入形式：预训练语音编码器（Whisper Encoder）提取的连续隐藏表征。
  • 接口连接模块：轻量 1D 卷积降采样 + 两层 MLP Projector。
    • 对时序进行 2x 步长压缩后映射到 LLM 嵌入空间。

1.2 配套设计与训练要点

  • 关键设计（联合 CTC 辅助监督）：
    • 在语音编码器顶部并联一个 CTC 分支，引入辅助 CTC 损失 $\mathcal{L}_{ ext{CTC}}$；
    • 联合 LLM 的自回归因果损失 $\mathcal{L}_{ ext{LLM}}$ 构建多任务目标：$\mathcal{L} = \mathcal{L}_{ ext{LLM}} + lpha \mathcal{L}_{ ext{CTC}}$。
  • 全链路联合优化：端到端微调语音编码器、Projector 与 LLM LoRA，既借助 CTC 强化局部显式音素/文字边界对齐，又利用 LLM 自回归捕获全局上下文。

总结：Speech–LLM 接口设计的选型权衡

回顾 8 篇代表性工作的演进脉络，语音送入 LLM 的接口设计主要围绕三个核心维度进行权衡：

  1. 输入表征：离散 vs 连续 vs 原始频谱

    • 离散 Token（AudioPaLM / LauraGPT）：无需额外投影层，直接复用 LLM 统一自回归 Decoder，但严重依赖离线 Codec 的量化质量与大词表扩展；
    • 连续特征（SALMONN / SLAM-ASR / JSTIP）：保留完整声学细粒度信息，是当前 ASR 与全音频理解的主流路线；
    • 原始频谱（Mel-LLM）：架构最为极致纯粹，摆脱了对外部预训练声学编码器的依赖。

  2. 接口模块（Projector）：从重型到轻量化

    • Q-Former（SALMONN）：具备较强的信息抽取能力，但训练对齐难度与结构复杂度较高；
    • Conv + Linear/MLP（SLAM-ASR / Mel-LLM / JSTIP）：计算极轻、延迟极低，通过简单的时序步长降采样即可达到优秀的对齐效果，成为主流工业界的首选。

  3. 解耦与泛化（LegoSLM）

    • 通过统一的 CTC 概率空间作为中介，实现了声学前端与不同 LLM 基座之间的即插即用与彻底解耦。
