Multi-Task GRPO: Reliable LLM Reasoning Across Tasks

本文最后更新于 2026年8月24日 下午

导读与核心背景

强化学习后训练（RL Post-Training）已成为激发大语言模型复杂推理（Mathematical Reasoning, Coding, Logic Puzzles）能力的核心手段。其中，DeepSeek 提出的群组相对策略优化（Group-Relative Policy Optimization, GRPO）通过在 Prompt 内部对采样的 $G$ 个候选回答执行组内相对优势归一化，成功去除了传统 PPO 对独立 Critic/Value 模型的依赖，大幅降低了显存开销与训练复杂度。

然而，现有的 RL 后训练绝大多数针对单一领域或狭窄基准设计（如专注刷 MATH 或 Codeforces）。当尝试在真实多任务场景（Multi-Task Reasoning）下联合后训练单个模型时，标准 GRPO 面临两大严重的理论与工程缺陷：

  1. 平均性能最大化导致的“任务牺牲”与鲁棒性缺失（Lack of Task-wise Robustness）：
    标准的加权平均目标 $\frac{1}{K}\sum_k J_k(\theta)$ 允许简单任务（如 Countdown 倒计时）的巨大提升掩盖复杂任务（如 ARC 抽象推理、Zebra 斑马逻辑难题）的停滞甚至倒退（负迁移与梯度干扰）。
  2. 多任务间零梯度率不均引发的梯度扭曲（Uneven Zero-Gradient Rates）：
    在 GRPO 中，如果一个 Prompt 的 $G$ 个采样 Rollouts 得分全对（全 1）或全错（全 0），则组内标准差为 0 或优势值全为 0，该 Prompt 对策略更新产生的有效梯度贡献为零。不同难度和类型的任务，其零梯度 Prompt 的比例截然不同。这导致即使算法显式调高了弱势任务的目标权重，实际回传的反向传播梯度依然被零梯度率较低的任务所统治。

为此，来自 UCL、华为诺亚方舟实验室与巴塞尔大学的研究团队在 ICML 2026 上提出了 Multi-Task GRPO (MT-GRPO)（arXiv: 2602.05547）。该方法通过动态改进感知任务重加权（Improvement-Aware Task Reweighting）与保比例保真采样器（Ratio-Preserving Sampler），在兼顾平均性能的同时显著拉升最差任务（Worst-Task）准确率 16%~28%，实现了真正均衡可靠的多任务推理。

2.2 解耦 GRPO 损失：基于真实奖励与进展动量的动态重加权

传统分布鲁棒优化（DRO）通常依据当前批次的 Loss 动态调整权重（Loss 越大权重越高）。但在 GRPO 中，Loss 在全对与全错时都趋近于 0，无法直接作为任务难度的评价标尺。

MT-GRPO 提出直接利用真实任务级奖励 $J_k(\theta)$ 与短时进展动量进行重加权：

  1. Logit 空间参数化：定义 $z_t = \text{Softmax}(\xi_t)$，其中 $\xi \in \mathbb{R}^K$。

  2. 动态更新梯度计算：

    当某任务的奖励低于加权均值时，$(g_t)_k < 0$，在梯度下降 $\xi_{t+1} = \xi_t - \beta g_t$ 下其 Logit 与分配权重 $z_k$ 将自动调高。

  3. 引入改进动量防止权重极化崩溃（Improvement-Aware Regularization）：
    若仅针对瞬时表现最差的任务施加极值权重，会导致权重在难任务间剧烈震荡（图中 Worst-task Collapse）。MT-GRPO 引入任务历史提升速度（Improvement Velocity），对处于“快速爬坡期”的任务给予适度宽限，实现全局平滑演进。

2.3 保比例接受采样器（Ratio-Preserving Batch Sampler, RPS）

即使计算出了理想的目标任务权重 $z \in \Delta_K$，由于各任务的零梯度 Prompt 比例（Zero-Gradient Rate, 记为 $\zeta_k$）极不一致，传统的均匀抽样会导致实际产生梯度的样本比例与 $z$ 严重偏离。

MT-GRPO 设计了 Ratio-Preserving Sampler (RPS)：

  • 实时追踪各任务的有效样本产出率（Non-zero Gradient Acceptance Rate $1 - \zeta_k$）；
  • 动态调整送入 Rollout 阶段的候选 Prompt 比例 $\tilde{z}_k \propto \frac{z_k}{1 - \zeta_k}$；
  • 确保在过滤掉全 0 / 全 1 的无梯度样本后，进入反向传播梯度的有效 Token/Prompt 比例与目标权重 $z_k$ 严格一致。

实验结果与对比分析

研究在 3B 与 7B 参数规模模型（包括 Qwen-2.5-7B-Base、OLMo-3-7B）上进行了系统的多任务后训练评测，任务涵盖规划（Countdown）、复杂逻辑（Zebra Puzzles）、归纳抽象（ARC-AGI）、自然语言科学问答（SciKnowEval）与竞赛数学（GSM8K/MATH）。

2. 关键实验结论

  1. 彻底攻克木桶短板：相比标准 GRPO 与单一任务过滤的 DAPO，MT-GRPO 在保持最高平均准确率（63.8%）的同时，将最差任务准确率从 34.1% 强力拉升至 50.8%（绝对增益 +16.7%）。
  2. 收敛效率倍增：达到 50% 最差任务准确率所需步数缩短了 50%，大幅降低了多任务强化学习后训练的算力消耗。
  3. 跨域规模化泛化（9-Task Setting）：在扩展至涵盖 ARC-Challenge、Zebra、LogiQA 等 9 项异构任务的更大评测矩阵中，MT-GRPO 在所有任务上均未发生灾难性遗忘，展现出极佳的多任务帕累托最优（Pareto Frontier）。

总结与未来展望

MT-GRPO 指出了大模型从“单一学科刷榜”走向“通用稳健推理”必须跨越的多任务优化障碍。通过解耦 GRPO 目标下的奖励重加权与克服零梯度率偏差的保比例采样，MT-GRPO 为大模型通用推理能力构建与多模态联合后训练提供了极具指导意义的工程与理论范式。
