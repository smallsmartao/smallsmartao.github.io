How Auditory Knowledge in LLM Backbones Shapes Audio Language Models: A Holistic Evaluation

本文最后更新于 2026年3月21日 中午

How Auditory Knowledge in LLM Backbones Shapes Audio Language Models: A Holistic Evaluation

  • 论文：https://arxiv.org/abs/2603.19195
  • PDF：https://arxiv.org/pdf/2603.19195
  • 作者：Kehan Lu, Fu Yan, et al.（National Taiwan University / NVIDIA / Academia Sinica）

摘要（译）

探究文本预训练的 LLM 自身包含的“听觉知识”在多大程度上影响下游音频语言模型（LALM）。作者对 12 个开源与 5 个专有 LLM 在三个设定下做系统评估：

  1. 在 AKB-2000 基准上直接 probing 听觉知识；
  2. 级联评测：音频经 captioner 转文本后由 LLM 推理；
  3. 音频设定：每个 LLM 搭配音频编码器微调为 LALM。结果显示不同家族差异显著，文本结果与音频表现高度相关，音系类任务普遍偏弱，简单级联方案在部分任务能匹配或超越端到端 LALM，当前瓶颈主要在音频编码器。

核心贡献（译）

  • 提供 12 个开源 LLM 的听觉知识全景评估，为选择 LALM 骨干提供可操作依据。
  • 发布 AKB-2000：覆盖 Music、Sound、Paralinguistic、Phonetic、Audio Quality、Technical 六大类、48 子类的 2000 条问答基准。
  • 在统一框架下给出文本、级联、音频三种评测并公开代码与模型。

评估设计（译）

  • 直接听觉知识评测：在 AKB-2000 上直接问答，衡量 LLM 文本层的听觉知识广度/深度。
  • 级联评测：音频 → captioner → 文本描述 → LLM 回答原题，观察文本推理对音频任务的迁移。
  • 音频设定（LALM）：为每个 LLM 配置音频编码器，按 DeSTA 自蒸馏框架微调，直接以音频输入测试。

基准与设置（译）

  • AKB-2000：6 类、48 子类听觉知识问答，涵盖声学、韵律、语音学、音乐、音质与技术知识。
  • 级联 captioner：Whisper / Omni / Gemini 等，将音频转详细文本描述后再由 LLM 回答。
  • 音频微调：同策略微调各 LLM 成 LALM，对比 Published systems 与作者复现。

结论（译）

  • 不同 LLM 家族的听觉知识差异显著；在相同微调策略下，骨干差异可带来 >10% 绝对差距。
  • 文本评测与音频表现正相关，可作为轻量“选模”指标。
  • 语音学（phonological）任务是共同短板。
  • 简单 caption→LLM 级联在部分任务可匹配/超越端到端 LALM，瓶颈主要在音频编码器，LLM 的听觉推理仍有潜力未被充分利用。
