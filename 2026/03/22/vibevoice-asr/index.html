VibeVoice-ASR Technical Report

  • 论文：https://arxiv.org/abs/2601.18184
  • PDF：https://arxiv.org/pdf/2601.18184
  • 作者：Microsoft Research

摘要（直译整理）

本文提出 VibeVoice-ASR，用于长语音的统一识别与理解。系统可在单次生成中同时输出识别文本、说话人标识和时间戳，目标是替代“分段 ASR + 独立 diarization + 对齐”的多模块流水线，以减少长音频场景中的上下文割裂。论文报告该系统支持最长约 60 分钟音频、50+ 语言与中英混说，并支持通过文本提示注入领域上下文。

任务定义与输出形式

作者将长语音理解建模为自回归语言建模任务：

  • 输入：音频编码器输出的连续表示 + 可选文本提示
  • 输出：Rich Transcription 序列，统一编码
    • Who：说话人身份
    • When：时间边界
    • What：转写内容

与传统 ASR 只输出文本不同，VibeVoice-ASR 的目标序列显式携带说话人与时间结构。

方法细节（直译整理）

  1. 主干结构

    • 使用 decoder-only LLM（Qwen2.5 系）作为生成核心。
    • 音频表示由预训练声学/语义编码器提供。

  2. 说话人标签构建

    • 声纹提取：vblinkp（WeSpeaker）
    • 聚类：HDBSCAN
    • 合并：余弦阈值 0.67

  3. 时间戳构建

    • 先做 ASR 对齐
    • 再按标点切分，匹配生成序列粒度

训练数据与训练流程（直译整理）

  • 预训练语料：大规模长语音伪标数据（会议、播客等），用于学习长上下文依赖。
  • 上下文合成管线：
    • GPT-5 生成脚本与上下文提示
    • VibeVoice 引擎合成多说话人中英与 code-switch 音频
    • 通过闭环 ASR 过滤高 WER 样本
    • 最终保留约 6k 小时合成数据
  • 长语音转写修复：对 >50 分钟录音的分段转写进行重写拼合，减少切块边界错误。
  • SFT 数据：MLC-SLM、Fisher 等高质量对话/会议语料 + Muse 音乐数据。
  • 长度课程学习：输入长度从 8k 逐步增加到 65k。

实验结果（论文表格转录）

Dataset Metric WhisperX Emilia VibeVoice-ASR
AISHELL-4 DER / WER 14.55 / 29.69 16.58 / 49.40 16.93 / 18.99
AMI-IHM DER / WER 18.27 / 24.12 35.44 / 47.85 15.46 / 23.22
AMI-SDM DER / WER 23.05 / 39.65 46.55 / 61.70 17.78 / 28.40
AliMeeting DER / WER 35.53 / 36.62 25.57 / 54.27 25.34 / 30.82

论文结论（直译整理）

  • 将识别、说话人、时间戳统一到单一生成框架可以覆盖长音频场景。
  • 在报告的数据集上，VibeVoice-ASR 在 WER 与 DER 的组合表现上具备竞争力。
  • 系统支持多语言与 code-switch，并支持上下文提示注入。
