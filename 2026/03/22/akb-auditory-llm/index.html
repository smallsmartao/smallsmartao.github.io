How Auditory Knowledge in LLM Backbones Shapes Audio Language Models

本文最后更新于 2026年4月8日 下午

How Auditory Knowledge in LLM Backbones Shapes Audio Language Models: A Holistic Evaluation

  • 论文链接：https://arxiv.org/abs/2603.19195
  • PDF：https://arxiv.org/pdf/2603.19195.pdf
  • 作者团队：Kehan Lu, Fu Yan, et al.（NTU / NVIDIA / Academia Sinica）

1. 核心动机：大语言模型到底“懂不懂”声音？

目前，大音频语言模型（Large Audio Language Models, LALMs）的主流范式是将一个音频编码器（Audio Encoder）对接到一个预训练的大语言模型（LLM）上，然后进行联合微调。由于人类在互联网文本中留下了大量关于听觉体验的描述（例如“小提琴听起来很温暖”、“警笛声随着靠近而变大”），业界普遍假设：即便只经过纯文本预训练，LLM 内部也已经内化了丰富的听觉世界知识（Auditory Knowledge）。

然而，这种文本内化的听觉知识到底有多少？它是否真的能决定下游多模态 LALM 的表现？
为了填补这一空白，本文提出了一个全方位的评估框架，通过控制变量法（仅更换 LLM backbone），在纯文本测试、级联测试和端到端音频测试三个维度上对 17 种主流 LLM（12个开源 + 5个闭源）进行了深度剖析。

2. 评测方法论设计

为了彻底摸清 LLM 的听觉认知底线，作者设计了三种互补的评测设定：

2.1 纯文本听觉知识基准（AKB-2000）

作者人工构建了一个包含 2000 道多选题的知识库（AKB-2000），直接考察模型对音频知识的广度和深度。

  • 分类体系：分为 6 大顶层类别（声音、副语言、语音学、音乐、音频质量、技术知识）和 48 个细粒度子类。
  • 考察点：避免纯文本阅读理解，重点测试常识经验（如拟声词对应什么声源、单词的重音模式）以及专业知识（如特定噪声的物理属性、乐理）。

2.2 文本级联推理（Cascade Evaluation）

除了直接做题，LLM 能否在实际音频任务中发挥作用？
作者使用 Gemini-2.5-Pro (Audio) 作为“完美字幕机（Captioner）”，先将音频转化为详细的文本描述（涵盖声学属性、声源、语调等），然后让 LLM 纯靠阅读这段文本字幕来回答关于音频的复杂问题。该阶段采用 MMAU 和 MMAR 基准测试集。

2.3 端到端音频微调（Audio-Grounded Fine-Tuning）

这部分是探究“文本能力能否跨模态迁移”的核心。
作者基于 DeSTA 框架，将 8 种开源 LLM 转化为真正的 LALM：

  • 模型架构：Whisper-large-v3（音频编码器） + Q-Former（模态连接器） + LLM（骨干）。
  • 训练策略（关键数据构造）：采用自蒸馏（Self-Distillation）微调。在第一阶段，LLM 先读取音频的文本元数据并生成回答；在第二阶段，输入被替换为真实音频波形，模型需要端到端优化去重现第一阶段自己生成的回答。
  • 控制变量：在训练中完全冻结音频编码器和 LLM 的权重，仅训练模态连接器（Q-Former）。这种严格限制是为了防止 LLM 在微调中更新参数来弥补知识盲区，从而最纯粹地测试其自带的听觉知识底座强度。

4. 结论与启发

这篇论文揭示了多模态大模型背后的一个“残酷真相”：模态对齐拯救不了贫瘠的知识底座。

  1. 强大的文本听觉知识是强大 LALM 的先决条件。评测证明，如果在纯文本测试（AKB-2000）中表现不佳，该 LLM 即使加上最顶级的音频编码器，也无法成为一个优秀的端到端音频大模型。
  2. 纯文本级联（Cascade）是极其有效的筛选器。在正式耗费算力微调多模态模型前，通过 Captioner+LLM 的纯文本级联流程，可以极高概率预测该 LLM 最终在音频模态下的推理上限。
  3. 冻结参数策略的启示。通过只微调模态连接器（Q-Former）而冻结 LLM 和 Audio Encoder，作者证明了现阶段多模态能力瓶颈并不全在“对齐”，更在于骨干网本身是否具备处理跨模态概念的内在世界知识储备。
