如何科学设计训练计划：渐进超负荷、MRV与臀部三分法则

本文最后更新于 2026年6月24日 晚上

来源：自然之路播客 - 如何练出想要的完美体型（Elijah，体能教练/壶铃世界冠军，新西兰奥克兰）

核心观点

对大多数人来说，把几个核心复合动作练好练深，比追求动作多样性更重要。一旦你理解了逻辑，你就不再需要别人告诉你该怎么做。

一、新手训练的三大基础

1.1 训练频率

  • 每个肌群每周至少训练两次，效果显著优于每周一次
  • 原因：肌肉蛋白合成（MPS）在训练后持续24-48小时后回落，一周一次意味着5-6天的空白窗口
  • 新手建议：上下肢交替，每周5次；或全身训练每周3次，每次选不同主要动作
  • 关键原则：同一肌群相邻两次训练间隔≥48小时

1.2 训练量（每周组数）

目标 每肌群/周
维持 3-5组
温和增长 8-12组
积极增长 12-20组
收益递减区 >20组（恢复风险↑）
  • 新手从 8-10组/肌群/周 起步，不要贪多
  • 新手阶段神经系统对任何刺激都有反应，需要的是一致性的高质量刺激

1.3 渐进超负荷（Progressive Overload）

定义：随时间推移，持续给身体更大的挑战。

超负荷方式（由直接到间接）：

  1. 重量增加
  2. 次数增加
  3. 组数增加
  4. 休息时间缩短
  5. 动作质量提升（更大ROM、更慢离心）

双倍渐进法（推荐）：

这套系统帮你持续进步而不停留在舒适区。很多人练多年没变化，不是方法错，是每次做同样重量、同样次数，身体没有理由改变。

二、MRV：最大可恢复容量

MRV (Maximum Recoverable Volume)：一周内可承受的最大训练量，超过则恢复不及、表现下滑。

影响MRV的因素

  • 训练年限（越久越高）
  • 恢复能力（睡眠、营养、压力）
  • 当前生活压力总量

超过MRV的6个信号

  1. ⚠️ 训练表现连续下降（非偶尔）
  2. 需要比以前更长的热身才能进入状态
  3. 肌肉酸痛超过72小时
  4. 睡眠变差（很累但睡不着）
  5. 对训练失去热情，强撑着去
  6. 关节出现不明隐痛

主动弯曲测试（简单自测工具）

训练前不拿重量，对镜主动弯曲目标肌肉：

  • 感觉沉、松、没感觉 → 可能未恢复
  • 感觉有力量、有张力、饱满 → 可以正常训练

三、最后几个重复次数才是关键

  • 肌肉生长最强信号来自接近力竭状态（剩余0-3个）
  • 此时调动所有运动单元，包括平时不会用到的2b型快肌纤维
  • 一组做12次，前8-9次本质是铺垫，真正刺激集中在最后3-4个

力竭策略（10/90法则）

  • 10%的组做到真正力竭（最后一组）
  • 90%的组留1-2个停下来
  • 原因：完全力竭增加中枢神经疲劳、动作变形、损伤风险↑，但边际收益极小

节奏的优先级

  • 节奏对肌肥大的影响 远小于 是否接近力竭 + 训练总量
  • 简单原则：离心控制住（不借惯性），向心尽可能快
  • 节奏是优化项，不是基础项

四、臀肌训练：三分法则与六大动作

臀肌的三个动作方向

方向 功能 代表动作
髋伸展 把腿往后推/站立时髋前推 深蹲、硬拉、保加利亚分腿蹲
髋外展+外旋 腿向外打开/脚尖外转 弹力带侧走、臀中肌外展训练
髋铰链推进 髋关节最大伸展位激活最强 臀推、臀桥

关键认知

  • 深蹲/硬拉无法代替臀推（在顶端臀部激活反而最低）
  • 最大化臀大肌激活需要髋关节在伸展中末端的动作

三分法则

将臀肌训练量平均分配：

  • 1/3 髋主导铰链：深蹲、硬拉、保加利亚蹲
  • 1/3 臀推类：臀推、臀桥
  • 1/3 外展/外旋：弹力带侧走、臀中肌训练

臀推四大常见错误

  1. 腰部过度弓起 → 应保持骨盆中立位，臀肌主动收缩
  2. 重量太轻次数太多（50-100个无效） → 应在8-20次范围，找”只能推15-20个”的重量
  3. 顶端不停留 → 顶端主动挤压臀肌停留1秒
  4. 脚位不对 → 脚放在能让膝盖顶端呈90°的位置

六大复合动作框架

  1. 硬拉（臀大肌激活+后侧链）
  2. 罗马尼亚硬拉（后侧链王牌，离心阶段关键）
  3. 深蹲变体（背蹲/前蹲/高脚杯深蹲，下肢整体）
  4. 俯身划船（背阔肌/菱形肌/中下斜方肌）
  5. 卧推变体（胸大肌/三角肌前束/肱三头肌）
  6. 站姿推举（肩膀/核心/上肢协调）

一周只能练3次？每次选3-4个复合动作，进步速度超过每次练15个孤立动作的人。

动作多样性

  • 核心动作模式不变，具体动作每4-8周调整一次
  • 同一批动作几个月后身体产生神经适应，增肌刺激变小
  • 瓶颈期试试换动作：杠铃→保加利亚蹲，哑铃卧推→单臂卧推

五、落后肌群的追赶策略

遗传是起点，不是终点

  • 不同人对同一肌群的训练响应有巨大遗传差异（肌纤维类型分布、神经连接密度、肌腱附着点）
  • 难长的肌肉需要更多频率、更多量、更多时间

三个调整方向

  1. 增加频率：1次/周→2次→3次（落后肌群频率比强度更重要）
  2. 提高优先级：放到训练日最开始，精力最好时练
  3. 短期超量周期：8-12周内给落后肌群18-20组/周，其他维持8-12组，周期后回归均衡

肌肉记忆是真实的

  • 机制：训练时肌肉细胞核增加，停训后仍保留
  • 重新训练恢复速度比从零开始快2-3倍
  • 停训不等于从零开始，之前的努力以细胞核形式保留在体内

六、40岁以后的增肌现实

年龄带来的变化

  • 睾酮/生长激素水平下降
  • 肌肉蛋白合成响应变慢，恢复需要更长时间
  • 合成代谢抵抗增加（需要更多蛋白质触发同样合成反应）

但：60-80岁开始力量训练仍能增肌

围绝经期女性特别注意

  1. 骨密度加速流失 → 力量训练是”医疗级别的必要”，不是可选
  2. 蛋白质需求↑ → 从1.6g/kg提升到1.8-2.0g/kg，全天均匀分布
  3. 恢复时间↑ → 从每周5次降到3-4次
  4. 睡眠管理 → 激素波动影响睡眠，睡眠直接影响恢复

40+增肌三件核心事

✅ 蛋白质吃够
✅ 力量训练坚持
✅ 恢复放在优先位

七、身体重组（同时增肌减脂）

最容易发生重组的人群

  1. 训练新手（<1年）：神经肌肉响应强 + 脂肪储备充足
  2. 有停训史的人：肌肉记忆效应，恢复极快
  3. 较高体脂率训练者：有空间让脂肪作为能量底物

进阶训练者的策略：小波动周期

心理预期

  • 身体重组比单纯增肌/减脂都慢
  • 体重秤可能几个月不动
  • 用体围、照片、力量水平评估进展，不看体重

八、五大常见训练误解

误解 真相
普拉提可替代力量训练增肌 互补但不可替代，普拉提缺乏渐进超负荷系统
局部减脂存在 脂肪全身性消耗，但可增大特定部位肌肉改变视觉比例
髋部凹陷可练掉 主要由骨骼结构决定，只能通过增加臀中肌体积在视觉上减弱
宽/窄骨盆需要根本不同的训练 髋关节深度和方向更重要，通过试错找到适合自己的站距
握力训练不重要 握力是全因死亡率最强预测指标之一，可能是训练瓶颈

握力简单训练法

  • 每次训练后：正握悬挂 30-60s × 2-3组
  • 或：农夫行走 30-50m × 2-3组
  • 可以每天练，不会造成太多疲劳

十大训练原则总结

  1. 频率：每肌群每周≥2次
  2. 训练量：8-20组/肌群/周，新手8-10组起
  3. 渐进超负荷：没有它就没有长期进步
  4. 最后几个才是刺激：前面是铺垫
  5. 感受MRV：注意恢复信号，别硬撑
  6. 臀肌三方向：髋伸展+外展外旋+臀推（三分法则）
  7. 落后肌群：增频率、提优先、短期超量
  8. 40+可增肌：蛋白质够+训练坚持+恢复优先
  9. 身体重组可发生：但慢，用体围/力量评估
  10. 局部减脂不存在：普拉提≠力量训练，握力很重要
