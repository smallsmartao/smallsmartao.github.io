UNISON: 基于深度 LLM 融合的统一声音生成与编辑框架

本文最后更新于 2026年6月2日 上午

引言：为何统一音频生成与编辑如此困难？

一个实用的音频生成系统应能处理多样化任务：从文本描述生成音效、以目标说话人的声音合成语音、在录音中插入或移除特定声学事件、以及合成具有时间结构的声景。然而当前这些任务通常由孤立数据集上训练的专用模型分别处理，这种碎片化增加了部署复杂性，并阻碍了跨任务知识迁移。

尽管 AudioBox、MMAudio、Audio-Omni 和 UniSonate 等近期工作已向统一系统迈进，但两个根本性限制依然存在：

  1. 异构辅助模块导致的潜空间不一致——不同任务依赖不同的 mel 编码器、音素前端、条件流或时长预测器，各任务在微妙不同的表示体制下运作。
  2. 浅层文本条件化丢弃层次化语义——现有系统将单层文本表示（T5/CLAP/LLM 最后层）统一输入所有 DiT 层，丢弃了 Transformer 语言模型中低层编码词汇/句法、高层编码抽象语义的层次化组织。

来自香港中文大学等机构的研究团队提出 UNISON，首次在单一 MM-DiT 中联合实现逐层深度 LLM 融合、纯文本双语零样本 TTS、场景级编辑和定时合成，无需音素或 mel 侧编码器。

论文链接：arXiv:2605.31530

1. 架构设计

1.1 总体流水线

端到端流程如下：

  1. 构建文本指令和可选的源波形
  2. 冻结 VAE 编码波形得到 $z$（目标）和 $z_s$（源/参考）
  3. 采样流时间 $t$，构造噪声目标 $z_t$
  4. 通道拼接 $[z_t | z_s | m]$ 并嵌入为音频 token $h_0$
  5. 冻结 LLM 执行一次前向，逐块提供文本条件 $\tilde{E}_k$
  6. 预测速度 $v_\theta$ 并反向传播流匹配损失

推理时从噪声出发通过 ODE 求解器积分，再 VAE 解码。

1.2 音频 VAE

采用 MMAudio 连续 VAE。波形转换为 mel 频谱图后编码至 $z \in \mathbb{R}^{C \times T’}$（44.1 kHz 时 $C=40$，16 kHz 时 $C=20$）。同一 VAE 编码目标、编辑源和说话人参考，并在推理时解码去噪后的潜变量。

1.3 多任务输入设计

所有任务共享同一网络，仅 $(z, z_s, m)$ 和文本指令不同。任务标签 $m$ 为每帧标量：

  • $m=0$：生成（T2A, TTS, T2AS, 定时合成），$z_s = 0$
  • $m=1$：编辑，$z_s$ 为编辑前混合音频的 VAE 潜变量
  • $m=2$：零样本 TTS，$z_s$ 编码参考前缀

1.6 在线多任务数据合成

GPU 侧在线合成管线实时构造任务特定元组，处理 RMS 归一化（SNR 控制混合）、边界淡入淡出和随机化时间偏移。

1.7 课程训练与同质批处理

  • 两阶段课程：Stage 1 仅训练生成任务（前 150K 步），建立稳定的生成先验；Stage 2 引入所有编辑任务（约 70% 生成、30% 编辑）。
  • 任务同质批处理：每个 mini-batch 仅含单一任务类型，防止对立目标间的梯度冲突。

2. 模型配置与训练细节

两个变体：

  • D20（44kHz）：20 个双流块，40 通道潜变量，44.1 kHz VAE，621M 参数
  • D24（16kHz）：24 个双流块，20 通道潜变量，16 kHz VAE，732M 参数

训练数据：约 36M 片段（~57K 小时；2.3M 音频 + 33.7M 语音）。AdamW（$\beta_1=0.9$, $\beta_2=0.95$），学习率 $10^{-4}$ 余弦衰减，2000 步 warmup，8×H800，BF16 混合精度，EMA decay 0.999。

条件化方式 架构 参数量 FD↓ CLAP↑ WER-EN↓
O（深度融合, 7B） D24 732M 20.46 0.180 4.33

OL（深度+倒数第二层, 7B） D24 1,063M 20.18 0.187 5.52

O（深度融合, 3B） D24 694M 21.53 0.174 5.61

关键发现：

  1. 深度融合提升语义跟随：仅用倒数第二层（L）的 CLAP 最低，确认逐层注入优于单层广播。
  2. 冗余文本 token 损害 TTS：OL 变体获最佳 FD/CLAP 但 WER 最高（5.52%），双源文本引入噪声。
  3. 双流架构不可或缺：单流 S32 所有指标最差，共享归一化/QKV 阻碍模态特定表示。
  4. LLM 规模有影响：3B 替换 7B 后所有指标退化。

5. 局限性与未来方向

  • VAE 重建质量：MMAudio VAE 原为环境音设计，对语音高频共振峰细节和细微韵律变化的保真度构成性能上界。
  • 合成训练数据：编辑训练数据通过算法混合构造，与自然录音的复杂声学交互（混响、遮蔽、Lombard 效应）存在差距。
  • 规模与模态覆盖：当前模型（621M–732M）和数据量（~57K 小时）相对温和；架构设计支持扩展至视频特征（V2A）和更大 LLM 骨干。
  • 语言范围：当前支持英文和中文，扩展至其他语言仅需多语言语音数据，无需架构变更。

6. 总结

UNISON 通过逐层深度 LLM 融合和通道拼接架构，将所有音频生成与编辑任务路由到同一 VAE、DiT 骨干和前向传播中。单一 621M–732M 参数检查点在 T2A、TTS、零样本克隆、音频编辑和定时合成上实现了与专用模型竞争或超越的性能，且体量仅为可比统一系统（Audio-Omni 3.05B）的约四分之一。这证明了多任务音频生成不必然需要异构条件路径，为通过数据和模型规模增长（而非架构特化）来提升能力的通用音频系统指明了实际路径。
