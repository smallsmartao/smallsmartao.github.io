FSA-GRPO: Teaching Auditory LLMs to Use Few-shot Demonstrations

本文最后更新于 2026年6月3日 上午

论文信息

  • 标题: FSA-GRPO: Teaching Auditory LLMs to Use Few-shot Demonstrations
  • 作者: Haolong Zheng, Siyin Wang, Xulin Fan, Zengrui Jin, Mark Hasegawa-Johnson
  • 机构: University of Illinois Urbana-Champaign, Tsinghua University
  • 链接: arXiv:2606.02615
  • 日期: 2026年5月

1. 摘要与研究动机

Few-shot prompting 为听觉大语言模型（Auditory LLM）在低资源任务上的适配提供了一种无需梯度更新的有效途径，典型应用场景包括儿童语音识别。然而，当前绝大多数听觉大语言模型在训练阶段并未显式接触”demonstration-conditioned”（示例条件化）的推理格式，导致其从 few-shot prompting 中获益的上限受到限制。

本文提出 Few-Shot Aware GRPO (FSA-GRPO)，一种基于强化学习的后训练方法（post-training recipe），通过专门设计的奖励函数显式鼓励模型利用 few-shot demonstrations，从而强化其 few-shot 适配能力。核心发现：

  1. 仅使用高资源成人 ASR 数据训练即可提升模型在儿童 ASR、语音翻译和音频理解等任务上的通用 few-shot 适配能力；
  2. 在无法获取目标域数据的低资源场景下，FSA-GRPO 比直接在相关域外数据上微调更为有效；
  3. 该方法与模型架构无关（model-agnostic），在 Qwen2.5-Omni 和 Audio-Flamingo-Next 上均有效。

2. 相关工作

2.1 语音与音频的 Few-shot 适配

In-Context Learning (ICL) 已从文本领域扩展到多模态设置。在语音领域，先前工作主要将 ICL 视为推理时适配机制：

  • SICL 系列：将 Whisper 适配至中文方言识别，通过目标方言/说话人的配对语音-文本作为 demonstration；
  • Bayesian example selection：基于贝叶斯准则选择更有信息量的 demonstration；
  • M2R-Whisper：结合句子级 ICL 与 token 级检索；
  • TICL / TICL+：语义相似性检索 + 声学重排序，用于口音英语、多语种及儿童 ASR；
  • COSMIC / SALM：面向语音翻译和关键词感知 ASR/AST 的 demonstration-conditioned 方法。

2.2 训练模型利用 Demonstrations

  • MetaICL：通过多任务 NLP few-shot meta-training 增强 LLM 的 ICL 能力，但仅限文本模态；
  • SMILE / Omnilingual ASR：在语音域进行 ICL 格式训练，但绑定于特定 ASR 模型设计；
  • MetaSICL：对听觉 LLM 进行多任务 demonstration-conditioned 后训练，但未充分分析 zero-shot 能力的保持。

2.3 语音/音频 LLM 的 RL 后训练

Group Relative Policy Optimization (GRPO) 源自 DeepSeekMath，作为 PPO 的内存高效变体，已被应用于音频问答、口语问答、语音翻译和 ASR 等任务。GRPO 可直接优化序列级非可微目标（如 WER、BLEU），在有限后训练数据或域偏移下通常优于 SFT。

3. 方法论

3.1 整体框架

FSA-GRPO 的核心思想：将 few-shot ASR 推理格式引入 GRPO 训练，同时通过精心设计的奖励函数引导模型学会”利用 demonstration”而非仅”学习格式”。

训练流程概览：

  1. 从高资源 ASR 数据（Common Voice 英文子集）构建 few-shot 训练实例；
  2. 以查询语音配对检索得到的 (audio, text) demonstration；
  3. 使用 GRPO 优化 LoRA 适配器，奖励同时涵盖转录正确性和 demonstration 语义对齐。

3.2 训练数据构建

训练数据仅使用 Common Voice 英文子集，不依赖稀缺的目标域数据。具体构建方式遵循 TICL：

  • 查询集 $D_{\text{query}}$：Common Voice development split
  • Demonstration 池 $D_{\text{pool}}$：Common Voice training split
  • 每步采样查询对 $(x_q, y_q) \sim D_{\text{query}}$，从 $D_{\text{pool}}$ 检索 $k=3$ 个 in-context demonstrations $(x_j, y_j)_{j=1}^k$
  • 模型训练目标：$P_\theta(y_q \mid x_1, y_1, \ldots, x_k, y_k, x_q)$

由于 GRPO 计算开销较大，实际使用经数据选择策略筛选的 2k 查询实例。

评估前对预测和参考均应用 Whisper text normalizer。Bounded WER 将每条话语的编辑数上限设为参考长度，降低严重幻觉对语料级分数的影响。

4. 实验

4.1 基线对比

对比方法：

  1. Qwen2.5-Omni 原始模型：无后训练，测量原生 zero-shot/few-shot 能力
  2. MetaSICL：多任务 SFT 元训练，few-shot 格式训练
  3. Direct SFT (same data)：相同数据量的 ASR few-shot SFT
  4. FSA-GRPO (本文)

主要结果（Figure 2）：

任务 模型 0-shot 3-shot
MyST (↓) Qwen2.5-Omni 23.1 22.7
+MetaSICL 22.6 17.4
+SFT same data 16.9 17.5
+FSA-GRPO 11.2 —
RSR (↓) Qwen2.5-Omni 35.6 27.9
+MetaSICL 36.5 22.2
+SFT same data 28.7 22.3
+FSA-GRPO — 16.3
MMAU (↑) Qwen2.5-Omni 65.8 67.3
+MetaSICL 62.7 —
+FSA-GRPO 66.8 72.8
MMAR (↑) Qwen2.5-Omni 49.2 53.8
+FSA-GRPO 49.5 56.4

关键发现：

  • FSA-GRPO 在几乎所有设定下取得最优 few-shot 性能；
  • 改进迁移至非重叠的 held-out 任务（音频理解、多语种 ASR、语音翻译），说明提升的是通用 ICL 能力而非特定任务拟合；
  • 相比其他后训练方法，FSA-GRPO 更好地保持了 zero-shot 性能。

4.2 与直接微调的对比

在目标域（RSR 儿童语音）训练数据不可用的现实低资源场景下，对比：

分析要点：

  • 在相同有限预算下，相关域适配优于通用域外 ASR 微调；
  • Direct GRPO 优于 Direct SFT，说明 RL 后训练能从有限数据中提取更强信号；
  • FSA-GRPO 在 RSR 上实现 53.9% 相对 WER 降低，无需任何目标域训练数据；
  • 即使 in-context examples 来自域外（MyST 而非 RSR），FSA-GRPO 仍显著优于直接微调。

4.3 跨模型迁移性

将同一 FSA-GRPO 训练配方应用于 Audio-Flamingo-Next（未做模型特定超参调优）：

  • MyST、RSR 及域外 ICE 设定下均获得一致改进；
  • 增益相对 Qwen2.5-Omni 较温和，可能因超参数和奖励权重未针对该模型优化；
  • 初步验证了方法的跨模型可迁移性。

4.4 数据选择策略

GRPO 训练开销大，需在固定预算下识别最有价值的训练实例。对每个实例计算两个诊断分数：

  • Context quality：gold transcript 与检索标签的最大相似度（$\geq 0.6$ 为 good context）
  • Current performance：基座模型 few-shot 预测的原始 WER（$\geq 0.2$ 为 bad performance）
训练子集 (1k) Bounded WER
Qwen2.5-Omni (无训练) 27.83
+ Random 22.14
+ Good ctx, good perf 23.59
+ Bad ctx, bad perf 21.37
+ Good ctx, bad perf 20.56

结论：

  • 模型已解决的实例（good perf）提供较弱学习信号；
  • 失败案例中，context quality 进一步区分价值：good-context / bad-performance 的实例最有价值——即检索到了有用 demonstration 但模型未能利用的情况；
  • 主训练配方优先选择此类实例。

4.5 辅助奖励权重消融

$\lambda$ RSR 3-shot Bounded WER
0 21.58
0.01 19.78
0.02 18.52
0.04 16.56
0.08 17.31

分析：

  • 所有非零 $\lambda$ 均优于纯 ASR 奖励（$\lambda=0$）；
  • 最优值为 $\lambda=0.04$，适度的语义对齐奖励引导模型更好地利用 demonstrations；
  • $\lambda$ 过大（0.08）导致模型过度匹配/复制检索标签，性能轻微下降；
  • SA 奖励最有效的角色是温和的正则化信号而非主导优化目标。

5. 结论

FSA-GRPO 是首个面向听觉 LLM 的 RL-based model-agnostic 后训练方法，用于提升语音 in-context learning 能力。核心设计要素包括：

  1. Few-shot-aware reward：联合奖励转录正确性和 demonstration 利用程度；
  2. 仅需高资源 ASR 数据训练：改进迁移至儿童 ASR、多语种 ASR、语音翻译和音频理解等多个 held-out 任务；
  3. 优于直接微调：在低资源场景下提供更有效的适配策略；
  4. 数据选择与奖励权重的系统分析：good-context/bad-performance 实例最有价值，SA 奖励权重 $\lambda=0.04$ 为最优。

6. 局限性

  • 结果基于单一 checkpoint 单次评估，未报告多随机种子的均值和标准差；
  • Audio-Flamingo-Next 使用未优化的超参数，属初步跨模型验证；
  • 仅研究固定 demonstration 数量和检索策略；
  • 评估依赖基准数据集和自动指标，不完全反映实际用户体验；
  • 不构成临床、教育评估或法律部署的可靠性证明。

7. 个人评述

本文在”如何让听觉 LLM 真正学会利用 few-shot demonstrations”这一问题上给出了清晰且系统的回答。相比此前 SFT-based 的 few-shot 训练（如 MetaSICL），FSA-GRPO 通过 RL 框架将”利用 demonstration”显式建模为可优化的奖励目标，避免了模型仅学习格式而未学习利用内容的问题。SA 奖励的设计兼具直觉合理性和工程实用性（基于组内百分位的自适应阈值），数据选择策略的分析也为实践者提供了有价值的指导。

值得关注的是，仅 2k 高资源英文 ASR 数据的 GRPO 训练即可在儿童语音、多语种 ASR 和语音翻译上获得一致改进，这暗示 few-shot 适配能力可能是一种通过适当训练信号即可激活的 “latent capability”。
