LLM can Read Spectrogram: Encoder-free Speech-Language Modeling

本文最后更新于 2026年6月17日 下午

作者 Ruchao Fan, Yiming Wang, Yuxuan Hu, Bo Ren, Yufei Xia, Xiaofei Wang, Yao Qian, Shujie Liu, Jinyu Li
机构 Microsoft, USA

主题 去掉语音编码器，让 LLM 直接从 Mel 频谱图学习语音-文本对齐

1. 核心问题：为什么要去掉语音编码器？

当前主流 Speech-LLM 范式（如 Phi-4-MM、SALMONN 等）依赖三段式架构：预训练语音编码器 → 模态投影层 → LLM。语音编码器（通常是 Whisper-large 级别，600M+ 参数）负责将原始音频压缩为高层语义表征，再投射到 LLM 的嵌入空间。

这一范式存在三重瓶颈：

  1. 计算开销：编码器本身参数量巨大，推理时增加显著延迟。
  2. 表征错配：编码器学到的表征未必是 LLM 内部处理的最优格式，两者之间存在语义鸿沟。
  3. 信息瓶颈：LLM 只能通过编码器的压缩输出间接感知语音，原始声学细节在编码阶段可能已经丢失。

视觉领域的 Fuyu、Tuna-2 等工作已经证明：LLM 可以直接处理原始像素 patch，无需视觉编码器。本文将这一思路迁移到语音模态，提出核心研究问题：LLM 能否直接”阅读” Mel 频谱图？

2. Mel-LLM 架构设计

2.1 整体架构

Mel-LLM 的核心设计思想是：移除传统 Transformer/Conformer 编码器模块，仅保留轻量卷积层用于时间维度下采样，让 LLM 自身通过其 Transformer 层学习从原始频谱特征到语言语义的映射。系统基于 Phi-4-MultiModal (Phi-4-MM) 构建，支持 ASR（语音转文字）和 TTS（文字转语音）两个方向。

2.2 ASR：语音输入路径

Step 1: Mel 频谱提取与 MVN 归一化

提取 80 维 log-Mel 频谱特征，使用训练集预计算的均值/方差进行归一化（Mean-Variance Normalization）。

Step 2: 轻量卷积下采样（可选）

3. 实验设置

3.1 模型配置

  • LLM 基座：Phi-4-MM，隐藏维度 3072，32 层，24 注意力头，8 KV 头
  • LoRA：rank=320, $\alpha=640$，应用于注意力和 MLP 的线性层
  • ASR：移除主体 Conformer 编码器，保留 NeMoConv 层用于下采样
  • TTS VAE：3 层残差 MLP（dim=256）+ 5 层 Conv1D postnet

3.2 ASR 训练数据

仅使用公开英文语音数据，共约 3100 万条语料（~64k 小时）：

  • LibriSpeech (960h)、GigaSpeech (10kh)、MLS English (44kh)
  • SPGISpeech (5kh)、CommonVoice 15、VoxPopuli、TED-LIUM
  • AMI、Earnings-22、FLEURS English

训练配置：DeepSpeed ZeRO Stage-1，16×H100 GPU，AdamW 优化器（peak LR $1\times10^{-4}$），线性 warmup-decay（9000 warmup steps），梯度裁剪 1.0，有效 batch size 512。数据迭代 3 轮。

3.3 TTS 训练数据

使用 Libriheavy 50k 小时英文数据，dropout 设为 0.5（输入投影层和输出 Mel head），KL 权重 0.05，stop 权重 1.0，flux 权重 0.5，训练 5 个 epoch。

关键发现：

  • Phi-4-MM 初始化至关重要：encoder-free + Phi-4-MM LoRA 初始化达到 7.12% 平均 WER，仅比保留随机编码器的 baseline (6.97%) 高 0.15%。随机初始化 LoRA 则进一步退化到 7.44%。多模态预训练提供了解释原始频谱特征所需的归纳偏置。
  • Encoder-free 与 Whisper-Large-V3 持平：Mel-LLM (Random init) 的 7.44% 恰好等于 Whisper-Large-V3，而 Mel-LLM 完全没有独立的语音编码器。

关键发现：数据量是 encoder-free 方案的核心使能因素。有限公开数据下性能差距为 +11.3% 相对退化；扩展到 10 倍内部数据后，差距收窄至仅 +3.8%。充足数据使 LLM 能够自主学习隐式语音编码能力。

100Hz 获得最优 WER (6.58%)，但训练速度仅为 baseline 的 0.33×。12.5Hz 在质量和速度之间取得最佳平衡：WER 7.12%，训练速度 1.57× 加速（因为完全去掉了编码器的前向计算）。

有趣的是，12.5Hz 比 25Hz 反而更优（7.12 vs 7.21）。作者归因于 Phi-4-MM 预训练 LoRA 恰好基于 12.5Hz token rate 训练，12.5Hz 可以直接复用预训练权重，而 25Hz 需要适配帧率不匹配的问题。

4.4 消融实验：层级冻结揭示 LLM 层的角色分工

System Avg WER
Phi-4-MM-FT-Base (有编码器) 6.97
Mel-LLM (Random init) 7.44
Mel-LLM (all LoRA trainable) 7.12
+ freeze L16–31 7.94
+ freeze L20–31 7.77
+ freeze L24–31 7.43
+ freeze L28–31 7.40

关键发现：

  • 冻结 L28–31 仅造成 0.28% 退化（7.12→7.40），冻结 L24–31 得到 7.43%——几乎等于完全可训练的结果。
  • 但冻结扩展到 L20–31 (7.77%) 和 L16–31 (7.94%) 时退化明显加剧。

这揭示了清晰的层级功能分化：

  • Layer 0–23：必须被适配以学习”隐式语音编码器”功能——将原始频谱模式转换为语言学有意义的表征。
  • Layer 24–31：已在 Phi-4-MM 预训练中编码了高层语言语义（推理、话语结构、文本生成），无需语音特异性适配即可直接迁移。

这与 NLP 领域的发现一致：Transformer 底层捕获局部特征，高层处理抽象语义。

4.5 TTS：Next-Token VAE 初步结果

System WER ↓ UTMOS ↑
Mel-LLM (Random init) 收敛但无可听输出 —
Mel-LLM (Phi-4-MM, no norm) 11.03 3.10
Mel-LLM (Phi-4-MM, MVN) 14.75 3.25
+ dropout 0.1 85.51 1.38
+ fix-KL (0-mean) 12.65 3.22
+ sigma-VAE (0-mean) 18.07 3.29

关键发现：

  1. Phi-4-MM 初始化对 TTS 同样不可或缺：随机初始化虽然训练收敛，但生成的音频完全无法听辨。作者推测 LLM 嵌入空间语义丰富，从零开始对齐 Mel 空间极为困难。
  2. Dropout 至关重要：将 dropout 从 0.5 降至 0.1 导致灾难性退化（WER 85.51%），表明严重的 exposure bias。训练时足够的 dropout 防止模型过度依赖 teacher-forcing 的 ground-truth Mel 输入。
  3. 归一化与 KL 变体：不加归一化的 Mel 特征获得最优 WER (11.03)，添加 CMVN 略微提升感知质量 (UTMOS 3.25 vs 3.10) 但牺牲了可懂度。fix-KL 和 sigma-VAE 均未带来一致改进。

虽然 TTS 结果尚未达到 SOTA，但验证了同一个 encoder-free LLM 骨架可以同时用于 ASR 和 TTS 的可行性。

5. 讨论与展望

核心洞察

Mel-LLM 的核心发现可以概括为一句话：当 LLM 足够大时，其底层 Transformer 层能够自发学习充当”语音编码器”的功能。这意味着独立的大型预训练语音编码器并非必需——它只是一种用预训练知识加速收敛的手段，而非不可替代的组件。

与同期工作的关系

论文撰写期间，Google 发布了 Gemma 4 12B（2026年6月），同样移除了视觉和音频编码器，通过轻量投影将原始音频直接输入 LLM。但 Gemma 4 未提供详细的 encoder-based vs encoder-free 对比实验。本文是首个提供系统性苹果对苹果比较的学术发表。

局限性

  • ASR 和 TTS 分别训练，尚未实现联合训练
  • TTS 性能有待优化（WER 11.03% 仍远高于商用系统）
  • 未探索语音预训练（speech-only pretraining）对统一表征学习的增益

未来方向

  • 联合 ASR+TTS 训练
  • 语音专用数据预训练以学习统一表征
  • 进一步优化 VAE 解码器和训练策略

6. 总结

Mel-LLM 证明了一个简洁而有力的论点：大语言模型具备直接从 Mel 频谱图学习语音理解和生成的能力，不需要传统的预训练语音编码器。在充足数据规模下，encoder-free 方案与 encoder-initialized 方案的性能差距收窄至仅 3.8% 相对退化。层级分析进一步揭示了 LLM 内部的功能分化——底层自发学习声学处理，高层保持语言语义能力。这为构建真正统一的、极简架构的语音-语言模型开辟了新方向。
