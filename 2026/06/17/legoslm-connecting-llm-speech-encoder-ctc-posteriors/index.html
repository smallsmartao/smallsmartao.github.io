LegoSLM: Connecting LLM with Speech Encoder using CTC Posteriors

本文最后更新于 2026年6月17日 下午

论文概览

论文标题: LegoSLM: Connecting LLM with Speech Encoder using CTC Posteriors
作者: Rao Ma (University of Cambridge), Tongzhou Chen, Kartik Audhkhasi, Bhuvana Ramabhadran (Google DeepMind)
arXiv: 2505.11352
发表时间: 2025年5月

本文提出了 LegoSLM，一种全新的范式，利用 CTC 后验概率矩阵作为语音编码器（Speech Encoder）与大语言模型（LLM）之间的桥梁。该方法在保留丰富语音信息的同时，实现了模块化组合——训练完成后，语音编码器可以零样本（zero-shot）方式替换，无需重新训练 LLM。

1. 引言 (Introduction)

近年来，大规模预训练语音编码器（如 USM、SeamlessM4T）和大语言模型（如 Gemma、LLaMA）分别在语音和文本领域取得了 SOTA 性能。如何有效结合两者，是当前研究的核心问题。现有方法主要有两类：

  1. ASR 纠错 (AEC)：将 ASR 解码结果（文本假设）送入 LLM 进行纠错。优点是模块化，缺点是信息损失严重——LLM 只能看到离散文本。
  2. 语音提示 (Speech Prompts)：通过映射网络将语音编码器的连续向量转化为 LLM 可接受的 prompt。保留了更多信息，但牺牲了灵活性——LLM 与特定编码器绑定。

LegoSLM 提出了第三条路径（图中红色路径）：利用 CTC 后验概率乘以 LLM 嵌入表，重建伪语音嵌入。这既保留了丰富的概率信息，又天然支持模块化组合。

2. 相关工作 (Related Work)

模块化 ASR 方法

(Dalmia et al., 2023; Botros et al., 2023) 等工作关注构建模块化 E2E ASR 架构，训练解码器网络来嵌入 CTC 后验并输出细化的 ASR 假设。与之不同，LegoSLM 使用 decoder-only Transformer（即预训练 LLM），而非从头训练的 encoder-decoder 架构，充分利用 LLM 预训练获得的世界知识。

ASR 纠错 (AEC)

AEC 以 ASR 假设为输入，训练模型自动检测和纠正识别错误。多项研究利用 N-best list 代替单一假设以提供更丰富信息 (Zhu et al., 2021; Ma et al., 2023a)。近期工作开始使用 LLM 构建 AEC 系统 (Ma et al., 2023c; Chen et al., 2023; Li et al., 2024)。

LLM + 语音提示

映射网络（mapping network）将语音编码器输出转化为 LLM 兼容的声学提示。即使简单的线性投影层也展现了强大的对齐能力 (Fathullah et al., 2024; Ma et al., 2024)。部分方法通过堆叠向量或 CTC 压缩器来缩短序列长度 (Wu et al., 2023)。

应用场景：

  • ASR：LLM 基于 CTC 后验输出生成转录文本
  • AST（语音翻译）：语音编码器生成源语言 token 的后验，LLM 生成目标语言翻译

3.3 CTC Blank Token 讨论

CTC 网络输出的特殊 token <blk> 不属于 LLM 词汇表。实验中将其映射到随机初始化的新嵌入向量 $e_{\langle blk\rangle}$。

3.4 零样本系统组合 (Zero-shot System Combination)

LegoSLM 的核心优势之一：由于 LLM 仅接收 CTC 后验（离散概率分布），训练完成后可以插入不同的语音编码器，只要其使用相同的 CTC 词汇表即可。

具体流程：

  1. 基于原始语音编码器的输出微调 LLM
  2. 评估时，插入另一个单独训练的语音编码器
  3. 无需更新任何模型权重

这在实际应用中非常有价值——当 ASR 编码器需要用更多数据更新或适应新领域时，LLM 无需重训。

3.5 AM/LM 频谱控制 (AM/LM Spectrum Control)

在零样本组合中，编码器和解码器可能能力不对等。借鉴传统语音识别中声学模型（AM）和语言模型（LM）权重调节的思想，提出在 CTC softmax 层引入温度参数 $\tau > 0$：

  • $\tau > 1$：CTC 概率变平坦，LLM 在生成中获得更大自由度
  • $\tau < 1$：CTC 概率变尖锐，语音编码器获得更大确定性

这提供了一种简单有效的解码时控制手段，无需重新训练。

3.6 模型变体 (Model Variants)

CTC 概率分布遵循长尾分布，大部分概率集中在 top-K 预测上。因此可以只保留每帧的 top-K 预测：

LegoTopS (Top-K + Softmax)

计算索引向量 $i_t$ 对应 $z_t$ 中 top-K 值的位置，然后用 top-K 预测的 softmax 作为权重重建语音嵌入：

LegoTopP (Top-K + Projection)

将 top-K 预测对应的 LLM 嵌入拼接后，通过一个线性投影层映射到原始嵌入维度。该投影层随机初始化并与 LLM 权重联合训练。

4. 实验设置 (Experimental Setup)

4.1 模型配置

  • 语音编码器: USM (Universal Speech Model) 300M 参数

    • 2 层下采样卷积 + 24 层 Conformer，模型维度 768
    • 预训练于多语言 YouTube 数据（BEST-RQ loss）
    • 添加 CTC 层后在各数据集上微调
    • CTC 词汇表大小：256K（与 Gemma 相同）

  • LLM 解码器: Gemma 2B

    • 18 层 Transformer，模型维度 2048，词汇表 256K
    • ASR 实验使用 pt_f32 checkpoint
    • AST 实验使用 it_f32 checkpoint（指令微调版）

  • 训练细节:

    • LegoSLM 训练中冻结 USM-CTC，仅微调 Gemma
    • 学习率 1e-4，cosine decay
    • LibriSpeech/CoVoST 2: 5000 steps, batch size 512
    • MLS en-us: 25K steps, batch size 1024
    • Multi/Public: 40K steps, batch size 1024
    • 使用 SpecAugment + dropout 0.1

4.2 基线系统

5.3 AM/LM 频谱控制实验

实验验证了温度参数 $\tau$ 的有效性：

  • USM-CTC (lbs) + Gemma (mls-en)：解码器更强 → 最优 $\tau = 1.1$，给 LLM 更多自由度
  • USM-CTC (mls-en) + Gemma (lbs)：编码器更强 → 最优 $\tau \approx 0.6$，增强编码器确定性

极端情况分析：

  • $\tau \to 0$（如 $10^{-4}$）：近似 CTC greedy 解码
  • $\tau \to \infty$（如 $10^4$）：语音嵌入退化为 LLM 嵌入表的平均向量，LLM 产生幻觉

发现：

  • Softmax 加权（LegoTopS）优于投影层（LegoTopP）→ ASR 分数很重要
  • K=100 时 LegoTopS 与全词汇表 LegoSLM 持平 → 长尾分布使 top-K 保留了绝大部分信息
  • K=1（等价于 CTC greedy 解码无合并）性能大幅下降 → 替代预测对 LLM 至关重要
  • Top-K 方法有速度优势：无需全词汇表 softmax

6. 结论 (Conclusions)

LegoSLM 提出了一种新颖的预训练语音编码器与 LLM 结合方法：

  1. 性能：在 ASR 和 AST 任务上均取得了与现有方法竞争力相当的性能
  2. 模块化：CTC 后验作为桥梁，训练完成后 ASR 编码器可零样本替换
  3. 可控性：通过温度参数 $\tau$ 调节编码器与 LLM 的相对权重
  4. 隐私保护：CTC 后验相比连续语音特征，更好地保护了说话人隐私
  5. 高效性：无需 beam search 生成 N-best list，直接使用概率分布

7. 局限性 (Limitations)

  • 仅验证了 USM + Gemma 组合，需扩展到更多基础模型
  • 仅使用 CTC 编码器，可扩展到 RNN-T 或 LAS 架构
  • 使用全量微调，未验证 LoRA 等参数高效方法（预计趋势类似）

个人思考

LegoSLM 的核心洞察非常优雅：CTC 后验本质上是一个定义在 LLM 词汇表上的概率分布，天然可以与 LLM 嵌入表做矩阵乘法得到”伪语音嵌入”。这个连接方式：

  • 比 AEC 保留更多信息（概率分布 vs 离散文本）
  • 比 Speech Prompts 更模块化（标准化接口 vs 连续特征）
  • 计算简单高效（一次矩阵乘法）

温度控制机制也很实用——在实际部署中，编码器和 LLM 可能来自不同训练阶段，能在解码时灵活调节两者贡献非常有价值。
