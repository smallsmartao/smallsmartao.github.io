Transducer-Llama: Integrating LLMs into Streamable Transducer-based Speech Recognition

本文最后更新于 2026年6月17日 下午

论文信息

  • 标题: Transducer-Llama: Integrating LLMs into Streamable Transducer-based Speech Recognition
  • 作者: Keqi Deng, Jinxi Guo, Yingyi Ma, Niko Moritz, Philip C. Woodland, Ozlem Kalinli, Mike Seltzer
  • 机构: Meta AI, University of Cambridge
  • arXiv: 2412.16464

摘要

大语言模型（LLMs）在自动语音识别（ASR）领域的应用日益广泛，但如何使模型具备流式（streaming）能力仍然是一大挑战。本文提出了一种新型模型架构 Transducer-Llama，将 LLM 集成到 Factorized Transducer（FT）模型中，天然地支持流式识别。此外，针对 LLM 大词表带来的数据稀疏与训练成本问题，本文引入了高效的词表适配（Vocabulary Adaptation）技术。实验表明，直接用强预训练 LLM 作为 predictor 优化 RNN-T loss 仅能带来有限的提升，因此本文进一步提出 Weak-to-Strong LM Swap 策略：训练时使用弱 LM predictor，解码时替换为强 LLM，并结合 MWER loss 进行微调。在 LibriSpeech 和大规模多语言 MLS 数据集上，Transducer-Llama 相对于强 FT 基线实现了 17% 的相对 WER 降低，相对于 RNN-T 基线实现了 32% 的相对 WER 降低。

I. 引言 (Introduction)

端到端（E2E）ASR 直接将语音转写为文本，简化了传统的 pipeline 方法。在很多实际场景中，流式 ASR 对于低延迟至关重要。RNN-T 是流式 ASR 中广泛使用的方法，但其 prediction network 虽然结构类似语言模型，却并不能作为显式 LM 使用，这使得预训练 LM 的融合变得困难。

Factorized Transducer (FT) 将 LM 组件从 neural transducer 中分离出来（如 non-blank predictor），但即便如此，使用强内部 LM 在通用数据集上的提升仍然有限。近期 [8] 提出了有效的内部 LM 融合与训练策略，显著提升了 FT 模型性能。

另一方面，基于文本的 LLM 取得了巨大成功。一些研究将 LLM 扩展到处理语音输入（speech LLMs），将语音 prompt 前置于文本序列。但这种 decoder-only 架构天然不支持流式操作，因为语音 prompt 必须在文本输入之前完整给出。此外，LLM 的大词表（如 Llama3 的 128K tokens）在 ASR 系统训练中会导致数据稀疏和高昂的训练成本。

本文提出 Transducer-Llama 架构，基于 FT 模型，使用 LLM 作为 non-blank predictor，自然地支持 LLM-based 的流式 ASR。核心贡献包括：

  1. 词表适配技术：将 LLM 对齐到专用的 ASR 词表
  2. Weak-to-Strong LM Swap 策略：训练时使用弱 LM，解码时替换为强 LLM
  3. MWER 微调：在 LM 替换后使用 MWER loss 优化 LLM predictor 的集成

II. 相关工作 (Related Work)

流式 LLM-based 语音系统

由于 speech LLMs 将语音输入作为 prompt 前置于文本序列，在线操作需要基于已知的 speech-text alignment 来限制每个文本 token 可见的语音范围：

  • [23] Speech ReaLLM: 使用外部 CTC 模型提供对齐，但破坏了 E2E 模型的 flat-start 优势
  • [24]: 训练时通过 CTC greedy search 实时获取对齐，但降低了训练效率
  • [16] BESTOW: 使用 Wait-k 策略提供硬编码对齐，但不适合低延迟场景

本文的 Transducer-Llama 提供了一种自然的解决方案，支持 LLM-based 在线 ASR，且可以从 flat-start 高效训练。

III. Transducer-Llama 方法


图 1: Transducer-Llama 框架示意图。⊕ 表示加法。LLM 参数冻结（frozen）。红色标注的 output layer 和 embedding layer 基于词表适配方法初始化。

Transducer-Llama 使用 FT 架构，将 LLM 作为 non-blank predictor 在解码时建模因果依赖关系。Embedding layer 用作 blank predictor。整体框架结合词表适配、weak-to-strong LM swap 策略和 MWER 训练，实现高效训练并充分利用 LLM 提升 ASR 性能。

III-A. LLM 词表适配 (LLM Vocabulary Adaptation)

LLM 拥有庞大的词表（如 Llama3 为 128K），不适合语音系统直接使用。RNN-T loss 的输出是一个包含词表维度的 4 维张量，大词表会导致巨大的显存消耗和训练速度下降。

本文设计了词表适配方法，将 LLM 适配到 ASR 系统词表（通常为 5000 tokens，远小于 LLM 词表）。训练时 LLM 的 Transformer 层冻结不变，只更新 embedding layer 和 output layer。

初始化策略：假设新的权重矩阵为 $W_{new} \in \mathbb{R}^{|V| \times d}$，其中 $V$ 为 ASR 词表，$d$ 为 embedding 维度。LLM 原始词表为 $U$，对应权重矩阵为 $W_{llm} \in \mathbb{R}^{|U| \times d}$。对于每个 token $t_i \in V$：

  1. 若 $t_i \in V \cap U$：直接复制，$W_i^{new} = W_j^{llm}$，其中 $j$ 为 $t_i$ 在 LLM 词表中的索引
  2. 若 $t_i \notin U$：使用 LLM tokenizer 将 $t_i$ 进一步分词，$W_i^{new}$ 初始化为对应子词 embedding 的平均值
  3. 若无法分解：随机初始化

注意：embedding layer 和 output layer 的权重矩阵是独立训练的（不共享）。

III-B. Weak-to-Strong LM Swap

初步实验表明，使用 RNN-T loss 训练时，引入更强的 LM 作为 non-blank predictor 只能带来相对有限的 ASR 提升（这与之前的研究 [7], [9] 一致）。

为解决这一问题，本文提出 Weak-to-Strong LM Swap 策略：

  • 训练时：使用弱 LM（如 stateless predictor，即 embedding layer，功能类似 bigram LM）
  • 解码时：替换为强 LLM

这一策略的核心思想：

  1. 防止模型过度依赖强 LM 的准确预测，确保声学信息被充分优化和利用
  2. 大幅加速训练过程（弱 LM 计算开销极小）

III-C. 训练与解码流程 (Proposed Training and Decoding)

完整流程如下：

  1. 阶段一：从头训练 FT 模型，使用弱 LM（embedding layer）作为 non-blank predictor，训练使用 RNN-T loss + ILM loss [8]
  2. LM 替换：模型收敛后，将弱 LM 替换为 LLM，FT 模型变为 Transducer-Llama
  3. 阶段二：使用内部 LM-aware MWER loss [8] 微调 Transducer-Llama

MWER 训练直接优化 LLM predictor 集成，以 word-level edit distance 为目标进行序列判别训练。N-best hypotheses 根据公式 (1) 生成，MWER 训练时的 $\alpha$、$\beta$ 值在推理时也同样使用。

实验表明，相比 RNN-T loss，MWER loss 能更有效地利用强 LM 来提升 ASR 性能。

这一框架与传统的 NN-HMM hybrid 序列判别训练策略 [31]-[33] 或外部 LM 融合 [34] 有诸多相似之处。

IV. 实验 (Experiments)

IV-A. 数据集 (Corpus)

  • LibriSpeech LM 数据: 800M words + 训练数据 transcripts
  • MLS LM 数据: LibriSpeech LM (En) + French (146M words) + Italian (41M words) + Dutch (46M words)

IV-B. 模型配置 (Model Descriptions)

通用设置：

  • ASR 词表大小：5000 tokens + blank token
  • 解码 beam size：10

LibriSpeech 编码器：

  • 20 层 Emformer，160ms segment size
  • 512 attention dimensions, 2048 feed-forward dimensions, 8 heads
  • 参数量：63M

MLS 编码器：

  • 30 层 streaming Conformer (190M 参数)
  • chunk-based mask, 320ms 平均延迟

输入特征：80 维 filterbank, 10ms 帧率, 1/4 下采样

基线模型：

  • RNN-T: 2 层 LSTM predictor, 2048 hidden dimensions
  • FT baseline: 同结构的 non-blank predictor，在纯文本数据上预训练后冻结

Transducer-Llama 设置：

  • $\alpha = 0.6$, $\beta = 0.6$（公式 1）
  • 训练时使用 embedding layer 作为 non-blank predictor
  • LLM 选择：Llama2-0.5b 和 Llama3-8b
  • FFT Llama2：Transformer 层也参与更新

训练配置：

  • LibriSpeech: 40 epochs
  • MLS: 200k steps, total batch size 5.3M
  • MWER: 几千步
  • LM 训练: 最多 40 epochs
  • LLM 词表适配: 通常几个 epoch 后即 early stop

关键分析：

  5. 弱 LM 训练的优势：加速训练 + 防止模型依赖强 LM 的准确预测 → 确保声学编码器被充分训练

V. 结论 (Conclusions)

本文提出的 Transducer-Llama 框架将 LLM 自然地集成到在线 ASR 中，主要贡献：

  1. 词表适配技术：保留 ASR 专用 tokenizer 的灵活性，同时利用 LLM 的预训练知识
  2. Weak-to-Strong LM Swap：充分利用 LLM 提升 ASR 性能，同时保持良好的训练速度
  3. MWER 训练：在 LM 替换后进一步优化 Transducer-Llama 的集成效果

实验在 LibriSpeech 和 MLS 数据集上验证了方法的有效性：

  • 相比强 FT 基线：17% 相对 WER 降低
  • 相比 RNN-T 基线：32% 相对 WER 降低

个人思考

Transducer-Llama 的核心洞察在于：强 LM 在 RNN-T loss 训练中无法被充分利用（模型会”偷懒”，过度依赖 LM 预测而忽视声学信息），而 weak-to-strong swap + MWER 的两阶段策略巧妙地绕过了这一瓶颈。这与传统 hybrid 系统中 LM 的使用方式（CE 训练 + 序列判别训练 + LM 融合）异曲同工，说明 E2E 模型与传统方法在方法论层面正在逐步收敛。

词表适配带来的 8x 训练加速尤为实用——在 LLM 时代，如何高效地将 LLM 的文本知识注入到语音系统中，同时避免大词表的计算瓶颈，是工程落地的关键问题。
