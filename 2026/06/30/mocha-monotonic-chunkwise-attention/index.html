MoChA：单调分块注意力机制——在线解码与软注意力的完美折中

论文：Monotonic Chunkwise Attention (ICLR 2018)
作者：Chung-Cheng Chiu, Colin Raffel (Google Brain)
链接：arXiv:1712.05382
代码：github.com/craffel/mocha

1. 核心问题：在线解码 vs. 软注意力

标准 Seq2Seq 模型中的 Soft Attention（Bahdanau et al., 2015）在每个解码步都需要遍历完整的编码器记忆序列，带来两个根本问题：

  1. 解码复杂度为 $O(TU)$（$T$ 为输入长度，$U$ 为输出长度），时间空间均为二次
  2. 无法在线解码——必须等待整个输入序列处理完才能开始输出

对于语音识别这类天然具有单调对齐特性且需要实时响应的任务，这些限制极为致命。

Raffel et al. (2017) 提出了 Hard Monotonic Attention，实现了在线 + 线性时间解码，但代价是：

  • 每个解码步只能看到一个记忆项（hard assignment）
  • 强制严格单调，表达力受限
  • 实验中性能显著落后于 Soft Attention

MoChA 的核心思想：在 Hard Monotonic Attention 确定的位置上，额外允许对一个小窗口（chunk）进行 Soft Attention——兼得在线解码与软对齐的优势。

MoChA 的核心改进：Hard Monotonic 选定位置 $t_i$ 后，不再直接取 $h_{t_i}$，而是对 $t_i$ 前的长度为 $w$ 的窗口做 Soft Attention：

其中 ChunkEnergy(·) 是独立于 MonotonicEnergy(·) 的第二个能量函数。

关键性质：

  • 仍为在线解码：仅需 $h_1, \ldots, h_{t_i}$
  • 线性复杂度：只多了常数因子 $w$
  • 允许局部重排序：chunk 内的注意力权重可以非单调
  • 参数增量极小：仅多一个 ChunkEnergy（~1% 参数增加）
  • $w=1$ 时退化为 Hard Monotonic Attention

  1. $e_{i,j} = \text{MonotonicEnergy}(s_{i-1}, h_j)$
  2. $p_{i,j} = \sigma(e_{i,j} + \epsilon)$，$\epsilon \sim \mathcal{N}(0,1)$
  3. $\alpha_{i,:}$ 通过 cumprod/cumsum 并行计算
  4. $u_{i,j} = \text{ChunkEnergy}(s_{i-1}, h_j)$
  5. $\beta_{i,:}$ 通过 MovingSum 并行计算
  6. $c_i = \sum_{j=1}^T \beta_{i,j} h_j$

3. 实验结果

3.1 在线语音识别（WSJ）

在 Wall Street Journal 语料上的在线语音识别实验：

方法 Best WER Average WER
CTC baseline (Raffel et al., 2017) 33.4% —
Reinforcement Learning (Luo et al., 2016) 27.0% —
CTC (Wang et al., 2016) 22.7% —
Hard Monotonic Attention (Raffel et al., 2017) 17.4% —
Soft Attention (offline) 14.2% 14.6 ± 0.3%
MoChA, w=2 13.9% 15.0 ± 0.6%

关键发现：

  • MoChA 以 $w=2$ 这么小的窗口就追平了 offline Soft Attention 的性能
  • 相比之前最优的在线方法（Hard Monotonic 17.4%），相对提升 20%
  • $w \in {2, 3, 4, 6, 8}$ 表现相当，说明即使极小的 chunk 也足够
  • 这是首次在线注意力机制追平离线 Soft Attention

控制实验排除混淆因素：

  • 增加 Monotonic Attention 的能量函数隐层维度（匹配参数量）→ 无显著提升
  • 减小 MoChA 能量函数隐层维度（减少参数量）→ 仅增 0.2% WER
  • 增加卷积前端的时间感受野 → 无显著提升

这些实验确认收益确实来自 chunk 内的 soft attention，而非其他副作用。

3.2 文档摘要（CNN/Daily Mail）

在不具备单调对齐的文档摘要任务上测试 MoChA 的极限：

方法 ROUGE-1 ROUGE-2
Soft Attention (offline) 39.11 15.76
Hard Monotonic Attention 31.14 11.16
MoChA, w=8 35.46 13.55
  • Hard Monotonic 相比 Soft 下降了近 8 个 ROUGE-1 点（严格单调对文档摘要太强）
  • MoChA 有效弥合了约 一半 的差距
  • 仅用 $w=8$ 的小窗口就实现了显著改善

5. 总结与影响

核心贡献

  1. 提出 MoChA，在 Hard Monotonic Attention 的基础上加入 chunk 内 soft attention，以极小代价换取显著性能提升
  2. 给出高效训练算法（MovingSum trick），可用标准反向传播训练
  3. 在语音识别上首次让在线注意力追平离线 Soft Attention
  4. 证明即使 $w=2$ 这样极小的 chunk 也能带来巨大收益

后续影响

MoChA 是流式 Seq2Seq ASR 领域的里程碑工作。后续的 Triggered Attention、MMA (Monotonic Multi-head Attention) 等工作都直接建立在 MoChA 的思想之上。它清楚地表明：在具有单调对齐特性的任务上，不需要全局 Soft Attention 就能获得同等性能——只需要在正确的位置看一小块就够了。

局限与未来方向

  • chunk size $w$ 是固定超参数，论文提出可以让其自适应变化
  • 训练仍为 offline（使用期望值近似），训练-测试存在 mismatch
  • 在需要长距离重排序的任务（如翻译）上仍有差距

💡 一句话总结：MoChA = 用 Hard Monotonic Attention 决定”在哪里看”，再用 Soft Attention 决定”怎么看”——既快又准。
